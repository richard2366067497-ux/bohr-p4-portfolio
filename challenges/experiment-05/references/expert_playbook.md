## 1 判分要点与失败模式

交付物含三大板块：**实验方案**（假设/变量/对照/步骤/参数/资源/判读标准）、**依据与风险**、
**确认项**；当输入含数据时，另出 **五段式解释结论**：结果趋势 → 异常点 → 可能原因 → 复核步骤 →
后续实验建议。

| 优先级 | 维度 | 评委关注焦点 |
|--------|------|--------------|
| P0 | 实际效果 | 五段结论是否齐全、趋势/拐点是否与原始读数一致、异常点是否落在真正异常对象上、每条结论能否回指数据 |
| P1 | 使用增益 | 加载后质量是否稳定提升、是否减少返工、是否有公平对照 |
| P2 | 创新增益 | 异常是否绑定批次/通道维度、原因是否按可检验性排序 |
| P3 | 可靠体验 | 触发正确性、多数据形态下持续可用、异常数据处置 |
| P4 | 生态贡献 | 文档齐全、资源可复用 |

常见失败（错误 → 正确）：

| # | 错误做法 | 正确做法 |
|---|----------|----------|
| F1 | 趋势写成读数复述 | 给方向+幅度+区间："t=20–40 min 内吸光度以 0.032±0.004 AU/min 线性上升（R²=0.987）" |
| F2 | 把正常波动当异常 | 量化阈值："第 7 组均值 0.82 偏离对照 1.15 达 2.7σ（阈值 2.0σ），判统计异常" |
| F3 | 异常归错样本/批次 | 明确维度："批次 B-20240312、通道 Ch3、孔位 H7"，回指行号 |
| F4 | 原因只给一个机理猜测 | ≥2 个候选，各标支持证据、排除证据、可检验性评级 |
| F5 | 复核写"检查数据质量" | "打开 raw_batch_B.csv，核对第 47–52 行 Ch3 读数是否在 0.1–2.0 AU 内" |
| F6 | 数值/单位捏造 | 所有数值回指原始文件+字段+行号，单位与原始一致 |
| F7 | 假设写成事实 | 标 `[待验证]` 或 `[已确认:来源]`，未确认项入"确认项" |
| F8 | 对照缺失不声明 | 显式标注"本案例未提供 XX 对照，置信度降级为 [需补充对照]" |
| F9 | 建议泛泛 | "将 n=3 扩至 n=5（当前 CV=12%，目标 CV≤8%，n=(Z·CV/target)²）" |
| F10 | 忽略安全/伦理确认项 | 涉危化品/生物样品/高温高压时必须列出安全操作与专家确认 |

## 2 求解框架（6 步法）与门控

```
输入材料 → S1 材料解析 → S2 任务拆解 → S3 方案设计 → S4 数据解释 → S5 风险审查 → S6 组装交付
```

| 步 | 动作 | 冻结产物 | 门控 |
|----|------|----------|------|
| S1 | 读 case/task，解析附件（数据表/设备描述/文献），建素材表 | `material_inventory.md` | 每个数据文件标"已解析/失败/部分解析"，失败须在输出声明 |
| S2 | 目标拆为可检验假设（自变量/因变量/控制/混杂），定对照类型 | `variable_matrix.md` | 每假设 ≥1 量化判据；无对照者标"置信度降级" |
| S3 | 设步骤序列、参数范围、重复数、资源、判读标准（接受/拒绝阈值） | 方案草案 | 每参数有来源；无来源标 `[待确认]` |
| S4 | 五段式解释：趋势 / 异常定位 / 原因候选 / 复核步骤 / 后续建议 | `interpretation.md` | 每条趋势回指行号；每异常有阈值；每原因有支持证据+验证方案；每复核可执行 |
| S5 | 安全/伦理/设备/专家确认审查 | `confirmation_items.md` | 涉安全事项标 `[需专家确认]`，不得写成可执行事实 |
| S6 | 组装所有产物 | `result.json` + 各 md | 每文件存在且非空；status 诚实反映完成度 |

**映射到本 Skill 产物**：五段结论↔`interpretation.md`；异常档案（对象/严重度/裁决/归因）↔
`dossier_index.json` + `dossiers/anomaly-<id>.md`；筛检规则 R1–R9 与阈值↔`recompute.json` /
`thresholds.json`；统计复算↔`recompute.json`；盘点↔`inventory.json`；证据↔`evidence.json`；
不确定项↔`uncertainties.json`；方法↔`method_notes.md`。

## 3 统计口径（逐条可复算）

### 3.1 趋势量化指标

| 指标 | 公式 | 可接受波动 |
|------|------|-----------|
| 线性斜率 | k = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)² | 相对 SE < 15% |
| 拟合优度 | R² = 1 - SS_res/SS_tot | R² > 0.90 为良好线性 |
| 拐点 | 二阶导数过零点或分段拟合残差最小处 | 定位精度 ±1 采样间隔 |
| 平台期 | \|dy/dx\| < 2σ_noise，持续 ≥3 采样点 | — |
| 偏离幅度 | Δ = \|M_exp - M_ctrl\| / M_ctrl × 100% | 报告 95% CI |

### 3.2 异常判定阈值体系（按优先级选用）

| 方法 | 公式 | 适用条件 | 阈值 |
|------|------|----------|------|
| Z-score | Z = (x-μ)/σ | 正态，n ≥ 10 | \|Z\|>2.0 警告，>3.0 异常 |
| 修正 Z（MAD） | Z_MAD = 0.6745(x - median)/MAD | 非正态或小样本 | \|Z_MAD\| > 3.5 |
| IQR 法 | x < Q1-1.5·IQR 或 x > Q3+1.5·IQR | 分布未知 | 1.5×IQR 温和，3×IQR 极端 |
| Grubbs | G = \|x_max - x̄\|/s | 单变量正态，检单个异常值 | 查表临界值 |

**Z-score 示例**：10 个重复 `[2.31,2.28,2.35,2.29,2.33,2.87,2.30,2.32,2.27,2.34]`
→ μ=2.366, σ=0.1790；2.87 的 Z=0.504/0.1790=**2.82**（>2.0 警告，<3.0 异常）。
**MAD 示例**（同数据）：中位数 2.315，MAD=0.025 → Z_MAD = 0.6745×0.555/0.025 = **14.97**（≫3.5 强异常）。

### 3.3 统计功效与重复数

```
n = [(Z_{α/2} + Z_β) · σ / δ]²
```

示例：δ=0.5, σ=1.2, α=0.05, power=0.80 → n = [(1.96+0.842)×1.2/0.5]² = 6.725² = 45.2 → **每组 46**。

### 3.4 原因证据强度评级

| 等级 | 定义 | 证据要求 |
|------|------|----------|
| A（强） | 有直接数据支持因果 | ≥2 个独立数据点指向同一原因，且排除主要替代解释 |
| B（中） | 有相关性但未排除替代 | ≥1 个数据点支持，存在未排除的替代解释 |
| C（弱） | 仅理论/类比 | 无直接数据，基于文献或经验推断 |

## 4 领域陷阱与单位

| # | 错误 | 正确 |
|---|------|------|
| K1 | "吸光度 3.5 AU，浓度很高" | 多数分光光度计量程 0–2 AU，>2 AU 不可靠，需稀释重测 |
| K2 | "pH 7→5，酸度增 2 倍" | pH 为对数标度，降 2 意味着 [H⁺] 增 100 倍 |
| K3 | "温度 25→50 °C 翻倍" | 绝对温度 298→323 K，增 8.4%，非翻倍 |
| K4 | "R²=0.95 说明因果成立" | R² 仅衡量线性相关强度，不能证明因果 |
| K5 | "三次重复一致，可靠" | n=3 统计功效通常不足，需报告功效分析 |
| K6 | "对照无变化即无系统误差" | 对照可能同受系统误差，需外部标准品验证 |
| K7 | "峰面积与浓度成正比" | 仅在检测器线性范围内成立，需确认校准曲线 |
| K8 | 把精度当准确度 | precision ≠ accuracy，需校准标准品验证准确度 |

单位陷阱：mg/mL 转 mM 须除以分子量；稀释后测量值须乘回稀释倍数；表压 P_abs = P_gauge + 1 atm；
干基/湿基须标注；采样频率统一为秒。文献引用：参数范围/判读阈值/安全限值须引文献；禁止编造 DOI。

## 6 完整案例（Cat-X 催化降解苯酚）

> 输入：`reaction_data.csv`（空白 / Cat-S / Cat-X × 3 重复 × 8 时间点，苯酚 mg/L）、
> `equipment_log.csv`、`literature_ref.pdf`。约束：25±1 °C，pH 7.0±0.2，初始 100 mg/L。

**异常**：CatX_R3, t=20 min 读数 **148.3 mg/L**（高于初始 100，违反质量守恒）。
MAD 法（n=3）：三值 [47.2,46.5,148.3]，中位数 47.2，MAD=0.7 → Z_MAD = 0.6745×101.1/0.7 = **97.4**（极端异常）。
排除后 CatX t=20 = (47.2+46.5)/2 = **46.85**。

**趋势**：Cat-X 组 ln(C/C₀) 对 t 线性回归，k = **0.0427 min⁻¹**，R² = **0.9987**，t₁/₂ = 16.2 min；
Cat-S 组 k = 0.0206 min⁻¹，R² = 0.9991，t₁/₂ = 33.6 min → Cat-X 速率约为 Cat-S 的 **2.07 倍**。
空白组 90 min 仅降解 6%，说明催化降解是主要机制。

**原因**：候选 #1（高可检验性）取样交叉污染——支持：该值高于初始浓度、仅 R3 异常；验证：检查比色皿/移液器、
重做该点。候选 #2（中）比色皿残留——排除证据需查原始吸光度；验证：调取 t=20 原始吸光度核对换算。

**复核**：打开 `reaction_data.csv` 核对 t=20 行 CatX_R3；打开 `equipment_log.csv` 查 t=15–25 min 是否有 ERROR/WARN。

**建议**：重做 CatX_R3 t=20（高，影响均值与拟合）；增 t=15/25 采样点（中，加密拐点定位）。

**风险**：n=3 功效不足（中 → p>0.05 扩至 n=5）；吸光度超量程（低 → t=0/5 稀释重测）。
**确认项**：Cat-X 毒性需查 MSDS（`[需专家确认]`）；含苯酚废液按危废处置（`[需专家确认]`）。

## 7 专家注意点（逐条排雷）

1. **异常绑定维度**：定位到样本/批次/通道/孔位/时间点，并回指原始行号。
2. **量化在前**：任何"异常"判断必须带统计量与阈值，禁止凭感觉。
3. **物理合理性复核**：统计异常之外，须做物理/化学合理性检查（如超初始浓度即不可能）。
4. **规则只报分歧**：筛检规则只发现与分布或另一来源的分歧，不直接判定为错误。
5. **单位不一致并列**：冲突单位/阈值并列保留，不静默合并成一个值。
6. **原因排序**：按可检验性（有数据支持+可设计验证 → 高）排序，标支持/排除证据。
7. **复核可执行**：每条复核必须是第二人可照做的动作（文件+行号+条件）。
8. **假设≠事实**：未确认内容标 `[待验证]`，安全事项标 `[需专家确认]`。
