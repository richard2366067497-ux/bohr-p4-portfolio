# 专家参考手册 —— 跨文档证据链与可比性审查

本手册是 reading-client 的**执行前必读**方法论：它规定字段口径、抽取与核验流程、可比性判定、
公式与容差、交付物形态与自查清单。执行时按本手册推进，产出后再逐项过 §9 自查表。

---

## 1. 任务本质与高分要素

任务不是给每篇文档写一段摘要，而是交付一条**可复跑的跨文档证据链**：
统一字段定义 → 逐篇取值 → 条件可比性判定 → 受限定量比较 → 冲突解释 → 原文复核。

高分要素（缺一即扣分）：

1. **对得齐**：对象、数据、方法、条件、指标、结论、局限使用同一字段字典。
2. **填得准**：原值、单位、归一化值分开保存；不跨文档补值；不把去除率当吸附量。
3. **说得清**：先判定任务、指标、单位、材料、污染物、预算是否一致，再决定能否比较；
   差异归因必须有证据。
4. **查得回**：关键单元格带准确的 `source_document_id`、`paragraph_id` 与逐字引文；
   页码、表图号作为补充定位。

## 2. 七步求解框架与门控

| 步骤 | 操作 | 冻结产物 | 门控 |
|---|---|---|---|
| 0. 输入盘点 | 读取工单、案例 ID、输出契约、资源清单及全部文件 | `input_inventory`、输出字段清单 | 文件未读不得按文件名或领域标签猜内容 |
| 1. 文档登记 | 核对标题、DOI、版本、主题相关性；识别重复版本 | `document_registry` | 重复版本不得当作独立证据；不相关文档单列 |
| 2. 定义字段 | 冻结指标方向、单位、空值词、比较轴及预算含义 | `field_dictionary` | 同名字段定义不一致时先修字典，不急着抽值 |
| 3. 单文抽取 | 每篇独立形成 对象/数据/方法/条件/指标/结论/局限 卡片 | `evidence_cards` | 每个关键值有来源 ID、段落 ID、引文；缺失填 `NR` |
| 4. 建原始矩阵 | 一行对应「文档×实验条件×指标」，保存原始上下文 | `comparison_matrix` 初版 | 不把多组实验无标记压成一个数 |
| 5. 可比性判定 | 检查任务、指标、单位、材料、污染物、预算及关键条件 | `comparability_decisions` | 任一必需轴为「否/未知」，禁止自动合并或排名 |
| 6. 计算与整合 | 单位换算、复算、差值计算、冲突归因 | 主结果、冲突清单、排除理由 | 计算只读取已冻结的可比子集 |
| 7. 独立核验 | 重读引文、重跑公式、检查跨文档串值与 JSON 契约 | `validation_report` | 关键数值复算失败则降级状态，不得隐藏 |
| 8. 交付 | 写 `result.json` 及可编辑附件，记录变更 | 最终包 | `case_id`、原契约字段、状态、来源、不确定性齐全 |

预算分配：前 70% 完成读取与矩阵，20% 用于比较，至少 10% 用于复核。
首批证据卡形成后立即保存诚实的部分结果，再增量改善。

## 3. 可比性分级（四档，先判后算）

- **不可比**：任务、指标定义或污染物不同，且工单只允许同任务定量综合。
- **主题可比**：研究问题相近，但条件或口径不足，只能列示，不能计算优劣。
- **条件数值可比**：任务、指标、污染物、预算一致，单位可精确换算；
  材料若是工单指定的比较轴，可逐材料描述差异，但不计算跨材料均值。
- **直接复算/合并可比**：除上述条件外，材料、关键实验条件与统计口径也一致，
  并有足够重复与离散度信息。

「材料相同」不是任何比较的绝对前提：比较不同材料时，材料可以是**有意变化的自变量**；
但其他条件不一致时，不能把观察差异全部归因于材料。预算须按工单定义记录（吸附剂质量、
成本或能量上限）；Agent 的运行时间、模型请求数不得混入科学预算。

## 4. 量化口径与公式

去除率与平衡吸附量（\(C_0,C_e\) 用 mg/L，\(V\) 用 L，\(m\) 用 g，则 \(q_e\) 为 mg/g）：

\[
R(\%)=\frac{C_0-C_e}{C_0}\times100,\qquad
q_e=\frac{(C_0-C_e)V}{m}
\]

若 \(m\) 原文为 mg，必须先除以 1000。\(q_e\) 是实验平衡值，不能与模型拟合的 \(q_{\max}\) 混用。

同一可比子集内，以 \(i\) 为参照 \(ref\)：

\[
\Delta q=q_i-q_{\mathrm{ref}},\qquad
\Delta q_{\mathrm{rel}}=100\frac{q_i-q_{\mathrm{ref}}}{q_{\mathrm{ref}}}\%
\]

去除率之差应写「百分点」，例如 \(88\%-80\%=8\) 个百分点，而非「提高 8%」。
没有重复实验、标准误或原始数据时，不计算显著性，也不做加权荟萃。

## 5. 波动、复算容差与舍入包络

不存在通用的「实验差异 ±5% 即一致」。纯单位换算可用相对数值误差 \(10^{-9}\) 作为程序检查阈值；
由原文数值复算时，必须考虑有效数字。若整数浓度 \(C_0=100,C_e=20\) 仅按四舍五入理解，
各取 ±0.5 mg/L：

\[
R_{\min}=100(1-20.5/99.5)=79.397\%,\quad
R_{\max}=100(1-19.5/100.5)=80.597\%
\]

故论文报告 80.0% 可通过复算；该区间只是**舍入包络**，不是实验置信区间。
超出包络时检查单位、公式与取值，仍不一致则标记冲突。

## 6. 领域陷阱清单

- 去除率高不必然代表吸附量高：降低吸附剂质量可能提高 \(q_e\)，却降低总体去除能力。
- 吸附、降解与矿化不是同一任务；颜色消失不能自动证明污染物矿化。
- 不同染料不得因「都是有机污染物」而合并；同染料的不同浓度、pH、温度、离子强度也须分层。
- `mg/g`、`g/g`、`mmol/g` 不可直接比较；摩尔换算须使用材料明确给出的摩尔质量及化学形态。
- `mg/L` 与 `µg/mL` 数值相等；`m=50 mg` 必须换成 `0.050 g` 后代入公式。
- 一级、二级动力学速率常数量纲不同；不同模型拟合的 \(k\) 不可直接排名。
- 平衡时间不足时的「吸附量」不能擅自写成 \(q_e\)；最好条件值不能写成普遍性能。
- 论文未报重复数或误差棒时，不得自行补标准差；图表估读须标为估读并记录图号。
- 原文数值只能由该文档的证据支持；外部文献只可辅助解释公式或术语，须单独标注来源，
  不能替目标文档补实验条件或虚构 DOI。

## 7. 交付物与可核验方式

| 文件/章节 | 必需内容 | 可核验方式 |
|---|---|---|
| `result.json` | 原 `output_contract` 全字段、`case_id`、主结果、状态、不确定性、来源、变更记录 | 程序化校验字段；状态与排除项一致 |
| `comparison_matrix.csv` | 原值、原单位、归一值、条件、可比性、来源双 ID | 每行可定位到证据卡 |
| `evidence_cards.jsonl` | 短逐字引文、段落 ID、页/表/图、抽取备注 | 随机抽行回原文逐字核对 |
| `comparability_decisions.csv` | 六个必需轴及附加条件、判定、理由 | 每个被排除文档均有具体原因 |
| `comparison_report.md` | 字段字典、主表、冲突解释、限制、未报告项 | 区分事实、复算结果与解释性推断 |
| `validation_report.json` 与复算脚本 | 公式版本、输入值、误差、通过/失败项 | 运行固定命令重算，而非人工声称已检查 |

推荐复算命令：

```bash
python /app/work/recompute.py \
  --matrix /app/output/comparison_matrix.csv \
  --out /app/output/validation_report.json
```

引文应短而完整，省略号不得改变语义。材料未提供段落 ID 时，可生成稳定定位符并明确标记
「系统生成」，同时保存页码、段落序号与文本哈希，不能冒充原始 ID。

## 8. 完整虚构案例演示

> 以下文档、数值与 ID 均为合成示例，仅演示流程，不是正式测试结果。

输入：`case_id=DEMO-SYN-001`，比较不同材料在染料 D1、每批吸附剂预算 0.050 g 下的
\(q_e\) 与去除率；材料是指定比较轴，不计算跨材料均值。

- **DEMO-A, p014**：「将 0.050 g M1 加入 100 mL、100 mg/L 的 D1 溶液；298 K、pH 7、60 min 后 Ce=20 mg/L。」
- **DEMO-A, p015**：「qe=(C0−Ce)V/m，R=(C0−Ce)/C0×100%。」
- **DEMO-B, p009**：「将 0.050 g M2 加入 100 mL、100 mg/L 的 D1 溶液；298 K、pH 7、60 min 后 Ce=12 mg/L。」
- **DEMO-B, p010**：「qe=(C0−Ce)V/m，R=(C0−Ce)/C0×100%。」
- **DEMO-C, p006**：「0.100 g M3 处理 200 mL、50 mg/L 的 D2 溶液，平衡后 Ce=10 mg/L。」

统一 \(V=100\text{ mL}=0.100\text{ L}\)：

\[
R_A=80\%,\ q_{e,A}=(100-20)\times0.100/0.050=160\text{ mg/g}
\]
\[
R_B=88\%,\ q_{e,B}=88\times0.100/0.050=176\text{ mg/g}
\]
\[
R_C=80\%,\ q_{e,C}=(50-10)\times0.200/0.100=80\text{ mg/g}\ (\text{污染物与预算不匹配})
\]

| 文档 | 材料/污染物 | 预算 | qe（mg/g） | R | 判定 | 证据 |
|---|---|---:|---:|---:|---|---|
| DEMO-A | M1/D1 | 0.050 g | 160 | 80% | 条件数值可比 | p014–p015 |
| DEMO-B | M2/D1 | 0.050 g | 176 | 88% | 条件数值可比 | p009–p010 |
| DEMO-C | M3/D2 | 0.100 g | 80 | 80% | 不作定量综合 | p006 |

主结果：在题设条件下 M2 的复算 \(q_e\) 比 M1 高 \(176-160=16\) mg/g，相对参照高
\(16/160\times100=10.0\%\)；去除率高 8 个百分点。
总体状态为**部分完成**：三篇均已抽取，但仅 A/B 构成定量可比子集，C 因 D2 与 0.100 g 预算
保留但排除。因未报告独立重复、标准差与批次信息，只能陈述该条件下的观察差异，
不得宣称 M2 普遍优于 M1、差异具有统计显著性，或把 16 mg/g 全部归因于材料本征性质，
也不得将三篇平均为 138.7 mg/g。

## 9. 防扣分自查表（交付前逐项通过）

- [ ] 已实际读取工单、全部语料、资源清单与输出契约。
- [ ] 正式结果中的 `case_id` 与输入完全一致。
- [ ] 每篇指定文档均出现，或有明确排除/失败记录。
- [ ] 未把同一文档不同版本重复计为独立证据。
- [ ] 字段字典先于跨文档比较冻结。
- [ ] 每个关键单元格都有准确的文档 ID 与段落 ID。
- [ ] 引文逐字对应所标注文档，没有跨文串值。
- [ ] 原值、原单位、换算值与换算过程均已保留。
- [ ] 未报告项写 `NR`，未写成 0 或「无」。
- [ ] 多条件实验未被无标记压成单一数值。
- [ ] 定量计算前已检查任务、指标、单位、材料、污染物与预算。
- [ ] 未合并不同染料、不同指标定义或不同任务的数据。
- [ ] 去除率差使用「百分点」，相对差使用百分号。
- [ ] 未把 \(q_e\)、\(q_{\max}\)、去除率与降解率混用。
- [ ] 所有派生数值均可由保存的输入复算。
- [ ] 舍入包络与实验不确定性已明确区分。
- [ ] 无重复数或离散度时未宣称显著性。
- [ ] 冲突归因区分了样本、方法、条件与评价口径。
- [ ] 解析失败、材料缺失、无法判断分别记录。
- [ ] 不可比项与排除理由仍保留在主交付物中。
- [ ] `result.json` 含全部原契约字段，部分完成状态有原因。
- [ ] 已运行复算与抽样回读，且验证结果与摘要一致。
- [ ] 虚构示例、预制答案与未实际取得的跑分未进入正式结果。

**门控**：以上任一项未通过，`status` 记为 `partial` 并把未决项写入 `uncertainties`，
绝不静默提升为 `answered`。
