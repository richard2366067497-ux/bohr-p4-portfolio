# 研究方法与统计审查 Skill 专家手册（expert_playbook.md）

> 本手册用于指导通用 Agent 在“研究方法与统计审查”任务中稳定产出高分审查单。核心原则：**每条意见必须落回原文位置、逐字引用、区分缺陷类型、严重度与缺陷性质匹配、可独立复算**。不追求意见数量，追求可核验性。

---

## 1. 任务理解与判分要点

### 1.1 真正要交付什么

一份**结构化审查单**，不是读后感。每个案例返回：

- 逐条问题：位置、缺陷类型、严重度、修改建议；
- 依据与边界：原文逐字引用、数据/方法证据、待复核项；
- 结果状态：通过 / 问题 / 待复核 / 未检查项。

五个检查面必须覆盖：**研究设计、变量定义、统计方法、样本量与检验效能、结果报告**。同时覆盖六类审查面：**事实核验、引用支持、方法设计、统计报告、论证链、学术规范**。

### 1.2 评委看哪几件事

| 维度 | 关键考察 |
|---|---|
| 实际效果 40 分 | 是否真正走完五个检查面；结论与原文是否对得上；关键缺陷是否漏检；每条意见能否被第三方独立复核 |
| 使用增益 25 分 | 相比基础 Agent 是否稳定提升质量；是否减少人工回查；是否通过公平对照证明增益 |
| 创新增益 15 分 | 是否具备基础 Agent 不具备的定位与判定能力；流程、规则、分级是否有实质改进 |
| 可靠体验 10 分 | 能否被正确触发；不同排版下稳定运行；对缺页、扫描件、图表无法解析等异常有处置 |
| 生态贡献 10 分 | 检查项清单、严重度定义、输出字段、依赖与限制说明齐全；资源可复用 |

### 1.3 常见失败模式：错误做法 → 正确做法

1. **错误**：给出“统计方法不当”却不指位置。  
   **正确**：定位到“第 3.2 节，表 2 下方，原文‘采用独立样本 t 检验’”，并逐字引用。

2. **错误**：把“作者没有报告”写成“作者做错了”。  
   **正确**：区分“证据不足/未报告”与“事实错误/方法错误”。未报告只能标“待复核”或“规范问题”，不能判为硬伤。

3. **错误**：所有问题都标“重大缺陷”。  
   **正确**：按缺陷对结论可信度的影响分级：致命、重大、中等、轻微、建议。

4. **错误**：把可接受做法判成硬伤。例如两组各 40 例、未做多重比较校正但主要终点只有一个。  
   **正确**：先判断是否违反方法学常识或报告规范，再定严重度。

5. **错误**：凭空补缺失信息，例如“作者可能用了 SPSS”。  
   **正确**：材料不足以判断时，标记“待复核”，并说明需要补充什么信息。

6. **错误**：只审统计方法，不审研究设计、变量定义、样本量、结果报告。  
   **正确**：按五个检查面逐项生成检查点，确保覆盖。

7. **错误**：输出不可复算的结论，例如“p 值可疑”。  
   **正确**：给出复算公式和中间量，例如“t = -3.633, df = 78, p = 0.0005，与论文报告 p = 0.03 不一致”。

8. **错误**：忽略输入材料缺失、扫描件识别失败等异常。  
   **正确**：在结果状态中明确标注“未检查项”和“运行状态”，不假装已检查。

## 2. 求解框架：从输入材料到交付物的分步流程

### Step 0 — 输入解析与证据提取
- 读取 `/input/case.json` 和 `/input/task.md`，确认 `case_id`、材料路径、检查面要求。
- 对 PDF 执行文本提取；若为扫描件，调用 OCR；若图表无法解析，记录为“未检查项”。
- **冻结产物**：`/app/work/evidence_raw.jsonl`，每行包含 `{page, section, paragraph, text, table_id, figure_id}`。
- **门控**：若无法提取任何文本，输出 `result.json` 状态为 `failed`，并说明原因，不编造内容。

### Step 1 — 检查面映射与问题生成
- 按五个检查面生成检查点清单：
  - 研究设计：设计类型、对照设置、分组方式、盲法、主要终点是否事先明确。
  - 变量定义：暴露/结局/协变量定义、测量方式、编码、分类切点、单位、缺失值处理。
  - 统计方法：检验方法与数据结构、分布假设、独立性、多重比较、重复测量、交互项、敏感性分析。
  - 样本量与检验效能：样本量估算依据、效应量来源、α、把握度、失访/剔除处理。
  - 结果报告：效应量与置信区间、精确 p 值、统计量与自由度、图表与正文一致性、报告规范。
- **冻结产物**：`/app/work/checklist.json`，每个检查点标注 `status: pending/checked/not_applicable`。
- **门控**：五个检查面必须全部覆盖；若某面不适用，需说明理由。

### Step 2 — 证据定位与逐字引用
- 对每个潜在问题，从 `evidence_raw.jsonl` 中定位原文位置。
- 使用定位格式：`[S]节号/段落`、`[T]表号`、`[F]图号`、`[Q]原句`、`[L]页码/行号`。
- **冻结产物**：`/app/work/findings_draft.jsonl`，每条包含 `location`、`quote`、`check_face`。
- **门控**：每条意见必须有 `quote` 和 `location`，否则不得进入最终输出。

### Step 3 — 缺陷分类与严重度分级
- 缺陷类型四类：**事实错误、证据不足、规范问题、建议性意见**。
- 严重度五级：**致命、重大、中等、轻微、建议**（定义见第 3 节）。
- **冻结产物**：`/app/work/findings_classified.jsonl`。
- **门控**：每条意见必须同时有 `category` 和 `severity`；无法确认的标记 `status: pending_review`。

### Step 4 — 修改建议与复算
- 对每条问题给出可操作的修改建议，例如“补充报告 t 值和自由度”“采用 Bonferroni 校正 α = 0.05/3 = 0.0167”。
- 对统计判断给出复算公式和中间量，例如样本量、t 检验、置信区间。
- **冻结产物**：`/app/work/findings_with_suggestions.jsonl`。
- **门控**：涉及统计判断的意见必须附复算过程或公式，否则降级为“待复核”。

### Step 5 — 结构化输出与自检
- 生成 `/app/output/result.json`，包含所有 `output_contract` 字段：`case_id`、`status`、`findings`、`sources`、`uncertainty`、`change_records`。
- 运行自检脚本，检查定位可复核率、检查面覆盖率、严重度分布。
- **冻结产物**：`/app/output/result.json` 及可编辑预览文件。
- **门控**：自检不通过则迭代 Step 2–4，直到满足最低阈值。

## 3. 专家方法与量化口径

### 3.1 严重度定义

| 严重度 | 定义 | 示例 |
|---|---|---|
| 致命 | 影响主要结论有效性，必须拒稿或推翻结论 | 主要终点统计方法完全错误；样本量严重不足且结论阳性 |
| 重大 | 影响某一部分结论可信度，需修改后重审 | p 值报告与复算不一致；主要终点未报告置信区间 |
| 中等 | 不影响主要结论，但需修正或补充说明 | 样本量计算依据与实际效应量不一致；次要终点未校正多重比较 |
| 轻微 | 不影响结论，但需澄清或修正文字 | 表 1 与正文基线值不一致；单位未统一 |
| 建议 | 可接受但可改进 | 建议补充敏感性分析；建议报告效应量 |

### 3.2 缺陷类型定义

| 类型 | 定义 | 处理 |
|---|---|---|
| 事实错误 | 原文陈述与数据、引用、常识或复算结果矛盾 | 直接判为问题，给出证据 |
| 证据不足 | 作者未报告必要信息，无法判断对错 | 标记“待复核”，说明需要补充什么 |
| 规范问题 | 违反报告规范或方法学共识，但不一定影响结论 | 判为问题，给出规范依据 |
| 建议性意见 | 可接受但可改进 | 标注为建议，不扣严重度 |

### 3.3 证据定位格式

- `[S]3.2`：第 3.2 节
- `[T]2`：表 2
- `[F]1`：图 1
- `[Q]“采用独立样本 t 检验”`：逐字引用
- `[L]p.5, para 2`：页码、段落

### 3.4 量化指标

| 指标 | 定义 | 目标值 |
|---|---|---|
| 定位可复核率 | 有逐字引用且位置可定位的意见数 / 总意见数 | ≥ 95% |
| 检查面覆盖率 | 五个检查面中至少有一条意见的面数 / 5 | 100% |
| 关键缺陷召回率 | 命中的关键缺陷数 / 白板关键缺陷总数 | ≥ 80% |
| 严重度一致率 | 与专家白板严重度一致（允许 ±1 级）的意见数 / 总意见数 | ≥ 80% |
| 误报率 | 错误意见数 / 总意见数 | ≤ 10% |

### 3.5 关键公式与计算示例

**样本量计算（两组均值比较）**：

\[
n_{\text{per group}} = \frac{2(z_{1-\alpha/2} + z_{1-\beta})^2}{d^2}
\]

其中 \(d = (\mu_1 - \mu_2)/\sigma\)。  
示例：\(\alpha = 0.05\)，\(1-\beta = 0.80\)，\(d = 0.5\)。  
\(z_{0.975} = 1.96\)，\(z_{0.8} = 0.84\)。  
\(n = 2 \times (1.96 + 0.84)^2 / 0.5^2 = 2 \times 7.84 / 0.25 = 62.72 \approx 63\)。  
考虑 20% 失访：\(63 / (1 - 0.2) = 78.75 \approx 79\)，每组 80 例。

**实际入组 40 例时的把握度**（基于 \(d = 0.5\)）：

\[
z_{\text{power}} = d \sqrt{n/2} - z_{1-\alpha/2} = 0.5 \times \sqrt{40/2} - 1.96 = 0.5 \times 4.472 - 1.96 = 0.276
\]

把握度 \(= \Phi(0.276) \approx 0.609\)，即约 61%。

**独立样本 t 检验复算**：

\[
t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s^2/n_1 + s^2/n_2}}, \quad df = n_1 + n_2 - 2
\]

示例：\(\bar{x}_1 = -12.5\)，\(\bar{x}_2 = -6.0\)，\(s = 8.0\)，\(n_1 = n_2 = 40\)。  
\(SE = \sqrt{8^2/40 + 8^2/40} = \sqrt{1.6 + 1.6} = 1.789\)。  
\(t = (-12.5 - (-6.0)) / 1.789 = -6.5 / 1.789 = -3.633\)。  
\(df = 78\)，双侧 \(p = 2 \times P(T > 3.633) \approx 0.0005\)。  
95% CI：\(-6.5 \pm 1.96 \times 1.789 = (-10.006, -2.994)\)。

**多重比较 Bonferroni 校正**：  
若进行 3 次次要终点比较，校正后 \(\alpha = 0.05 / 3 = 0.0167\)。

### 3.6 可接受波动

- 定位可复核率 ≥ 95%；
- 检查面覆盖率 100%；
- 严重度一致率 ≥ 80%（允许 ±1 级）；
- 复算数值与论文报告数值差异超过 5% 或 p 值跨过显著性阈值时，必须标记为问题。

## 4. 领域知识清单

### 4.1 常见事实性错误

| 错误类型 | 示例 | 正确做法 |
|---|---|---|
| p 值报告 | 报告 \(p = 0.000\) | 写 \(p < 0.001\) |
| 置信区间与显著性 | OR = 1.5，95% CI 0.8–2.8，结论“显著” | CI 包含 1 不显著 |
| 统计量与自由度缺失 | 只写 \(p < 0.05\)，不写 \(t\) 或 \(df\) | 报告 \(t(78) = -3.63, p < 0.001\) |
| 图表不一致 | 正文写“基线收缩压 150.0”，表 1 写 150.2 | 必须一致 |
| 效应量缺失 | 只报告 p 值，不报告效应量和 CI | 报告均值差、OR/RR/HR 及 95% CI |

### 4.2 单位/量纲陷阱

| 陷阱 | 说明 |
|---|---|
| 血压单位 | mmHg 与 kPa 不可混用；1 kPa = 7.5006 mmHg |
| 血糖单位 | mg/dL 与 mmol/L 不可混用；1 mmol/L ≈ 18 mg/dL |
| 倍数变化 vs 百分比变化 | “降低 2 倍”不严谨；应报告绝对差或百分比变化 |
| log 转换 | 报告几何均值或中位数时需说明转换方式 |
| 分类切点 | 连续变量二分类化必须给出切点依据，如 BMI ≥ 25 |

### 4.3 文献依据要求

- 引用支持：每条方法学判断需引用报告规范或教科书，如 CONSORT、STROBE、PRISMA、STARD。
- 样本量效应量来源：必须引用先前研究或预试验数据，不能凭空设定。
- 统计软件：报告软件名称、版本、函数或过程，如“R 4.3.1, t.test()”。

### 4.4 统计方法匹配表

| 数据结构 | 正确方法 | 常见错误 |
|---|---|---|
| 两组独立连续变量 | 独立样本 t 检验或 Mann-Whitney U | 配对 t 检验 |
| 配对/重复测量 | 配对 t 检验或 Wilcoxon signed-rank | 独立样本 t 检验 |
| 多组比较 | 方差分析 + 多重比较校正 | 多次 t 检验不校正 |
| 二分类结局 | χ² 检验或 Fisher 精确检验 | t 检验 |
| 生存数据 | Kaplan-Meier + log-rank + Cox 回归 | 忽略删失 |

## 7. 完整虚构案例演示（输入 → 关键中间量 → 输出）

> 以下为**虚构示例**，仅用于说明流程，不冒充正式案例结果。

### 7.1 输入

`case_id = "DEMO-001"`，材料为 PDF 论文片段：

- 标题：某新药对原发性高血压患者收缩压影响的随机对照试验
- 方法：两组各 40 例，主要终点为治疗 8 周后收缩压变化，采用独立样本 t 检验
- 样本量计算：基于效应量 d = 0.5，α = 0.05，把握度 0.80，每组需 64 例，实际入组 40 例，未说明失访
- 结果：新药组 -12.5 ± 8.0 mmHg，安慰剂组 -6.0 ± 8.0 mmHg，p = 0.03，95% CI -12.0 to -1.0
- 表 1：安慰剂组基线收缩压 150.2 mmHg；正文写 150.0 mmHg
- 次要终点 3 个，未提及多重比较校正

### 7.2 关键中间量

**复算 t 检验**：

```
n1 = n2 = 40
m1 = -12.5, m2 = -6.0, sd = 8.0
SE = sqrt(8^2/40 + 8^2/40) = 1.789
t = (-12.5 - (-6.0)) / 1.789 = -3.633
df = 78
p = 2 * P(T > 3.633) ≈ 0.0005
95% CI = -6.5 ± 1.96 * 1.789 = (-10.006, -2.994)
```

论文报告 p = 0.03，95% CI -12.0 to -1.0，与复算不一致。

**复算样本量把握度**：

- 基于 d = 0.5，n = 40：\(z_{\text{power}} = 0.5 \times \sqrt{20} - 1.96 = 0.276\)，把握度 ≈ 0.609。
- 基于实际 d = (12.5 - 6.0)/8.0 = 0.8125，n = 40：\(z_{\text{power}} = 0.8125 \times \sqrt{20} - 1.96 = 1.674\)，把握度 ≈ 0.953。
