## 1. 任务本质与判分要点

### 1.1 任务本质

长文档的问题很少出在文笔，而出在**漂移**：同一缩写有两种展开，某个图被正文引用却没有图注，
某条引用找不到文献条目，结果章与讨论章对同一结论给出相反极性。本任务要求依据给定材料完成
**可复核的学术写作产物**，且**不改写作者原句、不虚构任何文献**。每份交付包含三面：

1. **目标产物**：可编辑的稿件 / 改稿 / 结构化结果，满足体裁、受众、格式。
2. **事实与来源映射**：数字、术语、引用、图表编号、关键论断逐条可回溯，不新增材料外事实。
3. **版本与边界**：修改差异、人工确认项、材料缺口、异常显式标注，结果可继续编辑。

### 1.2 判分要点（优先级从高到低）

1. **实际效果**：是否写出可用章节而非通用建议；每条论断是否与文献/材料对得上；章节、论证要素、
   著录项是否齐全；能否追溯到大纲条目、原始材料、具体文献与版本记录。
2. **使用增益**：跨章节一致性与可编辑性是否稳定提升；是否减少人工通读、统一术语、补引用、重排编号。
3. **创新增益**：是否形成基础能力之外的**长文档能力**——术语/符号/编号/引用/论断的多账本联动。
4. **可靠体验**：对材料缺失、引用找不到、结论冲突、编号不连续、格式不支持、超长截断能否识别处置。
5. **生态贡献**：文档、脚本、模板、检查清单是否齐全可复用。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 只给通用写作建议 | 依据材料写出具体章节、改稿或结构化结果 |
| 不保留来源 | 每条事实/数字/引用带 locator（原文页段或 `文件:行`） |
| 忽略材料不足或冲突 | 缺失、冲突、需人工确认处明确标注，不强行补造 |
| 凭标签猜内容 | 读 `case.json`、`task.md`、编辑工单与全部材料实际内容 |
| 不处理编号与交叉引用 | 检查图表编号连续性与正文引用匹配，修正后留记录 |
| 不生成 `result.json` 或字段不全 | 逐键回填 `output_contract`，含 `case_id`、状态、来源、不确定性、修改记录 |
| 不保存中间产物 | 增量落盘草稿、映射表、检查报告，防超时丢失 |
| 虚构数据或引用 | 只依据材料，引用须能在文献列表找到，找不到标存疑 |
| 可编辑产物无预览 | Office/幻灯片/图示产物同时给真实 PDF/PNG 渲染预览 |
| 静默统一而不留痕 | 术语/编号改动逐条记 before/after，可回退 |

## 2. 求解框架（6 步）

中间产物写入 `--work`，最终结果写入 `--output`。“冻结”表示后续修改必须留版本与原因。

| 步骤 | 操作 | 冻结产物 | 门控 |
|---|---|---|---|
| S0 输入解析 | 读 `case.json`、`task.md`、编辑工单与全部材料；识别任务类型、体裁、受众、格式 | `input_manifest.json`、`task_type`、`constraints` | 必需文件存在可读；缺失记 `uncertainty` 不中止 |
| S1 事实底稿与来源映射 | 抽取事实断言、数字、术语、缩写、符号、图表编号、引用；每条 `{fact_id,quote,locator,source_file,line/paragraph,status}` | `facts_sources.json/.md` | 每条有 locator 或标 `missing_source` |
| S2 任务执行 | 按类型生成/改写/校对/结构化：章节规划、一致性检查、术语与引用、版本管理、长上下文、持续修改 | 目标产物初稿（如 `chapter3_revised.md`） | 符合体裁/受众/格式；不新增材料外事实 |
| S3 一致性与引用核对 | 跑术语表、符号表、编号连续性、引用匹配检查 | `consistency_report.md` | 冲突解决或标 `unresolved`；缺失引用标 `citation_missing` |
| S4 版本与边界记录 | 生成 diff / before-after、人工确认项、材料缺口、异常 | `change_records.md`、`version_diff.md` | 修改可回退、可比较、可说明 |
| S5 打包与结果 | 目标产物、来源映射、一致性报告、版本记录、预览落 `--output`；写 `result.json` | `result.json` + 全部交付物 | 字段齐全；可编辑产物与预览存在；路径有效 |

**可回退不变量**：把插入的批注/修改视作独立块，移除后能逐字还原原文；`preserved_facts` 与
回滚校验记录这一事实。改写要留 before/after，不得覆盖后无迹可寻。

## 3. 量化口径与公式

| 指标 | 定义 | 公式 | 目标 | 可接受 |
|---|---|---|---|---|
| 事实-来源匹配率 | 有 locator 的事实占比 | `有locator事实数 / 总事实数 ×100%` | ≥95% | ≥90% |
| 术语一致性 | 统一后无变体的术语占比 | `1 − 变体数/术语总数`（×100%） | 100% | ≥95% |
| 引用缺失率 | 正文中无对应文献的引用占比 | `缺失引用数 / 总引用数 ×100%` | 0% | ≤5% |
| 编号连续性 | 连续编号段占比 | `连续段数 / 总段数 ×100%` | 100% | 100% |
| 修改可追溯率 | 有修改记录的改动占比 | `有记录修改数 / 总修改数 ×100%` | 100% | 100% |
| 未确认项占比 | 待人工确认项占比 | `未确认项数 / 总项数 ×100%` | ≤5% | ≤10% |

**计算示例**：某章 3200 字，事实断言 120 条、术语 45 个、正文引用 60 处、图表编号 12 个。

- 事实-来源匹配率 = 115/120 = **95.8%**（5 条 `missing_source`）。
- 术语一致性：45 个术语发现 3 个变体（“X射线衍射”/“XRD”/“X-射线衍射”），统一后 0 变体 = **100%**。
- 引用缺失率 = 2/60 = **3.3%**（标记存疑，仍在可接受范围）。
- 编号连续性：图 3.1–3.7 缺图 3.5，正文“图 3.5”实指“图 3.6”；重排后 = **100%**。
- 修改可追溯率：6 处修改（术语 3 / 引用 2 / 编号 1）全有记录 = **100%**。
- 未确认项占比 = 5/(120+45+60+12) = 5/237 = **2.1%**。

## 4. 领域知识清单

### 4.1 常见事实性错误

1. **混淆学位论文与期刊论文**：学位论文需要更详细的综述、方法、附录，不能套期刊的简洁风格。
2. **把文献综述写成摘要**：综述需要批判性分析，不是罗列。
3. **改写结论却保留原引用**：结论被改写时必须更新引用或标“结论有改动，请人工确认”。
4. **术语前后不一致**：同一概念多种写法（“X射线衍射” vs “XRD”），必须统一并留痕。
5. **图表编号与正文引用不匹配**：正文“图 3.5”对应“图 3.6”，必须修正并记录映射。
6. **单位错误**：rpm 与 ×g、℃ 与 K 混用。
7. **忽略材料自带“待确认/暂定”标记**：必须原样传递到输出。
8. **把示例当正式结果**：示例数据不得写入产物。
9. **只改不复核**：修一处后未重跑一致性检查，引入新的编号/引用漂移。

### 4.2 单位/量纲陷阱

- 浓度：mol/L、mg/mL、μg/mL、ng/mL；区分“M=摩尔浓度”与“M=分子量”。
- 温度：K = ℃ + 273.15，不得混写。
- 压强：1 bar = 100 kPa，1 atm = 101.325 kPa，1 mmHg ≈ 133.322 Pa。
- 质量/体积：g/mg/μg/ng、L/mL/μL，注意有效数字与“μL≠uL”。
- 转速：rpm 与 ×g 不能直接换算，需转子半径。
- 波长/能量：1 μm = 1000 nm；1 eV = 1.602×10⁻¹⁹ J。

### 4.3 文献依据要求

- 每条论断绑定具体文献；引用格式符合目标要求（GB/T 7714、APA、MLA 等）。
- 正文引用必须在文献列表中存在，文献列表条目必须被正文引用（双向核对）。
- 不引用不存在的文献；存疑引用标“待人工确认”。
- 引用保留原文关键信息，不改变作者原意。

## 5. 交付物清单与专家检查表

### 5.1 必需交付物

| 文件 | 内容 | 自证方式 |
|---|---|---|
| 目标产物（如 `chapter3_revised.md/docx`） | 可编辑的稿件/改稿/结构化结果 | 可打开编辑；符合任务要求 |
| 渲染预览（如 `*.pdf`/`*.png`） | 目标产出预览 | 可独立打开；与可编辑源一致 |
| `facts_sources.json/.md` | 每条事实的 quote/locator/source_file/line/status | 逐条回溯原文位置 |
| `consistency_report.md` | 术语表、符号表、编号连续性、引用匹配 | 附检查命令或脚本输出 |
| `change_records.md` / `version_diff.md` | 每处修改的原文、改后文、原因、类型、diff | before/after 可复核、可回退 |
| `result.json` | 逐键回填 `output_contract` + `case_id` + 状态 | `python -m json.tool` |

### 5.2 专家检查表（逐项通过方可交付）

- [ ] 已读 `case.json`、`task.md` 与全部材料（PDF/docx/bib 等）的实际内容。
- [ ] 已读并落实编辑工单（如 `organizer-edit-workorder.json`）的实际目标。
- [ ] 已建事实-来源映射，每条有 locator 或标记缺失。
- [ ] 产物满足任务指定的体裁、受众、格式。
- [ ] 术语与缩写已统一，变体已记录 before/after。
- [ ] 图表编号连续，正文引用与实际编号匹配（给原→新映射）。
- [ ] 正文引用与文献列表双向匹配，存疑引用已标注。
- [ ] 修改差异（diff / before-after）已记录，可回退。
- [ ] 人工确认项与材料缺口已列出。
- [ ] `result.json` 含全部必需字段与 `case_id`，路径指向真实文件。
- [ ] 可编辑产物与渲染预览均存在且内容一致。
- [ ] 未虚构数据或引用；示例数据未混入产物。
- [ ] 材料中自带的“待确认/暂定”标记已保留并传递。
- [ ] 中间产物在 `--work`，最终结果在 `--output`。
- [ ] 未确认部分明确标注，未伪装成已完成。
- [ ] 异常（文件缺失、格式不支持、超长截断）已记录在 `status/uncertainty`。
- [ ] 重复运行措辞可变化，但关键事实、数值、来源与论断边界不漂移。

## 6. 完整虚构案例

> 以下材料、数据与输出均为演示虚构，不对应任何正式测试案例。

**输入**：`case_id="case-001"`；任务为对材料科学学位论文第 3 章“实验方法”做术语统一、引用补全、
编号修正。材料：`chapter3.docx`（3200 字，事实 120 条，术语 45 个，引用 60 处，图表编号 12 个）、
`references.bib`（45 条）、编辑工单（统一术语 / 补全引用 / 修正编号）。

**关键中间量**：

1. 事实提取：120 条，115 条有 locator，5 条缺来源（如“样品在 300℃ 煅烧 2h”缺页码）。
2. 术语表：45 个术语，3 个变体 → 统一为“X射线衍射（XRD）”“扫描电子显微镜（SEM）”
   “透射电子显微镜（TEM）”。
3. 引用核对：60 处正文引用中 2 处找不到条目（`[Smith 2019]`、`[Wang 2020]`）标存疑；
   1 条 `[Li 2018]` 未被正文引用，标“未引用”。
4. 编号检查：图 3.1–3.7 缺 3.5，正文“图 3.5”实指“图 3.6”；重排：原 3.6→3.5、原 3.7→3.6。
5. 修改记录：6 处（术语 3 / 引用补全 2 / 编号 1）。

**输出**：`chapter3_revised.md`、`chapter3_revised.pdf`、`facts_sources.json`（120 条，115 有 locator，
5 标 `missing_source`）、`consistency_report.md`（术语 45、变体 0；引用缺失 2；编号连续率 100%）、
`change_records.md`（6 处 before/after）、`result.json`（10 键全回填，`status="completed"`）。

**数字自洽**：事实-来源匹配率 115/120=95.8%；术语一致性 100%；引用缺失率 2/60=3.3%；编号连续率
100%；修改可追溯率 6/6=100%；未确认项 5/237=2.1%。

## 7. 交付前门控

- 逐项勾选 §5.2 检查表；任一未通过先修复再交付。
- `result.json` 可解析、逐键回填、`case_id` 与输入一致，路径指向真实非空文件。
- 任一改动可沿“段落 → 修改记录 → 原文定位”走通；不可读内容不得猜测。
- 异常分类记录（材料缺失 / 无法判断 / 运行失败），不得伪装成“已完成”。
