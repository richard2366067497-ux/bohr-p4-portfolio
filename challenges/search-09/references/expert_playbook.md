## 任务理解与判分要点

本任务不是“替论文写摘要”，也不是单纯返回一个文献清单，而是形成两条可以相互追溯的证据链：

1. **检索链**：科研问题 → 查询与来源 → 候选及去重 → 纳入、排除、待决 → 排序和遗漏说明。
2. **评价链**：文献类型 → 适用检查点 → 维度判断 → 原文证据及定位 → 风险等级 → 汇总规则与复核记录。

每个案例都应以实际 `/input/case.json`、`task.md`、论文及来源响应为准，在 `/app/output/result.json` 中保留 `case_id` 和原 `output_contract` 的全部字段。证据不足、材料缺失、权限受限和程序失败必须分开报告。Skill 只能包含方法、量表、模板和脚本，不能内嵌三个正式案例的答案。

评分优先级上，首先保证**实际效果**：覆盖研究设计、证据充分性、偏倚风险、报告完整性及该研究类型特有检查点；其次保证每条结论可回到原文。效率和创新增益必须有同批文献、同量表、基础 Agent 与 Skill Agent 的真实对照，不能靠自述估算。

| 常见失败模式 | 错误做法 → 正确做法 |
|---|---|
| 泛化摘要 | “设计合理、结果可靠” → 按条目给出“判断—证据—等级—理由”。 |
| 编造证据 | 根据摘要补写随机化、盲法 → 只引用实际存在的原句；未报告则弃权。 |
| 证据定位粗放 | 只写“见方法部分” → 标明 PDF 页、章节、段落、表图及行列，保留逐字原文。 |
| 缺失即高风险 | “未提盲法，所以高偏倚” → “证据不足”，并列出已检查的章节和补充材料范围。 |
| 只交纳入文献 | 省略排除和待决记录 → 候选全集分区，排除有主理由，权限问题进入待决而非消失。 |
| 排名代替筛选 | 高分即纳入 → 先执行硬性纳排标准，相关性分数仅用于排序。 |
| 孤立总评 | 直接给“低风险” → 公开领域到总评的聚合规则，保留不可评价领域。 |
| 静默处理冲突 | 任意采用一个年份或 DOI → 保留各来源原值、采用值及裁决依据。 |
| 越界检索声明 | 宣称“已穷尽最新研究” → 限定为所给快照、响应和引用图实际覆盖范围。 |
| 状态混写 | 全文付费墙记为低质量 → 记为访问受限；研究质量与可获得性分别判断。 |
| 虚报增益 | 编造节省时间或一致率 → 仅报告实际双人复核、重复运行和平台对照数据。 |
| 最后才保存 | 预算耗尽后无结果 → 尽早保存合法的部分结果，再逐条补齐。 |

## 求解框架

以下产物均先写入 `/app/work`；通过门控后冻结，修改必须追加版本和变更原因，最终所需副本进入 `/app/output`。

| 步骤 | 关键动作 | 冻结产物 | 门控条件 |
|---|---|---|---|
| 0. 读取契约 | 读取案例、任务、资源清单；提取原始输出字段；记录输入哈希和实际工具版本 | `run_manifest.json`、部分版 `result.json` | 字段逐项来自原契约；不根据领域标签猜论文内容 |

| 2. 固定方案 | 明确人群、干预/暴露、对照、结局、研究设计、时间语言和来源边界 | `protocol.md/json` | 每个排除理由均能映射到预先声明的标准；修改留痕 |
| 3. 重建检索 | 逐字记录查询、过滤条件、页码/游标、响应文件、迭代原因和引用追踪方向 | `search_log.jsonl`、`source_graph.json` | 每条记录指向真实响应或真实图边；无响应不得补造 DOI、引文数 |
| 4. 去重与筛选 | DOI 规范化后精确去重；无 DOI 时组合题名、作者、年份并保留人工待决；执行题摘和全文筛选 | `candidates.jsonl`、`screening.jsonl` | 候选数满足分区恒等式；合并不删除原始来源记录 |
| 5. 排序与追踪 | 对相关性进行透明评分；记录前向/后向追踪和本地增量导入状态 | `ranking.json`、`import_state.json` | 分数不覆盖纳排；记录旧游标、新游标、增量数、累计数 |
| 6. 质量评价 | 先依据方法识别研究类型，再映射检查表；逐条引用、判断、分级和弃权 | `quality_table.json/md` | 四类维度及类型特有检查点齐全；无证据的肯定判断不得出表 |
| 7. 独立复核 | 核对引文位置、纳排一致性、数值复算和总评聚合；记录分歧与裁决 | `validation.json`、`changes.jsonl` | 定位失败必须修正或降级；不能只验证文件存在 |

异常处理必须进入主结果：空结果保留完整查询和筛选记录；图表不可解析时降低相关条目覆盖，而不是猜图；全文不可得时完成摘要可支持的部分，其余标为不可评价；接口失败只使用已有真实缓存，不声称远程覆盖完整。

## 专家方法与量化口径

### 1. 候选集、去重与排序

令纳入、排除、待决集合分别为 \(\mathcal I,\mathcal X,\mathcal U\)，三者互斥：

\[
|\mathcal C|=|\mathcal I|+|\mathcal X|+|\mathcal U|,\qquad
R_{\rm dedup}=\frac{N_{\rm raw}-|\mathcal C|}{N_{\rm raw}}\times100\%
\]

待决包括全文权限不足、元数据冲突无法裁决等，不能暗中并入排除。

相关性排序仅用于安排复核顺序：

\[
S_{\rm rel}=100(0.5T+0.3D+0.2O)
\]

其中 \(T,D,O\in\{0,0.5,1\}\)，分别表示主题/人群、研究设计、目标结局匹配程度：0 为不匹配，0.5 为部分或信息不全，1 为明确匹配。例：某文献主题匹配、设计不匹配、结局匹配，得 \(100(0.5+0+0.2)=70\) 分，但仍因设计不符合硬标准而排除。该分数不是研究质量分，也不是正确率。

元数据完整率可定义为 \(M=n_{\rm available}/6\)，六项为题名、作者、年份、 venue、持久标识符、来源定位；缺失保持空值并说明，不用推测值填满。

### 2. 证据覆盖与复核负担

设适用条目数为 \(N_a\)，有直接原文证据的条目数为 \(N_q\)，合规弃权条目数为 \(N_u\)：

\[
C_{\rm direct}=\frac{N_q}{N_a},\qquad
C_{\rm disposition}=\frac{N_q+N_u}{N_a}
\]

合规弃权必须附检查范围和未找到的信息；只有“未报告”三个字不计入 \(N_u\)。确实不适用于该设计的条目可记 N/A，但必须给出类型依据，不能借 N/A 提高覆盖率。分母为零时输出 `null`，不输出 100%。

双人复核一致率 \(A=k/n\)，其中 \(k\) 为裁决前判断一致的条目数。可将 \(A\ge0.80\) 作为流程复核触发线，而不是证明结论正确的统计学阈值。人工负担 \(H\) 定义为至少需要人工处理的唯一条目数，包括弃权、证据冲突和评审分歧。仅在相同文献、相同量表且基础组 \(H_{\rm base}>0\) 时计算：

\[
G_H=\frac{H_{\rm base}-H_{\rm skill}}{H_{\rm base}}\times100\%
\]

没有真实基础组数据时只报 \(H\)，不报提升百分比。

### 3. 偏倚判断和汇总

- **明确存在**：原文直接显示方法或分析存在具体问题。
- **可能存在**：有具体异常或不充分做法，但偏倚方向、大小或事实尚未完全确定。
- **未见迹象**：检查了应有证据，且发现支持该环节合理实施的正面信息；不等于证明绝无偏倚。
- **证据不足**：未报告、全文缺失、图表无法解析或信息相互矛盾，不能可靠判断。

汇总不得平均打分：任一关键领域“明确存在”时总评至少为高风险；无明确高风险但存在“可能存在”时总评为“可能存在/有一些担忧”；关键领域证据不足时不得给“未见风险”；只有全部关键适用领域均有充分正面证据时才可考虑低风险。报告完整性与偏倚风险分别汇总，不能用报告缺项直接证明实施偏倚。

### 4. 数值复算与允许波动

失访率为 \(100(n_{\rm randomized}-n_{\rm analyzed})/n_{\rm randomized}\)，组间失访率差用“百分点”，不能写成百分比变化。连续结局的组间差及近似标准误为：

\[
MD=\bar x_1-\bar x_0,\quad
SE=\sqrt{s_1^2/n_1+s_0^2/n_0},\quad
CI_{95\%}\approx MD\pm1.96SE
\]

SD、SE 不得混用；使用近似正态区间时必须注明，不能冒充作者报告值。

同一来源快照和同一规则下，候选 ID、纳排状态、去重数、排序及结构化风险判断的可接受波动为 **0**；引文核对失败数应为 **0**。复算仅允许舍入误差：效应值和 SE 绝对差不超过 0.01 个结局单位，比例差不超过 0.1 个百分点。超过容差应检查单位、分母和原始数据，而不是调整结果凑一致。运行时间只报告三次实测中位数和范围，不设虚假的稳定时限。

## 领域知识清单

1. “随机”“盲法”“前瞻性”等词出现在题名中，不足以认定实际实施；必须核对方法及流程。
2. 未报告不等于未实施；统计学不显著不等于无效，显著也不等于具有临床或工程重要性。
3. PRISMA 是报告清单，不应直接当作偏倚风险工具。使用 RoB 2、ROBINS-I、AMSTAR 2 等时，记录官方来源、版本和实际采用条目；只做部分映射时不得宣称完成正式工具评价。
4. 随机人数、纳入人数、完成人数和分析人数分别保留；技术重复不能冒充独立生物样本或独立实验批次。
5. 期刊影响力、引用量、DOI 是否存在均不能替代研究质量；预印本与正式版本须分别标识，不能无依据合并。
6. Crossref、EuropePMC 和出版方元数据可能分别对应在线日期、印刷日期和版本日期；冲突时保留原值，不机械指定某来源永远正确。
7. 引用图必须保留方向：“本文引用”与“引用本文”不可颠倒；本地快照不能推出全球引文数或最新发表状态。
8. PDF 页码与印刷页码须区分；表格证据定位到表号、行列，翻译只能作为附加内容，原评价仍锚定原文。
9. 材料/化学实验中，wt%、mol%、vol% 不可直接互换；产率、转化率、选择性分母不同。\(1\,\mathrm{MPa}=10\,\mathrm{bar}\)，摄氏温度转热力学温度需加 273.15；误差棒须确认 SD、SE 还是置信区间。
10. 所有领域判断须优先依据论文方法、结果、表格和补充材料；摘要及数据库元数据只支持其明确表达的内容。

## 一个完整虚构案例演示

**输入**：`case_id=DEMO-001`。问题为“成人膝骨关节炎患者中，运动疗法随机对照试验是否报告四周疼痛 NRS 结局”。纳入标准为年龄不低于 18 岁、随机对照设计、包含目标结局；非随机研究和未成年人研究排除。本地快照含五条原始记录，其中两条为同一篇 A 的 Crossref 与 EuropePMC 记录；另有一条 D 来自真实 retained reference graph 的“本文引用”边。D 全文因权限不可得。
