## 1. 任务本质与判分要点

### 1.1 任务本质

交付物不是“基金写作建议”，而是在每个未知案例上交付**可判分的写作题集**：可进入申请书/论文的
章节稿、七要素对照、逐句证据链和边界记录。正式运行只认 `/input` 中的实际材料与工作单；领域标签、
文件名和参赛者经验均**不能替代原文**。外部论文结论不等于申请人的前期成果，拟达到指标不等于已有数据。

### 1.2 判分要点（判分优先级）

1. **章节稿是否完整、合体裁**而非模板；
2. **事实、数字、引文、术语是否忠实**；
3. **七要素是否齐全**且目标—内容—路线—指标闭环；
4. **第三方能否按“段落—要素—证据”复核**；
5. **相同输入下是否比基础 Agent 更少漏项、无据论断和返工**。

效率与创新**必须由真实运行记录证明**，不得自填对照分数。参赛提交层另需 `SKILL.md`、实际依赖
资源、方法说明和标明“示例”的最小调用例；根目录 `GITHUB_URL.txt` 第一行应填可匿名访问的本作品链接。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 用政策口号和“意义重大”凑立项依据 | 写清“已有工作到哪一步—具体缺口—前期观察—为何现在可做—为何本团队可做” |
| 见到领域标签就补常见配方、性能或政策 | 只从实际文件抽取；材料外内容标“待确认”，不进入事实陈述 |
| 把所给论文写成“申请人已证实” | 分为“外部文献”“申请人已完成”“本研究拟开展”“无法确认”四类 |
| 使用“首次、国际领先、填补空白” | 指明与哪项代表工作在对象、变量、方法或证据上的差异 |
| 目标三条、路线两条，指标另起一套 | 用 Q/G/C/R/M 编号建立无孤儿映射，一对多时说明理由 |
| 只列作者年份或 DOI | 同时给文件名、页/节/表/图或文本行、逐字短引和核验状态 |
| 冲突数字取“更合理”的一个静默落稿 | 保留两种原文及定位，暂停相关强结论并请求人工确认 |
| 只交 `result.json`，或只交散文稿 | 同时交结构化状态、可编辑稿、映射表、缺口与修改记录 |
| 等全部写完才保存 | 尽早保存诚实的部分稿，再按审计结果增量修订 |

## 2. 求解框架（7 步法）

“冻结”指写入 `/app/work` 并计算哈希；后续修改另存版本并记录原因，不覆盖旧证据。所有正式产物
最终置于 `/app/output`。

| 步骤 | 动作 | 冻结产物 | 门控 |
|---|---|---|---|
| S0 解码任务 | 读 `case.json`、`task.md`、工作单、资源声明；原样提取 `case_id`、受众、体裁、篇幅、七要素 E1–E7、`output_contract` | `input_manifest.json`：文件 SHA-256、约束原文、来源清单 | 七要素不得自行猜名；必需字段和输入标识齐全；缺工作单即记录缺口并按明示任务产出部分稿 |
| S1 建立证据库 | 阅读真实 PDF/表格，不以文件名推断内容。每个原子事实建 V 卡：对象、条件、数值、单位、状态、来源、locator、逐字引文 | `evidence.jsonl`、`source_register.csv` | 每个数字和关键论断有 V 卡；PDF 页码用实际页序并另记印刷页码；找不到原文即“未核实” |
| S2 提炼论证 | 区分外部现状、瓶颈、前期观察和假设；列代表工作差异 | `rationale_map.md`、`comparison_table.csv` | “值得做、现在做、我们来做”各有证据或明确假设；无来源的新颖性判断删除 |
| S3 对齐计划 | 建科学问题 Q、目标 G、内容 C、路线 R、指标 M；路线写输入、方法、输出、判据、风险、备选 | `plan_matrix.csv` | 每个 G 至少一条完整 G–C–R–M 链，每个 C/R/M 均能回指 G；无无指标目标、无无路线内容 |
| S4 写作与映射 | 先写 clean 章节稿，再给段落 P 编号；把 P、E、V 和计划编号连接 | `chapter_draft.md`、`chapter_annotated.md`、`element_trace.csv` | E1–E7 全覆盖，厚度满足工作单；稿件不是提纲或写作建议；内部编号保留在审读版，不污染 clean 版 |
| S5 三重审计 | 分别做事实/来源审计、计划一致性审计、格式/语言审计；记录原句、改句、理由 | `audit_report.md`、`issues.csv`、`change_records.jsonl` | 新增材料外事实为 0；冲突不静默解决；已完成/拟开展逐处一致 |
| S6 封包复核 | 写 `result.json`，保留原契约全部字段、`case_id`、状态、来源、不确定性和修改记录；生成要求的可编辑文件与预览 | 正式输出包及验证记录 | JSON 可解析、路径存在、契约字段无缺失；Office/幻灯片/图示如有交付，附真实 PDF/PNG 预览并目检 |

900 秒预算下，优先保证“完整部分稿 + 证据表 + 有效 JSON”，再扩充论证和排版。工具不可用时保留
Markdown/CSV 主结果，明确预览或格式转换未完成，**不伪造软件状态**。

## 3. 量化口径与判定规则

1. **要素覆盖率** \(C_7=N_{\text{合格要素}}/7\times100\%\)。只有该要素成稿、满足规定子项且与其他
   要素衔接才算合格，空标题不计。目标恒为 \(7/7=100\%\)。
2. **事实支持率** \(R_s=N_{\text{有有效证据的事实陈述}}/N_{\text{全部事实陈述}}\times100\%\)。
   数字、引文、前期成果、政策、代表工作比较均计入；纯拟议目标不计事实分母，但必须有“拟”标记。
   目标 100%，**无据事实硬门槛为 0**。
3. **定位有效率** \(R_l=N_{\text{可打开且引文一致的定位}}/N_{\text{全部应定位的来源性陈述}}\times100\%\)。
   缺失定位也计入分母；有效 locator 至少含文件名及页/节/表/图之一，短引须逐字。推断可写
   “据 Vxx 推导”，不得伪装成原句。
4. **计划链覆盖率** \(R_c=N_{\text{具有完整 G–C–R–M 链的目标}}/N_{\text{全部目标}}\times100\%\)。
   另报孤儿数 \(N_o=\) 无目标的 C/R/M 数 + 无内容的 G 数 + 无路线的 C 数 + 无对应路线的 M 数 +
   无指标的 G 数；要求 \(R_c=100\%\)、\(N_o=0\)。一对多必须显式映射。
5. **状态准确率** \(R_t=N_{\text{状态标注正确句}}/N_{\text{状态敏感句}}\times100\%\)，目标 100%；
   尤其注意“已验证 / 初步观察 / 拟验证 / 预计达到”。
6. **数值复算**：百分数先化小数再相乘。若转化率为 \(X\)、目标产物选择性为 \(S\)，且二者基于相同
   进料与摩尔口径、化学计量为 1:1，则 \(Y=X\times S\)。提高多少用**百分点**：
   \(\Delta_{pp}=100(X_2-X_1)\)；相对提高为 \(\Delta_{rel}=(X_2-X_1)/X_1\times100\%\)，二者不可混写。
7. **重复性**：\(\bar{x}=\sum x_i/n\)，\(s=\left[\sum(x_i-\bar{x})^2/(n-1)\right]^{1/2}\)，
   \(RSD=s/\bar{x}\times100\%\)。同一溶液重复进样不等于独立制备重复；未给实验标准时不得宣称
   “波动可接受”。可接受波动只采用工作单、标准或原文阈值。
8. **波动与取整**：覆盖率、孤儿数等确定性检查重复运行应相差 0。复算与原文的差异允许量仅为末位
   取整，例如保留 1 位小数时绝对差不超过 0.05 个对应单位；超出即查单位、口径和转录，**不擅自改原值**。
9. **效率增益**：仅在平台同案同条件日志可得时计算 \(G_{\text{time}}=(T_{\text{基础}}-T_{\text{技能}})/T_{\text{基础}}\times100\%\)，
   同时报告人工改写条数和往返轮次。没有对照时间戳就写“未测”。

**计算示例**：三次独立批次转化率为 64.0%、65.0%、66.0%，则 \(\bar{x}=65.0\%\)、\(s=1.0\) 个百分点、
\(RSD=1.54\%\)。若选择性均值为 89.0%，则以均值估算 \(Y=0.650\times0.890=57.85\%\)；拟议目标
\(X\ge75.0\%\) 相对前期均值是提高 10.0 个百分点，而非“提高 10%”。

## 4. 领域知识清单

- **归因边界**：所给原论文和既有成果归外部作者；除非材料明确证明归属，不写“申请人提出/发现/建立”。
  真实申请人证据缺失时，应作为缺口，而非补造简历。
- **催化口径**：转化率、选择性、收率不可互换；不同温度、压力、空速、进料和平衡时间的性能不得
  直接排名。`%` 与百分点、质量分数与摩尔分数必须注明。
- **单位量纲**：`mol/L` 与 `mmol/L` 相差 \(10^3\)；`nm` 与 `μm` 相差 \(10^3\)；`kJ/mol` 与 `eV`
  不可直接比较。温度写 `°C` 或 `K`；压强区分表压/绝压；流量须说明是否标况。
- **催化速率**：GHSV/WHSV 通常为 `h⁻¹`，须写体积或质量基准；TOF 须写活性位点归一化方法和时间单位；
  STY 须写产物质量/摩尔数、催化剂基准及时间单位。
- **表征证据**：XPS 峰位或 XRD 峰变化不能单独“证实”氧空位及因果机制；DFT 是解释或预测，不等于
  实验验证。原位（in situ）与操作态（operando）不可随意互换。
- **实验设计**：`n` 要说明独立合成批次、平行反应还是重复表征；标准差 \(s\)、标准误 \(s/\sqrt n\) 和
  置信区间不可混用。拟议样本量不是已有重复数据。
- **创新表述**：代表文献不足时只能作限定比较，如“与材料中 L-01 的……相比”，不能由少量文献推出
  全球首创。
- **引文要求**：核对题名、作者、年份、期刊、DOI（若有）及其真正支持的论断；无法核实 DOI 时保留
  原始书目信息并标“未核实”，不得生成相似 DOI。
- **政策口径**：政策须给正式名称、发布机构、日期/文号及原文定位；案例未提供时不用“国家高度重视”
  等填充，也不把赛事工作单当现实资助政策。
- **目标数值**：性能阈值、样本量、进度和考核指标属于“拟达到”；可说明其相对前期值的差距，但不能
  写成必然实现或已有结果。

## 6. 完整虚构案例

> **以下全部来源与数据均为虚构，仅演示流程，不是正式案例结果。** 虚构工作单指定七要素依次为：
> E1 立项依据、E2 科学问题、E3 研究目标、E4 研究内容、E5 创新点、E6 技术路线、E7 研究基础与可行性；
> 真实运行仍须以实际工作单为准。

**输入。** `case_id=DEMO-CAT-01`，主题为糠醛选择性加氢。

- L-01（外部论文，第 4 页表 2）原文：“Cat-A 在 220 °C 下转化率 62.0%，糠醇选择性 88.0%。”
  第 6 页讨论原文：“尚未建立氧空位配位环境与羰基吸附构型的对应关系。”
- P-01（申请人实验记录，第 2 页表 1）原文：“Cat-B，220 °C，三次独立制备—评价批次，
  X=64.0/65.0/66.0%，S=88.5/89.0/89.5%。”
- P-02（平台记录，第 1 页）原文：“原位红外与固定床评价装置可用。”团队分工未提供。

**关键中间量。** 前期均值为 \(\bar{X}=65.0\%\)、\(\bar{S}=89.0\%\)，\(s_X=1.0\) 个百分点、
\(s_S=0.5\) 个百分点；同摩尔口径下平均收率约 \(57.85\%\)。拟议指标为 \(X\ge75.0\%\)、\(S\ge90.0\%\)，
对应收率下限 \(0.750\times0.900=67.50\%\)；相对前期均值，转化率和选择性分别拟提高 10.0、1.0
个百分点，收率下限提高 9.65 个百分点。计划矩阵为：

| 链 | 内容 | 路线输出与考核 |
|---|---|---|
| Q1–G1–C1–R1–M1 | 构建不同氧空位配位样品，联合原位红外与 DFT 解析羰基吸附 | 输出“配位环境—吸附构型—选择性”关系；M1 为至少三类可区分样品及一条经实验检验的关系，均为拟完成 |
| Q1–G2–C2–R2–M2 | 在统一评价条件下优化 Cat-B 并独立重复 | 输出最优样品及原始批次数据；M2 为 \(n\ge3\)，拟达到 \(X\ge75.0\%\)、\(S\ge90.0\%\)，报告 \(\bar{x}\pm s\) |

**输出章节稿（缩略但七要素完整）。**

- **E1 立项依据**：L-01 已报道 Cat-A 的活性与选择性，但其讨论明确指出氧空位配位环境—羰基吸附
  构型关系尚缺 [1]。申请人已完成 Cat-B 三次独立批次评价，均值为 65.0% 和 89.0% [2]，说明已有
  可重复研究的材料起点；上述数值本身不证明机理。因此，本研究拟把性能优化推进到可检验的界面
  配位机制。
- **E2 科学问题**：Q1 为“在 220 °C 统一评价边界内，Cat-B 的氧空位配位环境如何改变羰基吸附构型，
  并影响糠醇选择性？”研究不扩展至其他反应体系。
