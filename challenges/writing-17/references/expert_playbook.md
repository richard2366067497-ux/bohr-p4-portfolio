## 1. 任务本质与判分要点

### 1.1 任务本质

交付物**分两层，不能混为一谈**：

1. **参赛提交层**：交付可调用的 Skill，而非预制答案。`SKILL.md` 应写明触发条件、输入输出、执行
   流程、依赖和异常处理；脚本、模板、校验器及示例必须真实可用。
2. **案例运行层**：读取真实 `/input/case.json`、`task.md` 和原始材料，在 `/app/output` 交付指定
   主产物、可编辑源文件、真实预览、来源映射、不确定性和 `result.json`。**导图不能代替案例要求的
   主产物**（稿件/改稿/引用结果），但可作为其组织与证据层。

核心不是“图是否漂亮”，而是**抓得准、理得清、连得对、可追溯、可编辑、能复跑**。

### 1.2 判分要点（优先级从高到低）

1. **实际效果**：完整的、合体裁的主产物，而非提纲或图片；事实、数字、引用忠实。
2. **使用增益**：相同输入下相对基础 Agent 的改善**必须由平台对照或真实记录证明**，不能自述虚构。
3. **创新增益**：可运行的四向映射（材料—论断—图表—引用）、数值复算、缺项检测等。
4. **可靠体验**：空/坏/超限输入仍保存诚实部分结果，异常分类记录。
5. **生态贡献**：说明、脚本、模板、虚构示例可独立复用；GitHub 链接免登录可访问。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 根据文件名、领域标签猜论文内容 | 逐个读取实际文件；PDF 按真实页解析，解析失败单独标记 |
| 只交 PNG 或一张不可编辑的长图 | 交付可编辑导图/大纲、规范图数据及真实 PNG/PDF 预览 |
| 把每句话都做成节点 | 抽取原子事实，按研究问题、方法、证据、结论、风险和任务归并 |
| 为简洁省略数字条件、样本量或单位 | 关键数值保留原值、单位、条件和来源，细节放节点注释 |
| 把先后、相关或同现关系画成因果 | 边必须标注比较、支持、依赖、时间、引用、冲突等类型，并有证据 |
| 冲突数据取平均或选“看起来合理”的一个 | 并列保留原值，建立冲突节点和人工确认项 |
| 文末统一列参考文献，却无法定位节点 | 关键节点和关系逐项挂接 `evidence_id`、页码/段落/表行及逐字引文 |
| 把计算值、推断写成原文事实 | 区分 `fact`、`summary`、`calculation`、`inference`、`unknown` |
| 为显得完整而编造 DOI、页码、运行状态或提升比例 | 无法核验即留空并说明原因；无对照数据时增益记为 N/A |
| 最后才写结果，超时后没有可交付物 | 尽早保存诚实的 partial 版本，再增量完善 |

## 2. 求解框架（8 步法）

以下“冻结”表示形成可检查版本；后续修改必须记录原因和差异，而非静默覆盖。所有中间产物放
`/app/work`，正式产物放 `/app/output`。

| 步骤 | 操作 | 冻结产物 | 门控 |
|---|---|---|---|
| S1 契约解析与材料清点 | 读案例、任务说明、`output_contract`、受众、文体、格式和文件清单；检查运行依赖 | `contract.json`：`case_id`、必需字段、任务动作、材料清单、交付格式 | 每项任务要求均有对应输出位置；不得缺漏原契约字段。材料缺失、存在但不可读、格式不支持分别记录 |
| S2 建立来源登记册 | 对 PDF、Word、表格、图片和文本分配稳定 `source_id`；记录文件名、类型、页数、解析状态，必要时记 SHA-256。PDF 页码用从 1 开始的物理页，印刷页码另列 | `source_registry.json` | 所有实际使用材料均可定位；OCR 低置信内容不得冒充准确文本 |
| S3 抽取原子证据 | 每条证据保存：原值、单位、实验条件、逐字引文、定位符和适用范围。数值规范化另存，不覆盖原文 | `evidence.jsonl`：`evidence_id/source_id/locator/quote/value/unit/conditions/kind/status` | 任务涉及的结论、数字、图表和引用均有证据；找不到时明确标为材料不足 |
| S4 设计读者导向的层级 | 根节点表达读者要理解的问题或要做的决策，不简单照抄论文标题。二级分支按任务需要选择研究问题、方法、结果、局限、结论、风险和行动 | `outline_spec.json` 及初版 `outline.md` | 每个必需任务项至少映射一个分支；同级节点粒度一致，分类不交叉，重要证据不被埋在过深层级 |
| S5 构建“树＋语义边”双层图 | 主树每个非根节点只有一个父节点；因果、对比、依赖、支持和冲突作为独立语义边，避免用交叉树杈表达所有关系 | `graph.json`：节点含 `id/label/parent/type/evidence_ids/note`，边含 `source/target/relation/evidence_ids/status` | 无孤儿、无父节点环、无重复 ID；推断边必须标为推断，无证据关系不得进入正式图 |
| S6 校验、压缩与布局 | 先校验事实，再调整文字和布局。细节过多时采用“主图＋分图/节点注释”，不得删除必需证据 | `checks.json`、候选图和校验日志 | 必需项覆盖率、关键证据挂接率、数值准确率达到 §3 要求；无文字重叠、裁切和不可读边标签 |
| S7 生成可编辑主产物与真实预览 | 交付可编辑文件（如 `.mm`/`.opml`）、缩进 Markdown 和规范图数据；用实际可用渲染器生成 PNG/PDF 并打开检查 | 主产物、预览、证据映射和版本说明 | 可编辑文件能被解析，预览确实由当前版本生成；仅有空文件、扩展名改名或截图不算完成 |
| S8 封装结果并保留恢复入口 | 写 `/app/output/result.json`，保留原契约全部字段和 `case_id`，填入真实状态、路径、来源、不确定性和修改记录 | `result.json` | JSON 可解析，引用文件均存在，路径有效。运行到约三分之一预算时应已有 partial 主产物 |

## 3. 量化口径与判定规则

以下为 Skill 的内部质量门控，**不冒充官方评分公式**。

| 指标 | 定义与公式 | 建议门控 |
|---|---|---|
| 必需项覆盖率 | \(C=N_{\text{已覆盖必需项}}/N_{\text{全部必需项}}\times100\%\) | 100%；例如 12 项覆盖 11 项仅为 91.7%，必须补齐 |
| 关键证据可追溯率 | \(T=N_{\text{定位及引文有效的关键节点和边}}/N_{\text{关键节点和边总数}}\times100\%\) | 100% |
| 数值准确率 | \(A=N_{\text{原值、单位、条件及计算均正确的数值项}}/N_{\text{数值项总数}}\times100\%\) | 100%；原始转录不允许误差 |
| 无依据关系率 | \(U=N_{\text{无证据或方向错误的边}}/N_{\text{语义边总数}}\times100\%\) | 0% |
| 重复节点率 | \(D=N_{\text{语义重复且未合并的节点}}/N_{\text{节点总数}}\times100\%\) | 宜 ≤2%，孤儿节点为 0 |
| 重复运行稳定性 | 三次运行分别计算覆盖率、错误数和成功状态 | 目标 3/3 可交付；核心事实不得随批次消失 |
| 效率 | 记录耗时 \(T\)/秒、模型请求数 \(R\)/次、人工修改项 \(H\)/项 | 只记录实测值；对照条件不一致时不算增益 |

若平台提供同条件基础 Agent 数据，可计算耗时增益
\(G_T=(T_{\text{base}}-T_{\text{skill}})/T_{\text{base}}\times100\%\)，否则写“未测量”，**不得自行编造**。

**软约束**：主图通常控制在约 25–60 个节点、深度宜不超过 5 层、单分支优先 3–7 个同级节点；
材料要求更多内容时优先拆分子图。重复运行的布局坐标可以变化，但节点 ID、关键事实、来源和关系方向
不应变化。派生值统一规定舍入位，末位允许的正常舍入误差不超过 0.5 个末位单位；**原始数值和单位
不适用“波动容差”**。

## 4. 领域知识清单

- **产率、转化率、选择性不可互换**：必须采用材料给出的定义和基准。质量产率、摩尔产率、分离产率
  不能混算。
- **百分数与百分点不同**：86%−72%=14 个百分点；相对增幅为 \(14/72=19.4\%\)。标准差若以产率百分数
  计算，单位也应写“百分点”。
- **温度换算**：\(T/\mathrm{K}=t/^\circ\mathrm{C}+273.15\)；温差 1 °C 与 1 K 数值相等，但绝对温度
  不能直接写成相同数值。
- **尺度与浓度**：1 μm=1000 nm；wt% 是质量分数，vol% 是体积分数；mol/L 是物质的量浓度，mol/kg
  是质量摩尔浓度。
- **设备条件不可直接等同**：转速 rpm 不是线速度；缺少反应器几何参数时不得推算剪切或混合相似性。
  表压与绝压也不得混淆。
- **粒径指标不可混称**：D50、数均粒径、体积加权粒径及显微图测量均值不是同一指标；测量方法必须
  随结果保留。
- **重复与误差**：技术重复不能自动当作独立批次；mean±SD 与 mean±SEM 不得互改，样本量 \(n\) 必须保留。
- **受控实验也不自动证明机制**：可以写“在本材料实验条件下观察到”，不能擅自补充晶粒长大、反应
  机理或最优工艺结论。
- **禁止用领域常识改写原始事实**：看似异常的数值也应先保留并标记核实，而不是“修正”为常见范围。
- **文献依据必须可核验**：优先使用案例材料；允许外部知识时单独登记来源。DOI 不能替代具体页码、
  表行或图号，不得编造引文、页码和逐字引用。

## 6. 完整虚构案例

> 以下仅演示方法，不是正式测试案例或预置答案。

**输入任务**：`case_id=DEMO-TIO2-001`。面向工艺工程师，将材料整理为可编辑证据导图，比较温度对
水热 TiO₂ 粒径和产率的影响；所有数字保留来源，冲突不得擅自裁决。

**虚构材料**：

- `S1，第1页第2段`：“设置 120、160、200 °C 三组，每组 3 个独立批次，其余条件相同；反应 12 h。”
- `S1，第2页表1`：“粒径为平均值，产率为干基质量产率。”

| 温度 | 平均粒径 | 平均产率 |
|---|---:|---:|
| 120 °C | 18 nm | 72% |
| 160 °C | 25 nm | 86% |
| 200 °C | 41 nm | 84% |

- `S1，第2页表1脚注`：“160 °C 三批产率分别为 84%、86%、88%。”
- `S2，第1页第1段`：“200 °C 组平均产率记为 91%；原始称量表未附。”

**关键中间量**：

1. 建立证据 `F01`：实验设计，定位 `S1:p1:¶2`。
2. 建立 `F02/F03/F04`：三行结果，分别定位 `S1:p2:Table1:row120/160/200`。
3. 建立 `F05`：200 °C 的 84% 与 91% 冲突，连接两个来源，状态为 `unresolved`。
4. 160 °C 产率均值及样本标准差：

\[
\bar{y}=(84+86+88)/3=86.0\%,\qquad
s=\sqrt{\frac{(-2)^2+0^2+2^2}{3-1}}=2.0\ \text{个百分点}
\]

5. 120→160 °C 粒径相对变化：\((25-18)/18\times100\%=38.9\%\)。
6. 产率增加 \(86-72=14.0\) 个百分点，相对增加 \(14/72\times100\%=19.4\%\)。
7. 200 °C 两个产率记录相差 \(91-84=7.0\) 个百分点；**不得平均成 87.5%**。

**导图主结果示意**：

```text
温度对水热 TiO₂ 粒径与产率的影响
├─ 实验设计：三组温度；n=3 独立批次；12 h [F01]
├─ 原始结果
│  ├─ 120 °C：18 nm；72% [F02]
│  ├─ 160 °C：25 nm；86% [F03]
│  └─ 200 °C：41 nm；84% [F04]
├─ 派生比较〔calculation〕
│  ├─ 120→160 °C：粒径 +38.9% [C01←F02,F03]
│  └─ 120→160 °C：产率 +14.0 个百分点；相对 +19.4% [C02]
├─ 暂定候选：160 °C〔inference，不作全局最优结论〕
└─ 冲突与待办
   └─ 200 °C 产率：84% vs 91%；需原始称量表 [F04,F05]
```

其中只建立有依据的“比较”和“冲突”边，**不添加“升温通过某机理导致粒径增大”等材料外因果边**。
若任务清单包含设计、三组结果、粒径比较、产率比较和冲突处理共 7 项，则覆盖率为 \(7/7=100\%\)；
三条派生/冲突关系均有依据，无依据关系率为 \(0/3=0\%\)。

**输出状态**：可交付 `mindmap.mm`、`outline.md`、`graph.json`、真实 PNG/PDF 预览和
`evidence_map.jsonl`。`result.json` 可按契约定为 `completed`，同时保留 `U01=unresolved`，因为指定
任务已完成而科学冲突仍存在；若任务强制要求唯一最优温度，则应为 `partial`，说明无法判断的原因。

复算命令：

```bash
python - <<'PY'
from statistics import mean, stdev
y = [84, 86, 88]
print(f"mean={mean(y):.1f}%, s={stdev(y):.1f} percentage points")
print(f"diameter_change={(25-18)/18*100:.1f}%")
print(f"yield_delta={86-72:.1f} percentage points")
print(f"yield_relative={(86-72)/72*100:.1f}%")
print(f"conflict_delta={91-84:.1f} percentage points")
PY
```

预期依次得到：`86.0%`、`2.0` 个百分点、`38.9%`、`14.0` 个百分点、`19.4%`、`7.0` 个百分点。
