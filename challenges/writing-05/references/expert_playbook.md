## 1. 任务本质与判分要点

### 1.1 任务本质

交付物不是一篇通用综述，而是一个可独立复核的 **“论断清单—证据表—规范成稿”** 闭环：
材料/化学工艺案例只是演示载体，真正被检验的是“每一句实质判断能否被指认到具体来源、
具体位置、具体强度”。写得多不等于写得好；不可回查的句子是负债。

### 1.2 判分要点（优先级从高到低）

1. **完成指定动作**：体裁、受众、语言、篇幅、修改或格式要求均服从 `task.md` 与 `case.json`；
   不能用通用综述代替指定产物。
2. **证据真实且支持原句**：文献存在不等于证据有效；原文必须支持论断的对象、条件、方向、
   数值和强度。
3. **四类要素完整**：论断、来源、证据强度、不确定性均须显式呈现。
4. **可以回查**：有稳定编号、逐字摘录、页码/章节/段落定位、判定理由和复算过程。
5. **异常诚实**：材料缺失、无法判断、运行失败分别记录；不得补造文献、实验数据、
   软件状态或对照增益。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 先写成流畅成稿，再补几个看似相关的引用 | 先切分原子论断并绑定证据，再按允许的证据边界成稿 |
| 只读摘要，把“摘要提到”当成“全文证实” | 标记 `abstract_only`；可获取全文时核对方法、结果和限制 |
| DOI 可解析便判定引用正确 | 另核对标题、作者、年份、版本及原文对具体论断的支持范围 |
| 将“相关”“伴随”改写为“导致”“证明机制” | 保留研究设计允许的因果层级；机制未明处明确写出 |
| 将单篇三重复实验写成“行业共识” | 限定为该研究、该规模和该实验条件内的结果 |
| 一条文献支撑整段所有句子 | 将数字、比较、机制、外推分别编号并逐条映射 |
| 隐瞒原文与摘要、不同文献之间的冲突 | 双方摘录并列，降低结论强度或转人工确认 |
| 把产率、转化率、选择性混用 | 按原文定义分别转述，复算时写出计量假设 |
| unsupported 内容直接删除且不留痕 | 从成稿排除，同时在 `human_review.json` 和修改记录中说明 |
| 材料缺失、证据不足、程序异常均记为 `failed` | 分别使用材料缺口、需人工确认、运行失败等状态；保留部分成果 |
| 用手册中的固定 JSON 字段替代原题字段 | 保留全部原始 `output_contract` 字段及 `case_id`，扩展字段另加 |
| 把三个案例的预制答案塞进 Skill | 只放流程、模板、校验规则和明确标注的虚构示例 |

## 2. 求解框架（6 步法）

以下步骤均应保存中间产物；门控未通过时，不得用后续文字润色掩盖问题。

| 步骤 | 动作 | 冻结产物 | 门控 |
|---|---|---|---|
| S1 读取任务与登记输入 | 读取 `/input/case.json`、`task.md`、`environment/resources.yaml`，枚举实际文件 | 输入清单：标识、文件名、SHA-256、文件类型、动作、受众、格式、原始输出字段 | 所有输入均有读取状态；输出合同无遗漏 |
| S2 解析全文并建立来源登记册 | 优先全文；PDF 乱码时渲染页面或 OCR，不把乱码当可靠摘录 | 来源登记册：来源类型、版本、可得性、元数据核验状态、页码/印刷页、章节、段落、表图号、逐字摘录 | 每条摘录能在对应来源中按原文找回；否则标“定位未核验” |
| S3 切分原子论断 | 将任务要求与拟写内容拆为 `C001…`；一个论断只含一个主要可判定命题 | 论断清单：论断文本、类型、是否必须、拟用限定语 | 无“性能优异”“机理明确”等不可判定措辞；复合句已拆开 |
| S4 匹配证据并判定支持范围 | 每条论断关联一个或多个 `E###`，支持关系取 `full / partial / contradicts / context_only` | 证据表：研究设计、样本量、直接性、独立重复、适用范围、冲突、判定理由 | 所有实质论断有有效证据，或被排除并转人工；背景引用不能冒充直接证据 |
| S5 生成成稿与修改记录 | 按指定文体组织内容，措辞强度不高于证据等级；改写任务保留“原文—修改后—理由” | 成稿、逐句引用编号、修改记录、排除项留痕 | 不新增材料外事实；引用编号、论断编号、证据表可双向追踪 |
| S6 独立核验与交付 | 复算数字，检查单位、显著数字、参考文献一致性、冲突披露和引用回跳 | `verification.json`、`diff_report.md`、`human_review.json`、`result.json` | 重新打开交付文件、解析 JSON；失败则保留部分产物并写明限制 |

**时间预算**：首轮即保存诚实的 `partial` 结果，再逐步增强；预算末段至少预留约 10% 做核验。

**映射到本 Skill 产物**

| 步骤 | 对应产物 |
|---|---|
| S1 | `result.json`（`case_id`、`output_contract`、`sources`、`degradations`、`runtime`） |
| S2 | `evidence_table.json` 中的 `source_id / locator / quote`；`reference_check.md` |
| S3 | `claims.json`（`claim_id`、正文、类型、定位） |
| S4 | `evidence_table.json`（`support_scope / strength / conflicts / rationale / verified`）、`evidence_strength.md` |

## 3. 量化口径与判定规则

### 3.1 内部证据等级

该等级是本 Skill 的操作口径，不冒充领域统一标准，也不将等级转换为貌似精确的总分。

- **G3**：多个独立、直接且一致的证据，或适用范围内的高质量共识。
- **G2**：可检查全文的单项直接原始研究；结论限于其样本与条件。
- **G1**：仅摘要、间接证据、二手转引或存在未解决冲突；只能保守表述。
- **G0**：无有效来源或来源不支持；不得作为事实进入正文。

### 3.2 质量指标

设成稿实质性论断数为 \(N\)，有效关联论断数为 \(N_l\)，可独立回查数为 \(N_t\)，过度推断数为 \(N_o\)：

\[
R_{\mathrm{cov}}=\frac{N_l}{N}\times100\%,\qquad
R_{\mathrm{trace}}=\frac{N_t}{N}\times100\%,\qquad
R_{\mathrm{over}}=\frac{N_o}{N}\times100\%.
\]

目标分别为 **100%、100%、0%**。另设：

\[
R_{\mathrm{num}}=\frac{N_{\mathrm{复算通过}}}{N_{\mathrm{数值论断}}}\times100\%,\qquad
R_{\mathrm{conf}}=\frac{N_{\mathrm{已披露冲突}}}{N_{\mathrm{已发现冲突}}}\times100\%.
\]

分母为零时填 `null`，不得填 100%。被排除的无证据要求进入修改记录，不通过缩小 \(N\) 隐藏。

### 3.3 数字与允许偏差

- 百分比变化与百分点必须区分：84.0% 相对 72.0% 是 **增加 12.0 个百分点**，相对增幅为
  \(12/72\times100\%=16.7\%\)。
- 显示值保留一位小数时，复算显示容差可设为末位半个单位，即 **0.05**；这只是显示容差，
  不是实验重复性或允许修改原始值的理由。
- 原始冲突值不得平均。摘录仅允许空白归一化，不得静默修正符号、上下标或数字。
- 样本标准差使用 \(n-1\)；SD、SEM 和置信区间不得互换。

### 3.4 措辞强度分级

| 证据状态 | 允许措辞 | 禁止措辞 |
|---|---|---|
| 多项独立一致证据 | “一致表明”“在该条件下支持” | “普遍证明”“行业定论” |
| 单项直接原始研究 | “该研究报告了”“在其样本内观察到” | “已证实”“适用于所有体系” |
| 仅摘要/间接/二手 | “摘要提示”“据转引” | “全文证实”“机制明确” |
| 冲突未解决 | “存在不一致报告”“尚待确认” | 任选一方当作事实 |
| 无有效来源 | 从正文删除并登记 | 任何事实性断言 |

## 4. 领域知识清单

1. **温度**：Arrhenius 计算必须使用 K，\(T/\mathrm{K}=t/^\circ\mathrm{C}+273.15\)。摄氏温差与
   开尔文温差数值相同，但不宜用摄氏温度计算“相对升高百分比”。
2. **浓度与用量**：\(c=n/V\)，1 mL = \(10^{-3}\) L；“加入 25 mL 溶剂”不必然等于最终体积 25 mL。
3. **百分数**：wt%、vol%、mol%、at% 不可互换；稀水溶液中 mg/L 近似 ppm 的条件必须说明，
   固体中通常按 mg/kg 理解。
4. **工艺指标**：转化率、选择性、产率不是同义词。仅在定义与计量一致时可写 \(Y=X\times S\)；
   分离产率还需明确 limiting reagent 和理论产量。
5. **归一化**：催化速率按催化剂质量、活性位或面积归一化会得到不同单位；m²/g、mA/cm²、
   mmol/(g·h) 不可省略或混写。
6. **表征边界**：观察到目标 XRD 峰不自动证明物相纯净；单一表征通常不足以确认价态、结构
   或因果机制。
7. **统计**：三次平行测定不自动等于三次独立实验；不得把 SD 当作误差来源的完整解释，
   无统计检验不得声称“显著”。
8. **文献依据**：优先原始研究支撑实验数字和机制；综述用于背景与线索。预印本、撤稿、
   版本差异、补充材料和二手转引必须标注。
9. **外推边界**：烧瓶或 20–50 g 实验结果不能直接外推到连续生产线；规模、时间、设备和
   原料批次均是适用条件。

## 6. 完整虚构案例

> 以下文献、数据和引文均为演示虚构，不得作为真实科研事实使用。

### 6.1 输入

任务：依据两篇虚构材料写一份面向工艺工程师的简报，并交付论断—证据表。

- **S1，虚构原始研究，PDF 第 3 页，§2.1**：
  “25.0 mL、0.400 mol/L 前驱液在 1:1 计量假设下理论生成产物 P（M = 100.0 g/mol）。”
- **S1，PDF 第 4 页，表 2**：
  “180 °C 组三次独立实验的产物质量为 0.800、0.840、0.880 g；160 °C 组为 0.680、0.720、0.760 g。”
- **S1，PDF 第 5 页，§4**：
  “结果仅来自 20–50 g 实验室规模，尚未验证连续生产。”
- **S2，虚构原始研究，PDF 第 2 页摘要**：
  “180 °C 样品中观察到目标相的衍射峰。”
- **S2，PDF 第 6 页，§3.1**：
  “在 2θ = 28.5° 附近存在一个未归属弱峰。”
- 用户另要求写“180 °C 是连续生产线通用最优温度”，但材料没有该证据。

### 6.2 关键中间量与复算

\[
V=25.0\ \mathrm{mL}=0.0250\ \mathrm{L}
\]

\[
n=cV=0.400\ \mathrm{mol/L}\times0.0250\ \mathrm{L}
=0.0100\ \mathrm{mol}=10.0\ \mathrm{mmol}
\]

按 1:1 计量：

\[
m_{\mathrm{theory}}=nM=0.0100\ \mathrm{mol}\times100.0\ \mathrm{g/mol}
=1.00\ \mathrm{g}
\]

180 °C 组产率为 80.0%、84.0%、88.0%，故：

\[
\bar Y=84.0\%,\qquad
s=\sqrt{\frac{(-4.0)^2+0^2+(4.0)^2}{3-1}}
=4.0\ \text{个百分点}
\]

160 °C 组平均产率为 72.0%，所以绝对差为：

\[
84.0\%-72.0\%=12.0\ \text{个百分点}
\]

相对增幅为：

\[
\frac{84.0-72.0}{72.0}\times100\%=16.7\%
\]

### 6.3 论断—证据表摘录

| 论断 | 证据与定位 | 等级及处理 |
|---|---|---|
| C001：前驱体为 10.0 mmol | S1，第 3 页 §2.1，逐字引文；CALC01 | G2，计算论断 |
| C002：理论产量为 1.00 g | 同一引文；CALC02，明确 1:1 假设 | G2，不写成实际产量 |
| C003：180 °C 平均产率 84.0%，SD 4.0 个百分点，n=3 | S1，第 4 页表 2；CALC03 | G2，限定三次独立实验 |
| C004：较 160 °C 高 12.0 个百分点，相对增幅 16.7% | S1，第 4 页表 2；CALC04 | G2，不写“提高 12%” |
| C005：连续生产尚未验证 | S1，第 5 页 §4 逐字引文 | G2，保留规模边界 |
| C006：存在目标相峰，但物相纯度仍待确认 | S2，第 2 页摘要及第 6 页 §3.1 两条引文 | G1，披露未归属弱峰，不写“纯相” |

“连续生产线通用最优温度”记为 `X001/G0`，从成稿排除并列入人工确认，
不得用 S1 的实验室结果替代证据。

### 6.4 输出成稿示例

在 25.0 mL、0.400 mol/L 前驱液及 1:1 计量假设下，前驱体为 10.0 mmol，产物 P 的理论产量为
1.00 g[1]。180 °C 组三次独立实验的平均分离产率为 84.0%，SD 为 4.0 个百分点；与 160 °C 组的
72.0% 相比，高 12.0 个百分点，相对增幅为 16.7%[1]。这些结果仅来自 20–50 g 实验室规模，
连续生产尚未验证[1]。S2 观察到目标相衍射峰，但全文另报告一个未归属弱峰，因此不能据此认定
物相纯净[2]。

本次成稿 \(N=6\)，六条均有定位和复算或判定理由，因此 \(R_{\mathrm{cov}}=100\%\)、
\(R_{\mathrm{trace}}=100\%\)；四条数值论断全部复算通过，\(R_{\mathrm{num}}=100\%\)；
发现的一处证据冲突已披露，\(R_{\mathrm{conf}}=100\%\)；无证据的“通用最优”未进入正文，
\(R_{\mathrm{over}}=0\)。这些数字只证明该虚构示例内部一致，不代表平台正式得分或相对其他
Agent 的增益。
