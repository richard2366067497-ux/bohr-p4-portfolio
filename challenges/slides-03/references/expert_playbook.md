# 专家参考手册 —— 学术汇报幻灯片生成（论文材料 → 可编辑演示文稿）（slides-03）

## 1. 交付什么（判分要点）

任务是把固定论文或研究材料组织成**结构清楚、证据可追溯、可编辑并符合模板要求的学术汇报产物**。交付物不是"论文压缩版"，而是面向指定听众、时长、页数约束的**可上台讲述的页面序列 + 讲稿/备注 + 页级证据映射 + 渲染版本记录**。

验收从五个维度核验：

1. **实际效果**：报告目标、听众定位、叙事顺序、逐页重点信息与问答准备是否形成闭环；页面科学内容、数字、图表引用是否与源材料一致；是否覆盖论文主线、页结构、图表引用、讲解逻辑、模板约束、导出渲染六个方面；从源材料到成稿的取舍能否被独立复核。
2. **使用增益**：相同输入下，采用结构化方法后相比无方法的直接输出，是否提升汇报内容组织质量、减少人工修改量、返工页数与导出修正次数，并能通过公平对照证明。
3. **方法增益**：是否具备听众适配、页级规划、问答预演能力；叙事模板、内容取舍规则、图表引用绑定、模板约束与导出处理是否带来实质改进。
4. **可靠体验**：能否在合适时机触发，按说明完成一次完整生成；在不同汇报类型、源材料长度与重复运行下稳定产出；对缺图、分辨率不足、公式丢失、模板冲突、字体缺失、导出失败、超时等异常有识别与处置。
5. **可复用性**：文档、依赖、模板、导出设置、示例、适用范围与维护信息齐全；题集、页级金标准、叙事模板、模板文件、导出脚本可复用；沉淀可分享的汇报案例与经验。

核心原则：**页面唯一主张、证据逐页可回溯、渲染结果可复核**。

## 2. 分步流程与门控

从输入材料到交付物的分步流程，每步有冻结产物与门控标准。

### 第 1 步：输入解析与约束提取

**输入**：`/input/case.json`、`/input/task.md`、实际论文 PDF/材料文件、模板文件（如有）。

**冻结产物**：
- `input_manifest.json`：记录 case_id、源文件路径、页数、图表数量、公式数量、任务约束（听众、时长、页数、模板要求）。
- `constraints.json`：提取的硬约束（页数上限、模板路径、必须使用的图表、禁止修改的内容）和软约束（听众偏好、时长弹性）。

**门控**：必须实际读取文件内容，不得依据标签或文件名假设源材料内容；若 PDF 解析失败或图表缺失，记录异常并降级处理。

### 第 2 步：报告目标与听众建模

**冻结产物**：
- `audience_profile.json`：听众类型、先验知识、关注点、可能质疑。
- `report_goal.json`：本次汇报要达成的可检查目标（如"让评审认可方法新颖性""让合作者理解进度风险"）。

**门控**：目标必须可检查，不能是"讲清楚论文"这类空泛表述；听众定位必须影响后续页数分配和术语解释深度。

### 第 3 步：主线提取与页级规划

**冻结产物**：
- `narrative_outline.json`：叙事顺序（问题—方法—结果—结论—问答），每页一个主主张，标注证据强度。
- `page_plan.json`：每页的标题、主主张、支撑点、图表引用、讲稿要点、预计时长。

**门控**：
- 页数 = 时长 / 每页平均讲述时间（建议 0.75–1.5 分钟/页，根据听众调整）。
- 每页主主张数 = 1；支撑点 ≤ 2。
- 每个主主张必须有源材料定位（locator）或明确标注"综合推断"。

### 第 4 步：内容生成与证据绑定

**冻结产物**：
- `slides_content.json`：每页的标题、正文、图表占位符、公式、备注/讲稿。
- `evidence_map.json`：每页内容对应论文图、表、章节、公式、数据的具体定位。

**门控**：
- 图表引用编号与源材料一致，错误数 = 0。
- 公式符号与源材料一致，无丢失。
- 单位与源材料一致，无混用。
- 讲稿字数 ≈ 语速 × 时长（中文口头汇报 120–160 字/分钟）。

### 第 5 步：模板应用与渲染导出

**冻结产物**：
- 可编辑 PPTX 文件（使用模板母版）。
- 导出 PDF/PNG 预览。
- `render_report.json`：记录导出命令、页数、字体嵌入、溢出检查结果。

**门控**：
- PDF 页数与 PPTX 页数一致。
- 字体嵌入率 100%。
- 无文本溢出（可通过渲染预览人工或自动检查）。
- 母版合规（标题、页脚、页码位置正确）。

### 第 6 步：问答准备与不确定性标注

**冻结产物**：
- `qa_prep.json`：每页预判 1–2 个追问，准备回答要点或备用页引用。
- `uncertainty.json`：记录证据强度、缺失信息、推断内容。

**门控**：每个主主张必须有证据强度标注；推断内容必须与源材料中的确切表述区分。

### 第 7 步：最终交付与自检

**冻结产物**：
- `/app/output/result.json`：包含 case_id、状态、来源、不确定性、修改记录、输出文件清单。
- 所有可编辑文件和预览文件。

**门控**：result.json 字段完整，输出文件可打开、可编辑、可复核；部分失败必须诚实标注限制。

## 3. 量化口径、公式与容差

### 关键指标定义与公式

| 指标 | 定义 | 公式 | 单位 | 可接受波动 |
|---|---|---|---|---|
| 页数预算 P | 根据总时长和每页平均讲述时间计算 | P = ceil(T / t_page) | 页 | ±1 页 |
| 每页平均讲述时间 t_page | 总时长 / 实际页数 | t_page = T / P | 分钟/页 | 0.75–1.5 |
| 讲稿总字数 W | 语速 × 时长 | W = r × T | 字 | ±10% |
| 语速 r | 中文口头汇报语速 | r = 120–160 | 字/分钟 | 固定范围 |
| 每页备注字数 w_page | 讲稿总字数 / 有效内容页数 | w_page = W / (P − 封面页 − 致谢页) | 字/页 | 80–150 |
| 主张证据覆盖率 C | 有 locator 的主张数 / 总主张数 | C = N_located / N_total | % | ≥ 95% |
| 主张精确定位率 A | 精确 locator（图/表/公式/章节）数 / 总主张数 | A = N_exact / N_total | % | ≥ 80% |
| 图表引用错误数 E | 图表编号与源材料不一致的数量 | E = count(错误引用) | 个 | 0 |
| 公式符号丢失数 F | 公式符号与源材料不一致或丢失的数量 | F = count(符号问题) | 个 | 0 |
| 渲染页数一致性 | PDF 页数 − PPTX 页数 | ΔP = P_pdf − P_pptx | 页 | 0 |
| 字体嵌入率 | 嵌入字体数 / 总字体数 | R_font = N_embedded / N_total_fonts | % | 100% |

### 计算示例（数字自洽）

**输入**：总时长 T = 8 分钟，页数约束 P = 10 页（含封面 1 页、致谢 1 页），语速 r = 140 字/分钟。

**计算**：
- 有效内容页数 = 10 − 2 = 8 页。
- 每页平均讲述时间 t_page = 8 / 10 = 0.8 分钟/页（48 秒/页），在建议范围内。
- 讲稿总字数 W = 140 × 8 = 1120 字。
- 每页备注字数 w_page = 1120 / 8 = 140 字/页，在 80–150 范围内。
- 假设提取 8 个主主张，其中 7 个有精确 locator（图 2b、图 3a、表 1、第 3.1 节、公式 (2) 等），1 个为综合推断（标注"综合图 4 与图 5，中等强度"）。
- 主张证据覆盖率 C = 8/8 = 100%。
- 主张精确定位率 A = 7/8 = 87.5%。
- 图表引用错误数 E = 0。
- 渲染：导出 PDF 10 页，字体嵌入率 100%，无溢出。

**结论**：该方案满足所有门控标准。

## 4. 领域陷阱与事实性错误（错误做法→正确做法）

| 错误做法 | 正确做法 |
|---|---|
| 把摘要和 Results 逐段搬成页面，页数与讲述时长脱节 | 先根据听众、时长、页数预算确定每页唯一主张，再按叙事顺序分配内容 |
| 图表与页内结论不对应，图表编号错位 | 每页图表引用必须直接支撑该页主主张；从源材料提取时保留原始编号，渲染后逐项核对 |
| 公式和引用编号错位，符号丢失 | 使用源材料中的原始公式编号和符号，导出后检查公式渲染，必要时转为图片或 Unicode |
| 讲解备注缺失或与页面重复 | 备注为口语化讲稿，与页面文字互补：页面给结论，备注给解释、过渡和问答提示 |
| 导出后字体、配色、母版不合规 | 使用模板母版，导出 PDF 预览，检查字体嵌入、文本溢出、页数一致性 |
| 被追问时没有任何准备 | 每页预判 1–2 个可能追问，准备备用页或回答要点，并在备注中标注证据强度 |
| 证据强度误标（把"可能"写成"证明"） | 按源材料表述标注证据强度：强/中/弱/推测，并在证据映射中记录依据 |
| 忽略听众先验知识，术语解释过多或过少 | 识别听众类型（同行专家/跨学科/评审委员会），决定背景铺垫比例和术语解释范围 |
| 只生成 PPTX，不导出 PDF 预览 | 同时导出 PDF/PNG 预览，供检查渲染效果和版式 |
| result.json 只写成功，不写不确定性 | 诚实标注状态、来源、不确定性、修改记录和失败限制 |

### 本领域容易犯的事实性错误

1. **图表编号错位**：源材料中图 2 被引用为图 3，或子图编号（a/b/c）丢失。必须从源材料原文提取编号，渲染后逐项核对。
2. **公式符号丢失或变形**：PDF 解析时公式可能丢失上下标、希腊字母、特殊符号。应保留原始公式截图或使用 Unicode/LaTeX 渲染，并在备注中说明。
3. **单位混用**：常见单位有 eV、kcal/mol、kJ/mol、nm、mA cm⁻²、V、Wh kg⁻¹ 等。必须与源材料一致，不能自行换算或混用。换算关系：1 eV = 96.485 kJ/mol = 23.06 kcal/mol；1 kcal/mol = 4.184 kJ/mol。
4. **证据强度误标**：把"可能""提示""表明"写成"证明""证实"。必须按源材料表述标注：强（原文明确数据支持）、中（多图综合）、弱（单一观察）、推测（作者讨论）。
5. **术语解释不当**：对跨学科听众使用过多专业术语而不解释，或对同行专家解释基础概念。应根据听众先验知识调整。
6. **忽略图表分辨率**：源材料中图表分辨率不足，直接放大导致模糊。应标注"源图分辨率不足，建议替换"或使用矢量图。
7. **引用编号错位**：参考文献编号与源材料不一致。应保留源材料中的原始编号，不重新编号。
8. **页脚/页码与母版冲突**：使用模板时，页脚或页码被内容覆盖或位置错误。应使用母版占位符，不手动添加页码。

### 单位/量纲陷阱

- **能量单位**：eV、kcal/mol、kJ/mol 不可混用。若源材料用 eV，汇报中也用 eV，不换算。
- **电流密度**：mA cm⁻² 与 A m⁻² 不同，注意上标格式。
- **比容量/能量密度**：Wh kg⁻¹ 与 mAh g⁻¹ 不同，不可直接比较。
- **温度**：K 与 °C 不可混用，注意源材料中的单位。
- **浓度**：mol L⁻¹、M、mM 需一致，注意大小写。

### 文献依据要求

- 每个事实性论断必须有源材料定位（locator），格式建议：`[图2b]`、`[表1]`、`[第3.2节]`、`[公式(2)]`、`[第5页第2段]`。
- 若源材料中未明确，需标注"源材料未提供"或"综合推断"，不得补造数据。
- 不得引用外部未提供文献；若需背景知识，标注"背景知识，非源材料内容"。

## 5. 交付物、证据与 locator

### 应交付文件/章节

| 文件/章节 | 内容 | 自证可核验方式 |
|---|---|---|
| `SKILL.md` | 用途、适用条件、调用方式、输入输出、异常处理 | 说明与提交版本一致，可独立使用 |
| `references/expert_playbook.md` | 本手册 | 包含量化口径、门控标准、自查表 |
| 可编辑演示文件（PPTX） | 页级结构、主张、图表、讲稿/备注、模板结果 | 可打开、播放、编辑；每页有主主张和备注 |
| 导出 PDF/PNG 预览 | 渲染结果 | PDF 页数与 PPTX 一致，字体嵌入 100%，无溢出 |
| `evidence_map.json` | 每页内容对应论文图、表、章节、数据 | 每个 locator 可回溯到源材料具体位置 |
| `result.json` | case_id、状态、来源、不确定性、修改记录、输出文件清单 | 字段完整，诚实标注限制 |
| `render_report.json` | 导出命令、页数、字体嵌入、溢出检查结果 | 记录实际命令和输出，可复现 |
| `qa_prep.json` | 每页预判追问与回答要点 | 每个主主张有对应问答准备 |
| `narrative_outline.json` | 叙事顺序、每页主主张、证据强度 | 每页一个主主张，证据强度标注明确 |
| `input_manifest.json` | 输入文件清单、约束提取 | 记录实际读取的文件和提取的约束 |

### 自证可核验的具体方法

- **locator 逐字引用**：在 `evidence_map.json` 中，每个 locator 包含源材料中的原文摘录（10–30 字），例如 `"图2b显示效率从18.2%提升至22.1%"`。
- **复算命令**：在 `render_report.json` 中记录导出命令，例如 `soffice --headless --convert-to pdf --outdir /app/output /app/output/case_id_slides.pptx`，并记录 `pdfinfo` 输出的页数、`pdffonts` 输出的字体嵌入情况。
- **修改记录**：在 `result.json` 中记录每次修改的时间、内容、原因，例如 `"v2: 修正图3引用编号，原为图2"`。

## 7. 虚构案例（自洽校验）

### 输入

- **案例 ID**：`case-mxene-sc-2024`
- **源材料**：论文《MXene 基柔性超级电容器的赝电容机制与倍率性能优化》，发表于 *J. Mater. Chem. A*, 2024, 12, 3456-3467。PDF 共 10 页，含图 6 个（图 1 结构示意图、图 2 电化学性能、图 3 倍率性能、图 4 机理表征、图 5 理论计算、图 6 柔性测试）、表 2 个（表 1 性能对比、表 2 拟合参数）、公式 3 个（公式 (1) 比电容计算、公式 (2) 赝电容贡献、公式 (3) 扩散系数）。
- **任务约束**：听众为材料化学方向评审专家，时长 8 分钟，页数 10 页（含封面 1 页、致谢 1 页），必须使用学校学术汇报模板，每页一个主主张，备注含讲稿。
- **模板**：`template_academic.pptx`，母版含标题、页脚、页码占位符。

### 关键中间量（数字可复算）

| 步骤 | 计算/操作 | 结果 |
|---|---|---|
| 页数预算 | P = 10 页（给定），有效内容页 = 10 − 2 = 8 页 | 8 页有效内容 |
| 每页平均讲述时间 | t_page = 8 min / 10 页 = 0.8 min/页 | 48 秒/页，在 0.75–1.5 范围内 |
| 讲稿总字数 | W = 140 字/min × 8 min = 1120 字 | 1120 字 |
