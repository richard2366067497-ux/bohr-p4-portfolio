# 专家参考手册 · 科研底稿的受众/体裁忠实改写（writing-16）

> 本手册是本 Skill 的核心方法论基准：执行前必读。任务本质、错误做法→正确做法、求解框架、量化
> 口径、领域知识、交付物检查表与案例均以本手册为准；与 `SKILL.md` 冲突时，契约键名与入口命令以
> `SKILL.md` 为准，方法与判分口径以本手册为准。

## 1. 任务本质与判分要点

**任务本质**：不是“把文章写漂亮”，而是完成一条可复核的转化链——**受众画像 → 证据取舍 → 术语与
论断映射 → 完整成稿 → 来源定位与逐段改动记录**。案例可能更换学科、体裁与输入形式，须依赖规则
现场生成，不能内置领域答案。交付含三面：**目标产物**（符合受众/体裁/篇幅/格式的完整成稿，不是
提纲或建议）、**证据面**（每个数字、单位、样本量、条件、图表编号与论断强度都可回溯到逐字定位）、
**边界面**（冲突、缺口、待确认与降级如实标注，首轮即保存可读产物）。

**判分要点（优先级从高到低）**：① 实际效果——完整成稿、事实正确、关键证据不丢、逐段可回溯，
先保这些再优化文采；② 使用增益——相对基础 Agent 减少事实纠错、术语返工、证据补回与格式重做，
须同输入同约束对照，不得自报；③ 创新增益——“必须保留项清单 + 术语锁 + 论断强度锁 + 边界标注 +
逐段对照”的组合能力；④ 可靠体验——长文、缺材料、数据冲突、重复运行、不同文体都能处置，部分
完成也保存可用结果；⑤ 生态贡献——`SKILL.md`、模板、验收口径、异常处理、最小示例、版本说明一致。

**错误做法 → 正确做法**：

| 错误做法 | 正确做法 |
|---|---|
| 只给建议（“建议压缩方法部分、增强科普性”） | 交付符合受众/体裁/篇幅的完整稿件并附证据映射 |
| 凭文件名或领域标签猜材料 | 实读 `case.json`、`task.md` 与原始材料；未读到的内容不进正文 |
| 改写时升级论断（相关→导致、初步→证实、10 h→长期稳定） | 强度不得高于研究设计、样本与源文结论 |
| 只留漂亮数字，删掉基准、条件、样本量 | 同时保留比较对象、绝对差、实验窗口、统计口径与限定 |
| 摘要与表格冲突时自行选一个数 | 用可核实口径或暂缓表述，`uncertainty` 列冲突与待确认项 |
| 为科普删掉所有条件、单位与限制 | 用短解释替代行话，保留支撑结论的最小证据包 |
| 只有终稿没有版本记录 | 给段号、原意、改后位置、操作类型、理由与来源定位 |
| 伪造对照得分、读者满意度或正式案例结果 | 只记录本次真实检查；未提供的对照与未知结果保持空缺 |
| 最后才写结果，预算耗尽只剩笔记 | 首轮即保存可读 `deliverable.md` 与合法 `result.json`，增量改进 |
| 静默统一术语而不留痕 | 术语改动逐条记 before/after，可回退 |

## 2. 求解框架（8 步）

中间件写 `--work`，正式产物写 `--output`；“冻结”表示后续修改必须留版本与原因。

| 步骤 | 操作 | 冻结产物 | 门控 |
|---|---|---|---|
| S0 契约 | 提取 `case_id`、全部契约字段、受众、用途、体裁、篇幅、禁用事项 | `00_contract.md` | 字段无遗漏；未知标“未提供” |
| S1 源料账本 | 枚举文件、记哈希、按页/段定位 | `01_sources.md` | 来源可重开；解析失败与缺失分开记 |
| S2 转化规格 | 读者已知/读后要做/需解释术语/必需结构 | `02_brief.md` | 体裁篇幅冲突先标注，不擅放宽 |
| S3 证据原子 | 对象—指标—数值—单位—条件—样本—统计口径—基准—定位—逐字引文 | `03_evidence.csv` | 关键数字/论断有来源；派生值标 `derived` |
| S4 三把锁 | 必须保留项 `M`、术语锁、强度锁；列可压缩项 `C`、可删除项 `D` | `04_locks.md` | 删除项不得含结论所需条件/基准/限制 |
| S5 段落映射 | 先排“结论—证据—限制—行动边界”，再分配每个 `M` | `05_map.md` | 所有 `M` 有去向；无来源句不入稿 |
| S6 成稿改写 | 缩写首现展开、同义词收敛；不夸大成熟度 | `deliverable.md`、段级 `change_log.md` | 是完整产物；段落可回指证据原子 |
| S7 独立复核 | 重算派生值、核对单位与图表、查篇幅/术语/引用/删改理由 | `qa.md` | 关键项失败即退回；不用润色掩盖事实错误 |
| S8 结构化交付 | 汇总状态、主结果、来源、不确定性、修改记录、缺口 | `result.json`+附件 | JSON 可解析、含原契约字段与 `case_id` |

**异常三分法**：材料缺失→交付有限草稿并列缺口；无法判断→保留冲突与待确认项；运行失败→记录失败
阶段与已保存产物。涉密或未发表材料只在授权环境内处理。

## 3. 量化口径与公式

- **证据保留率** `= |R ∩ M| / |M| × 100%`，目标 **100%**。不只指数值出现：若“42.0%”丢了“300 ℃、
  对照体系、3 次独立实验”中的必需条件，仍判未完整保留；背景机理可压缩，支撑结论的限制不可删。
- **数值一致率** `= 数值元组一致的输出项数 / 输出数值总项数 × 100%`，目标 **100%**。元组至少含
  `数值、单位、指标、对象、条件、分母/基准、统计口径`。源文抄录值**零自由波动**（不改有效数字、
  不把 SD 改成 SEM）；派生值按原精度计算后声明舍入，保留 `d` 位小数时 `|复算值 − 报告值| ≤ 0.5 × 10⁻ᵈ`
  （例：`35.5%` 复算 `35.48387…%`，差 `0.01613 < 0.05`，合格）。篇幅上限容差 **0**；重复运行措辞
  可变，关键事实、数值、来源、论断边界不得漂移。
- **论断越级率** `= 强度高于源证据的论断数 / 实质论断总数 × 100%`，目标 **0**。四种升级须查：
  相关→因果、单条件→普遍适用、实验室→工业验证、潜力→已证明。合理简化是“复杂句变短”，不是
  “限定语消失”。
- **术语与追溯**：`缩写首现展开率`、`术语锁定率`、`段落可追溯率` 目标均 **100%**；通俗性不能只靠
  指标宣称，至少检查目标读者是否需要额外查公式、缩写或基准。
- **效率增益**：人工编辑项分事实纠错、证据补回、术语统一、结构调整、格式返工（同段同问题只计一次），
  `人工编辑下降率 = (H₀ − H₁) / H₀ × 100%`；仅在同源文/同受众/同篇幅/同计时口径下报告，`H₀=0`
  报绝对数，无对照时不得生成增益数字。

## 4. 领域知识清单

1. **百分比与百分点**：31.0%→42.0% 是增加 11.0 个百分点；相对增幅 35.48%，不可互换。
2. **转化率/选择性/产率**：定义与基准一致才可用 `Y=X×S`；碳基选择性不能与质量基转化率混算。
3. **`均值±SD`/`均值±SEM`/置信区间**不可互换；`n=3` 须说明独立重复还是同样品三次测量。
4. **空速与流量**：`mL·g_cat⁻¹·h⁻¹` ≠ `mL·h⁻¹`；换算需核对催化剂质量、计量状态与时间单位。
5. **温压**：℃ 与 K 不混写；0.10 MPa = 100 kPa，表压与绝压不可静默转换。
6. **组成单位**：`wt%`/`mol%`/`vol%`/`at%`/`ppm` 基准不同，不能只换单位名称。
7. **样品身份**：催化剂/膜/合金/批次的编号、组成、预处理、负载量不可跨样品合并。
8. **尺度外推**：固定床、扣式电池、小试膜组件不代表放大设备；10 h 稳定 ≠ 长寿命；实验室性能
   不推出经济收益。
9. **图表与引用**：保留原编号，重编号须给“原→新”映射；不生成源文不存在的图号、DOI、作者、文献。
10. **文献依据**：案例事实以原始材料为主；外部资料仅在允许时用于术语解释并标外部来源；缺引用标缺口。

> 受众矩阵与强度词表见 `references/audience-genre-matrix.md`；工作稿字段字典见 `references/draft-schema.md`。

## 5. 交付物清单与专家检查表

**必需交付物**：`deliverable.md`（完整成稿、段号、必要标题与图表引用）；`result.json`（原契约全字段、
`case_id`、状态、主结果、来源、不确定性、修改记录，`python -m json.tool` 可解析）；
`retained_facts.json`/`evidence_map.csv`（事实 ID、输出段号、来源文件、页/节/表图/段号、逐字引文、
派生公式）；`change_log.md`/`diff_map.md`（原段定位、改后段号、保留/压缩/删除/改写/降级、理由）；
`glossary.csv`/`terms_and_limits.md`（术语锁、缩写展开、禁用升级词、待确认）；`qa.md`（指标、篇幅
计数、复算命令、输入哈希、异常与剩余限制）；其他格式附件（DOCX/幻灯片/图示须附真实 PDF/PNG 预览）。
**定位格式**：`文件名 | PDF物理页x（印刷页y） | 节/表/图 | 段落 | "逐字引文"`；纯文本
`标题 | 第n自然段 | "逐字引文"`；只写文件名不算有效定位。

**专家检查表（逐项通过方可交付）**：

- [ ] 已读实际 `case.json`、`task.md` 与全部相关材料，未据文件名猜测。
- [ ] `case_id` 与输入一致，`result.json` 保留原契约全部字段。
- [ ] 已交付完整可用产物，不是建议、提纲或零散润色。
- [ ] 受众、用途、体裁、篇幅、语言与指定格式均满足。
- [ ] 关键结论、条件、样本量、统计口径、比较基准与限制在必须保留清单中。
- [ ] 每个关键数字有对象、单位、条件及来源定位。
- [ ] 百分比、百分点、相对变化已区分，派生值均标为派生。
- [ ] `±`、样本量、独立/技术重复未被改写或补造。
- [ ] 未发生相关→因果、实验室→工业、短期→长期的论断升级。
- [ ] 缩写首现已展开，同一概念全文一个称谓。
- [ ] 图表编号、样品编号与引用均与源文对应。
- [ ] 未添加源文不支持的新机理、新结论、新文献或经济收益。
- [ ] 每个实质段落可回溯，删除和压缩也有理由。
- [ ] 源文冲突未被静默修复；两种定位与待确认项已记录。
- [ ] 材料缺失、无法判断、运行失败被分别描述。
- [ ] 稿件不确定性与 `result.json` 的 `uncertainty` 一致。
- [ ] 篇幅由明确脚本或计数口径检查，硬上限没有“适当超出”。
- [ ] 首轮已保存部分交付物，后续改进未覆盖可用版本。
- [ ] JSON 已实际解析，声明路径均指向存在的真实文件。
- [ ] DOCX/幻灯片等可编辑产物有真实渲染预览，非伪造截图。
- [ ] 示例为明确标注的虚构演示，不含预制正式答案或虚构对照得分。
- [ ] 未公开上传涉密、未发表或超出授权范围的材料。

## 6. 完整虚构案例

> 以下材料、数据与输出均为演示虚构，不对应任何正式测试案例。

**输入**：`case_id=DEMO-NI-001`；任务为“将技术报告改为面向化工园区投资经理的项目简报，450 字
以内，保留比较基准、实验条件与限制”。虚拟来源 `S1.pdf`：

| 定位 | 逐字事实（节选） |
|---|---|
| p.2 表1 | “催化剂 0.100 g；300 ℃、0.10 MPa（绝压）、H₂/CO₂=4:1，空速 12 000 mL·g_cat⁻¹·h⁻¹。” |
| p.2 表1 | “Ni/A 的 CO₂ 转化率 42.0%±1.5%，对照 B 为 31.0%±1.8%；均值±SD，n=3 次独立实验。” |
| p.2 表1 | “Ni/A 的甲烷选择性 96.0%±0.8%（碳基）。” |
| p.3 图2 | “初始转化率 42.0%，连续运行 10 h 后为 40.8%。” |
| p.4 局限性 | “未考察原料杂质、放大传热及成型催化剂。” |

必须保留项：`M1 实验尺度`、`M2 反应条件`、`M3 转化率及统计口径`、`M4 对照`、`M5 选择性`、
`M6 十小时结果`、`M7 三项限制`；术语锁：全文只用“CO₂转化率”“甲烷选择性”。派生计算：
`42.0−31.0=11.0` 个百分点、`(42.0−31.0)/31.0×100=35.5%`、`0.420×0.960×100=40.32%`、
`40.8/42.0×100=97.14%`；40.32% 仅由中心值复算，图 2 未报告重复数 → 列不确定性。

**输出主稿（450 字内）**：

> **实验室镍基催化剂显示二氧化碳制甲烷潜力，工业验证仍待完成**
>
> 一种镍基催化剂 Ni/A 在实验室固定床中表现出二氧化碳加氢制甲烷潜力。使用 0.100 g 催化剂，在
> 300 ℃、0.10 MPa（绝压）、H₂/CO₂=4:1 和空速 12 000 mL·g_cat⁻¹·h⁻¹ 条件下，CO₂ 转化率为
> 42.0%±1.5%，对照催化剂 B 为 31.0%±1.8%（均值±标准差，均为 3 次独立实验）：绝对高 11.0 个
> 百分点，相对高 35.5%。甲烷选择性为 96.0%±0.8%（碳基），按中心值复算产率为 40.32%。原文图 2
> 显示，同一稳定性实验运行 10 h 后转化率为 40.8%（初始值的 97.14%）。这些结果仅支持上述实验
> 窗口内的性能判断；原料杂质、放大传热和成型催化剂尚未考察，10 h 数据也不能证明长期稳定性或
> 工业收益。

**来源映射与修改**：条件及性能 → `S1.pdf | p.2 | 表1`，35.5%/11.0 个百分点/40.32% 链接复算；
稳定性 → `S1.pdf | p.3 | 图2 | "连续运行 10 h 后为 40.8%"`，97.14% 标派生值；限制 → `S1.pdf | p.4 | 局限性`。
“性能优异且稳定”→“上述实验窗口内的性能判断”（缺长期及放大验证）；“提高 35.5%”→“绝对高
11.0 个百分点、相对高 35.5%”（消除口径歧义）。状态 `completed`。数字自洽：保留率 7/7=100%；
派生差 `0.01613 < 0.05`；越级率 0/1=0；术语锁定率 100%。

## 7. 交付前门控

- 逐项勾选 §5 检查表；任一未通过先修复再交付。
- `result.json` 可解析、逐键回填、`case_id` 与输入一致，路径指向真实非空文件。
- 成稿可沿“段落 → 来源定位 → 逐字引文”走通；派生值可由复算命令重跑。
- 异常分类记录（材料缺失 / 无法判断 / 运行失败），不得伪装成“已完成”。
