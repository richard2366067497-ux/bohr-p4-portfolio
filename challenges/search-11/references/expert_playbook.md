# 专家参考手册 —— 可复核检索证据包（search-11）

本手册是 patent-search-dossier 的**执行前必读**方法论：它规定检索协议、来源授权分级、
抽取与规范化口径、指标公式、领域事实边界、交付物形态与自查清单。
执行时按本手册推进，产出后再逐项过 §8 自查表。

---

## 1. 任务本质与高分要素

交付物不是一篇专利综述，而是一份**可独立复核的检索证据包**。每个案例都要回答：
检索对象是什么、用了哪些获准来源、如何取得与筛选、专利号与同族是否对应、
法律状态核验到哪个日期、权利要求来自哪个版本、哪些事项仍不能确定。

**证据范围是材料边界，不是预填答案**：题设给的是有限记录数与若干原始传真件及对比论文；
运行时必须读取实际文件，不得把文件数量当成结论。

评分优先级：实际效果 40、使用增益 25、创新增益 15、可靠体验 10、生态贡献 10。
Skill 的价值在于稳定执行「协议先行 → 证据留存 → 规范抽取 → 冲突显式化 → 机器校验」，
在相同输入与权限下减少重复核对，而非堆砌数据库数量。

常见失败模式与正确做法：

| 错误做法 | 正确做法 |
|---|---|
| 把主题词交给通用搜索、以摘要拼答案 | 分离号码定位/主题发现/法律状态/权利要求四类查询，逐条保存检索式与原始返回 |
| 正则通过就宣称专利真实存在 | 格式规范化与存在性核验分开；存在性必须有来源中的精确号码匹配 |
| 混用公开号/申请号/授权号/优先权号 | 分字段保存原值、规范值、号码类型、国家/地区、种类代码 |
| 把优先权日当作申请日或授权日 | 日期分列并使用 ISO 格式；无法确认的日期置空并说明 |
| 标题相似或关键词相同就合并同族 | 按来源支持的优先权关系归并，注明简单族/扩展族及定义来源 |
| 把观察到的族成员当成完整族 | 标为「本次来源观察到的成员」，另列覆盖限制与遗漏风险 |
| 认为同族成员权利要求或法律状态相同 | 按成员、版本、司法辖区分别核验，不作等同推断 |
| 从授权公告推断「目前有效」 | 授权种类代码只说明文献事件；当前状态须查官方登记并注明查询日期 |
| 用摘要或说明书代替权利要求 | 标明公开/授权版本、独立/从属权利要求、编号、页码与逐字引文 |
| 对合并 OCR 连续抽取 | 保留文件与文档边界；边界不明的字段不得跨段拼接 |
| 遇到登录墙/付费墙继续抓取 | 记录权限阻断，停止访问与原文展示，启用元数据级降级 |
| 冲突时任选较新或较多的网页 | 并列来源、事件日期、查询日期与原文，官方登记优先但不掩盖冲突 |
| 无结果时补造相近文献 | 报告空查询、过滤条件、覆盖范围与改检建议 |
| 自述节省时间或提高分数 | 只记录真实运行日志；基线增益由同输入、同权限对照证明 |

## 2. 七步求解框架与门控

1. **读取契约与盘点材料**：读取 `/input/case.json`、`task.md`、`environment/resources.yaml`，
   枚举并解析实际材料，不以文件名推断内容。冻结 `run_manifest.json`：`case_id`、输出字段映射、
   文件路径、SHA-256、来源许可、运行环境、实际查询时间。
   *门控*：所有 `output_contract` 字段均有去向；缺材料/无法判断/运行失败分别编码。
2. **冻结检索协议**：在查看筛选结果前生成 `search_protocol.json`：研究问题、辖区/语言/时间范围、
   纳排标准、目标字段、族定义、排序规则、计划查询与停止条件。
   *门控*：每条纳排标准均可操作化；不得看完结果后倒推标准。
3. **建立来源索引与授权分级**：绿/黄/红分级见 §3。
   *门控*：每个来源均记录库名、版本/快照、查询日期、许可依据与降级方案。
4. **执行查询并保存原始证据**：号码查询保留原始与规范化字符串；主题查询组合关键词、IPC/CPC、
   申请人及引证关系；专利与论文分别设计。每次查询保存 `query_id`、完整检索式、过滤器、时间、
   返回量、错误及原始响应路径。*门控*：每条候选至少有一个 `query_id`；空结果也保存查询记录。
5. **抽取、规范化与定位**：先文档级记录，再族级视图。每个关键字段带 locator：文件哈希、PDF 页码、
   印刷页码、栏/行、权利要求号或原始 JSON 路径。OCR 不确定字符不得静默修正。
   *门控*：号码、日期、族关系、法律状态、权利要求均能回到原文；规范化不改变原值。
6. **筛选、排序、归并与状态核验**：对全部候选执行相同纳排标准，保留排除理由与排序分项。
   简单族、扩展族与「仅观察到关联」不得混写。当前法律状态必须来自可核验官方登记；
   无法访问时填 `not_verified`，不能填「有效」。
   *门控*：原始命中数 = 去重后文档数 + 重复数；所有候选均有处理去向。
7. **尽早输出并增量完善**：先写可解析的 `result.json`（全部契约字段、`case_id`、状态、来源、
   不确定性、变更记录），再补报告与证据表。运行校验、复算指标、复核全部有限记录。
   *门控*：JSON 可解析、相对路径有效、计数一致、引文准确；部分完成必须明确限制，不能包装成完整成功。

## 3. 来源授权分级（绿/黄/红闸门）

- **绿色**：题设允许的材料及许可明确的公开来源。
- **黄色**：展示范围不清、限流、OCR 质量差或官方接口暂不可达；仅保留获准的最小元数据。
- **红色**：无授权登录、付费墙、保密或许可禁止展示；不访问、不留原文，只登记。

许可未声明的来源一律按**黄色**处理并写入 `gaps`；红色来源只登记不引用。

## 4. 量化口径与公式

- **选择精确率**：\(P=TP/(TP+FP)\)；TP 为最终纳入且相关，FP 为纳入但不相关。
- **证据范围召回率**：\(R_e=TP/(TP+FN)\)；**仅在案例给定完整参考范围时**计算，
  否则报 `not_estimable`，不得宣称「查全率 100%」。
- **候选池相关率**：相关去重候选数 / 全部去重候选数，与最终选择精确率分开报告。
- **元数据正确率**：\(A_m=C/E\)，C 为核验正确的已抽取字段数，E 为实际抽取并接受核验的字段数。
- **必填字段覆盖率**：\(C_f=V/N_{req}\)；合理填写的 `unknown` 不算正确抽取，也不能静默从分母删除。
- **可追溯率**：\(T=N_{trace}/N_{out}\)；完整 trace 至少含查询、来源、locator 与相关性理由。
- **法律状态核验覆盖率**：\(L=N_{official}/N_{legal\_req}\)，只统计带官方登记及查询日期的当前状态。
- **族归并对账率**：\(F=N_{assigned}/N_{unique}\)；每个候选须归入族、单件或带理由的未决项，目标 100%。

专利主题排序可采用

\[
S=0.35K+0.25C+0.25T+0.15R
\]

其中 K 为关键词覆盖，C 为分类号匹配，T 为权利要求/摘要的技术匹配，R 为申请人或引证支持；
各取 0、0.5、1，并保存理由。S 只用于排序，不能推翻硬性纳排标准。
论文另按方法、材料体系与可比实验条件评分，不套用专利用权重。

计数单位为「文档」「族」「字段」；时间用带时区时间戳，时长用秒；百分比统一保留两位小数。
相同快照下，号码、计数、哈希与引文允许偏差为 **0**；指标复算与报告值最多相差 0.01 个百分点（仅舍入）。
运行耗时可用三次中位数，波动超过中位数 10% 只触发工程检查，不是科研正确性阈值。
来源更新导致的状态变化**不得平均**，应另建快照。

技术材料比较须保留原始条件：`80 °C = 353.15 K`、`30 min = 0.5 h`；wt%/mol%/vol% 不可互换，
kPa 与 MPa 相差 \(10^3\)；没有依据不得换算或补齐实验条件。

## 5. 领域事实清单

1. US A1 通常是公开申请，B1/B2 是授权文献种类代码，均不直接表示当前有效或可执行。
2. 公开号、授权号可能指向同一申请的不同阶段，但不得仅凭号码猜测对应关系。
3. 最早优先权日不自动证明每项权利要求均享有该日期；不作权利要求有效性的法律判断。
4. 简单族通常要求相同优先权集合，扩展族按直接/间接优先权关联扩展；必须采用所用数据源的正式定义。
5. 同族成员的申请人、法律状态、权利要求数量与范围可能不同；continuation、divisional 等关系须逐件记录。
6. WO 是公开体系，不是「世界专利授权」；是否进入国家阶段须另有证据。
7. 法律事件与派生状态分列（授权、视为撤回、未缴年费、期限届满）；不得把单一事件外推为全球状态。
8. 引证可能来自审查员或申请人，只表示记录中的引证关系，不自动证明技术相同或更优。
9. IPC/CPC 命中只是相关性证据；分类版本、原始/当前分类与人工修订未知时应注明。
10. 科学论文须区分预印本与正式版本；DOI 缺失不能补造，题名相似不能代替版本核验。
11. 对比论文的性能结论必须保留材料体系、测试方法与条件，不能跨单位、跨条件直接排名。
12. PDF 首页著录项可证明其发布时记录，不足以证明当前法律状态；二手聚合页不得称为官方登记。
13. OCR 中 `0/O`、`1/l`、逗号与空格属高风险字符；无清晰原图核对时保留不确定标记。
14. 所有领域事实均需来源定位；官方字段定义用官方文档，技术结论用实际论文或专利原文，搜索摘要只可作为发现线索。

## 6. 交付物与自证方式

**每案运行产物**：

- `result.json`：完整契约字段、`case_id`、主结果、状态、来源、不确定性、遗漏与变更记录。
- `report.md`：范围、方法、候选与排序、排除项、族视图、法律状态、权利要求、论文对比、授权限制与复核建议。
- `candidates.jsonl`：每条候选的原始/规范号码、元数据、查询来源、评分明细、纳排决定、理由与 locator。
- `queries.jsonl`：查询全文、来源版本、日期、过滤器、返回量、原始响应哈希与异常。
- `evidence_tables.csv`：族关系、法律事件、权利要求版本与科学论文条件。
- `evidence/`：仅保存获准留存的原始返回、文本抽取与必要页面快照。
- `validation.json`：字段完整性、计数对账、指标复算与文件检查结果。

自证方式是「locator + 逐字引用 + 复算命令」，例如
`demo.pdf#page=7&col=2&lines=1-3&claim=1`，以及实际可执行的校验命令；
另用 JSON 语法检查与 `sha256` 核对证据。若生成图形交付物，同时提供真实渲染的 PNG 预览。

## 7. 完整虚构案例演示

> 以下号码、来源、论文与状态全部为虚构，仅演示流程，不是正式案例答案。

**输入**：`case_id=DEMO-MAT-001`；问题为「查找在不超过 80 °C、30 min 内固化的涂层组合物，
定位 D01/D02，比较族关系、法律状态与指定权利要求，并找一篇方法可比论文」。
协议规定必须同时满足温度与时间条件；只有催化剂相同而固化条件不符者排除。

号码规范化示例：`US2099/0999999A1 → US 2099/0999999 A1`，仅改变展示格式。
两次查询 `QN1`（号码）与 `QT1`（主题+分类号）共返回 7 条，D02 重复一次，去重后 6 条。

| ID | 虚构公开号 | 决定 | 依据 | 观察简单族 |
|---|---|---|---|---|
| D01 | US 2099/0999999 A1 | 纳入 | 80 °C、30 min；摘要支持 | F1 |
| D02 | US 99,999,999 B2 | 纳入 | 授权权利要求支持 | F1 |
| D03 | WO 2099/123456 A1 | 纳入 | 技术相关，公开日因 OCR 边界未知 | F2 |
| D04 | EP 4,599,999 A1 | 纳入 | 80 °C、30 min | F2 |
| D05 | US 2099/0888888 A1 | 纳入 | 75 °C、25 min | F3 |
| D06 | US 2099/0777777 A1 | 排除 | 120 °C、60 min，不满足硬条件 | F4 |

D01 排序分项 \(K=1,C=1,T=0.5,R=0\)，故 \(S=0.35+0.25+0.25\times0.5=0.725\)；
不因分数较高而省略权利要求核验。

参考证据范围另有相关 D07 未被检出，故 TP=5、FP=0、FN=1：
选择精确率 \(5/5=100.00\%\)，证据范围召回率 \(5/6=83.33\%\)，候选池相关率 \(5/6=83.33\%\)。
纳入文档形成 3 个**观察到的**简单族，不能称为完整扩展族。

5 条纳入记录各查 4 个必填字段共 20 个；D03 公开日未知，其余 19 个均核验正确，
故元数据正确率 \(19/19=100.00\%\)，覆盖率 \(19/20=95.00\%\)。6 条候选均有完整证据，T=100.00%。
D02 在虚构官方登记中于 `2100-01-15T10:00:00Z` 显示 `ACTIVE`，D01 因官方接口超时未核验，
故 L \(=1/2=50.00\%\)，不得把 D02 的登记标签外推为全球可执行状态。

D02 权利要求证据：`d02_uspto.pdf#page=7&col=2&lines=1-3&claim=1`，逐字引用：
「1. A composition comprising component A and component B.」。
D03 的指定权利要求位于合并 OCR 边界，标记 `claim_version=undetermined`。
虚构对比论文 `paper_demo.pdf#page=2&table=1` 给出 80 °C、30 min，但 DOI 缺失，记为 `DOI=null`。

最终状态 `partial`：主结果含 D01–D05、3 个观察族与上述指标；不确定性列明 D07 遗漏、
D01 状态未核验、D03 日期与权利要求版本未定、论文 DOI 缺失；变更记录仅保存号码格式化及依据。
即便可追溯率 100%，也不得声称「检索完整」或「全部法律状态已核验」。

## 8. 防扣分自查表（交付前逐项通过）

- [ ] 已读取实际 `case.json`、`task.md` 与全部相关材料。
- [ ] `result.json` 含原始契约全部字段及正确 `case_id`。
- [ ] 未使用预制答案、虚构文献或虚构基准成绩。
- [ ] 每个来源均有库名、版本/快照、查询日期与许可依据。
- [ ] 未绕过登录、付费墙、限流或保密限制。
- [ ] 原始传真件按实际页面读取并保留页级定位。
- [ ] 检索协议与纳排标准在筛选前冻结。
- [ ] 号码查询与主题查询分别记录，空查询也有日志。
- [ ] 公开号、申请号、授权号、优先权号未混用。
- [ ] 原始号码保留，规范化未被当作存在性证明。
- [ ] 优先权日、申请日、公开日、授权日分列。
- [ ] 每条候选均有查询来源、相关性理由与 locator。
- [ ] 排除项有具体理由，不仅写「不相关」。
- [ ] 简单族、扩展族与观察关联已明确区分。
- [ ] 未将观察成员声称为完整族，未暗示同族权利要求等同。
- [ ] 当前法律状态均有官方依据与查询日期；未知即标未知。
- [ ] 法律状态冲突并列呈现，未按网页数量投票。
- [ ] 权利要求标明版本与编号，关键内容为逐字引用。
- [ ] 未给出侵权、自由实施或专利价值结论。
- [ ] 合并 OCR 边界保留，未跨文档拼接字段。
- [ ] 论文与专利分别检索，DOI/版本/实验条件缺失已说明。
- [ ] 材料缺失、无法判断、权限异常与运行失败未混为一种状态。
- [ ] 所有指标分母明确，无法估计召回率时未报 100%。
- [ ] 原始命中、去重、纳入、排除与族归并数量可对账。
- [ ] 校验脚本真实执行，输出路径与证据哈希有效。
- [ ] 已尽早保存诚实的部分结果，最终状态与剩余限制一致。

**门控**：以上任一项未通过，`status` 记为 `partial` 并把未决项写入 `uncertainties` /
`boundary_log.json`，绝不静默提升为完整成功。
