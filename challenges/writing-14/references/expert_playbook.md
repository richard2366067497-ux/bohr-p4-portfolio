## 1. 任务本质与判分要点

### 1.1 任务本质

交付物是**可执行的 Skill，而非三份预制开题报告**。Skill 应读取 `/input/case.json`、`task.md`
及实际论文、表格、PDF，在 `/app/work` 处理，在 `/app/output` 生成：

1. 满足体裁、受众、篇幅、语言和格式要求的可编辑主稿；
2. 研究背景、问题定义、目标、技术路线、阶段计划、风险、预期成果七要素；
3. 论断—来源映射、修改记录、材料缺口、不确定性和真实运行状态；
4. 保留原 `output_contract` 全部字段及 `case_id` 的 `result.json`；
5. Office、图示等交付物的真实 PDF/PNG 预览；无法渲染时明确说明，不伪造预览。

### 1.2 判分要点（判分优先级）

评委核心看五点：**七要素是否齐全且互相对齐，计划是否落在周期与资源内，事实和引用是否可追溯，
异常是否诚实处置，加载 Skill 后是否比基础 Agent 更稳定、更少返工。** 文档自述不能替代实际运行证据。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 把背景写成领域综述 | 用“已知—未知—待验证”收束缺口，每条已知结论挂接证据 |
| 一次提出宽泛课题和十余个目标 | 收敛为 1—3 个可证伪问题，每个目标写明指标、样本、对照、时间点 |
| 七个章节分别写得漂亮但互不对应 | 建立“问题→目标→任务→验证→成果”矩阵，消除断链和孤儿任务 |
| 只列季度安排，不核算工作量 | 计算总工时、关键路径、人员负载、样本数和预算，并保留余量 |
| 风险只写“实验可能失败” | 写清触发信号、影响范围、备选方案、决策时点和责任角色 |
| 根据标题、DOI 或领域常识补写论文结论 | 阅读实际来源，保存逐字引文及页码、表单元格等定位；无法获取则标记 |
| 缺少周期、经费或工艺参数时自行补齐 | 对话场景集中追问；无人交互场景先交部分结果，并列阻塞项和影响 |
| 只返回正文或笼统“成功” | 返回结构化状态、来源、变更和不确定性；区分材料缺失、无法判断、运行失败 |
| 将示例主题、数字套入未知案例 | 示例只复用结构，所有事实、阈值和约束必须重新从当次输入抽取 |

## 2. 求解框架（8 步法）

所有中间产物放在 `/app/work`。“冻结”指形成可追踪版本，后续修改必须记录原因并联动重算，而非禁止修订。

| 步骤 | 操作 | 冻结产物 | 门控 |
|---|---|---|---|
| S0 读取与建档 | 读取实际文件和输出合同；记录文件名、版本、哈希、可用解析工具 | `run_manifest.json`、来源清单 | 输入均已检查；不得凭文件名猜内容 |
| S1 抽取约束 | 抽取受众、文体、篇幅、周期、经费、人员、设备、数据、伦理及格式要求 | `constraints.yaml` | 每项含数值、单位、硬/软约束和 locator；缺失项不得默认填补 |
| S2 建立证据卡 | 摘录关键论断、前期数据、术语和引用，保留上下文 | `evidence.jsonl` | 关键数字核对原表；记录原单位、归一化过程和逐字引文 |
| S3 定义问题与目标 | 形成缺口，提出 1—3 个研究问题，为每题设定验收标准 | `design.yaml` | 问题可证伪；阈值有来源，或明确标为“拟定目标/项目假设” |
| S4 设计技术路线 | 将方法拆为有输入、输出、依赖、质控的任务 | `route.md`、`alignment.csv` | 每个目标均有验证任务；每个任务均服务于目标 |
| S5 核算计划 | 展开样本、批次、工时、费用、月份和依赖关系 | `schedule.csv`、`budget.csv` | 关键路径不超期；人员不超载；预算与样本口径一致 |
| S6 风险与成果 | 按数据、方法、进度、伦理/安全合规分类；定义成果考核方式 | `risks.csv`、`outcomes.csv` | 每条风险都有可观察触发器和备选路线；成果可验收 |
| S7 写作与验证 | 生成主稿、来源映射和差异记录，运行结构与数值检查，渲染预览 | `/app/output` 全套交付物 | 七要素、引用、算术、格式、状态和合同字段全部通过；失败则保存部分稿 |

为减少模型往返，应“一次解析、多步复用”，优先修改结构化中间表，再由模板重生成受影响章节。尽早
保存可交付部分稿，不在最后一步才写输出。

## 3. 量化口径与判定规则

以下是 **Skill 的建议内部门控，不是官方评分线，也不是跨学科通用标准**；输入材料另有规定时以输入为准。

### 3.1 完整性与可追溯性

- 七要素覆盖率 \(E=N_{\text{合格要素}}/7\times100\%\)，门控 7/7；但“有标题”不算合格，必须含实质内容。
- 关键论断溯源率 \(T=N_{\text{有有效来源且定位可打开的关键论断}}/N_{\text{关键论断}}\times100\%\)；
  外部事实、前期数据和引用应为 100%；研究设想不得伪装成已有事实。
- 目标对齐率 \(A=N_{\text{具有完整问题—任务—验证—成果链的目标}}/N_{\text{全部目标}}\times100\%\)，建议 100%。
- 数值复算允许误差：仅由显示精度造成的尾差，按输出精度控制在 0.01 以内；**不能用该容差掩盖实验误差**。

### 3.2 样本、重复与变异

若有个案组、对照组、独立重复和备用批次：

\[
N_{\text{总批次}}=G\times r+\lceil G\times r\times q\rceil
\]

其中 \(G\) 为组数，\(r\) 为独立批次数，\(q\) 为备用比例。技术重复先在批次内汇总，再计算批间统计量，
**不能把同一批的两只样品当作 \(n=2\) 个独立实验**。

\[
\bar{x}=\frac{1}{n}\sum x_i,\qquad
s=\sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}},\qquad
RSD=\frac{s}{\bar{x}}\times100\%
\]

例如前期三个独立批次为 82%、83%、84%，则均值 83.0%，样本标准差 1.0 个百分点，
\(RSD=1/83\times100\%=1.20\%\)。RSD 可接受限值必须来自材料或明确的项目假设，不能宣称“所有实验
均应小于 5%”。若需显著性或确证性结论，应依据预期效应量、方差和检验效能另行估算样本量。

### 3.3 性能改善与计划可行性

容量保持率等比例指标应区分“相对提升”和“百分点提升”：

\[
\Delta_{pp}=Y_{\text{实验}}-Y_{\text{同期对照}},\qquad
\Delta_{rel}=\frac{Y_{\text{实验}}-Y_{\text{同期对照}}}{Y_{\text{同期对照}}}\times100\%
\]

例如由 83% 升至 90%，是提高 7.0 个百分点，而相对提高 8.43%，二者不可混写。人员负载率和预算为：

\[
U=\frac{H_{\text{任务}}}{H_{\text{可用}}}\times100\%,\qquad
B=\sum C_i+C_{\text{预备金}}\le B_{\text{上限}}
\]

无既定标准时，可将 \(U\le85\%\) 作为保守排产假设并显式标注；同时检查各月负载和关键路径，不能
只看全周期平均值。

## 4. 领域知识清单

| 易错点 | 正确处理 |
|---|---|
| wt%、mol%、ppm 分母不明 | 写明相对最终产物、活性材料、前驱体还是溶液；给出干基/湿基和计算公式 |
| 产率、转化率、选择性、纯度混用 | 分别定义基准物质和计量关系，不能用“产物很纯”推出“收率高” |
| % 与百分点混淆 | 保持率、占比之差用“个百分点”；相对变化另列百分比 |
| 独立批次与技术重复混淆 | 在图表、统计和样本数中分别标明，避免伪重复 |
| °C 与 K、Pa 与 bar、sccm 与 mL/min 直接混算 | 先换算再计算；气体体积流量需说明标准状态，升温速率用 °C/min 等 |
| rpm 直接当离心力 | 如需 RCF，必须取得转子半径；\(RCF=1.118\times10^{-5}r(\mathrm{cm})\times rpm^2\) |
| C 倍率与 mA/g 互换 | 必须知道额定/实际比容量；面容量还需电极载量，禁止无参数换算 |
| 表征证据越界 | XRD 主要支持晶相；SEM 支持形貌；EDS 多为局部半定量。单一结果不能证明均匀包覆或因果机制 |
| 电化学结果脱离测试条件 | 同时报告电压窗口、温度、倍率、首圈定义、圈数和电极载量等已有信息 |
| 把文献目标当通用阈值 | 区分“文献报道值”“指南要求”“本研究拟定值”；不同测试条件不得直接横比 |

引用优先使用实际提供的原文、数据表和可访问的一手文献。PDF 定位到页码及段落/图表，表格定位到
工作表和单元格，Markdown 定位到标题和行区间。逐字引文不得清洗掉影响含义的条件；无法取得全文时
只能记录书目信息和“支持关系未核验”，**不得生成虚构页码、DOI 或结论**。

## 6. 完整虚构案例（输入 → 关键中间量 → 输出）

> **以下全部虚构，仅演示方法；禁止在正式案例中复用其主题、数字或引文。**

**输入材料**

- **S1《指南.pdf》第 2 页**：“周期 6 个月，经费上限 30000 元。比较 0、1、2、3 wt% ZrO₂ 包覆 NCM811，
  2 wt% 为主要验证组。在 25 °C、0.5C、2.8—4.3 V 下，100 圈容量保持率均值不低于 90.0%，较同期未
  包覆组高至少 5.0 个百分点，三独立批次 RSD 不高于 3.0%。”
- **S2《前期数据.xlsx》工作表 Baseline，B2:D2**：历史未包覆组三个独立批次为 82.0%、83.0%、84.0%；
  测试条件与 S1 相同。
- **S3《资源.md》“资源”节**：26 周、每周 20 小时；每批原料及合成耗材 400 元，XRD 每批 80 元，
  电池组装测试每批 250 元，SEM 每个有效样品 250 元；每批组装 2 只电池作为技术重复；备用批次 20%，
  费用预备金为直接费用 10%。SOP-07 规定其余合成参数。

**关键中间量**

1. **缺口**：已有历史基线，但 2 wt% 组能否在同期对照下同时满足保持率、改善幅度和批间稳定性仍未知。
   历史 83.0% 不能替代未来同期对照。
2. **研究问题**：在 S1 固定测试条件下，2 wt% 组相较 0 wt% 组能否达到预设性能与重复性标准？
   1、3 wt% 仅作梯度探索。
3. **样本量**：\(4\times3+\lceil12\times20\%\rceil=12+3=15\) 批，最多组装 \(15\times2=30\) 只电池；
   SEM 检测 4 组 ×3 个有效批次，共 12 个样品。
4. **前期统计**：83.0%±1.0%（均值±样本 SD，\(n=3\) 独立批次），\(RSD=1.20\%\)。
5. **预算**：原料 6000 元，XRD \(15\times80=1200\) 元，SEM \(12\times250=3000\) 元，电池测试
   \(15\times250=3750\) 元；直接费用 13950 元，预备金 1395 元，总计 15345 元，低于 30000 元。
6. **工时**：设计 32 h、合成 120 h、表征 80 h、电化学与统计 96 h、写作 72 h，共 400 h；可用工时
   \(26\times20=520\) h，负载率 \(400/520=76.9\%\)，预留 120 h。
7. **对齐链**：研究问题→2 wt% 与同期 0 wt% 比较→三独立批次及 100 圈测试→均值、差值和 RSD→
   性能数据集与 SOP。XRD/SEM 用于解释结构和形貌，不单独承担机理证明。

**主稿节选**

> 前期未包覆样品 100 圈容量保持率为 83.0%±1.0%（均值±SD，\(n=3\) 独立批次）[C01]。本研究拟在
> 25 °C、0.5C、2.8—4.3 V 条件下，检验 2 wt% ZrO₂ 包覆组是否达到均值 ≥90.0%、较同期未包覆组提高
> ≥5.0 个百分点且批间 RSD ≤3.0%[C02]。1、3 wt% 组用于探索包覆量响应，不据此预先宣称存在最优机理。

计划为：M1 完成设计与 SOP 确认，M2—M3 完成合成和物相筛查，M3—M4 完成表征，M4—M5 完成电化学测试
和统计，M6 复算、撰写与交付。若首批次 RSD 超过 3.0%，暂停扩批并核查 SOP 执行和测试一致性；若
SEM 外送延迟超过 5 个工作日，则在 M3 末启用备选检测档期，优先保证主要电化学终点。

**来源映射与交付状态**

| claim_id | 来源定位 | 逐字依据或复算 |
|---|---|---|
| C01 | S2，Baseline!B2:D2 | “82.0%、83.0%、84.0%”；均值 83.0%，SD 1.0 个百分点 |
| C02 | S1，第 2 页 | “均值不低于 90.0%……高至少 5.0 个百分点……RSD 不高于 3.0%” |
| C03 | S3，“资源”节 | \(6000+1200+3000+3750+1395=15345\) 元 |
| C04 | S3，“资源”节 | \(400/520\times100\%=76.9\%\) |

输出应包括可编辑主稿、对齐表、计划预算表、风险表、来源映射、变更记录和 `result.json`。若 SEM 具体
档期未提供，应列入人工确认项和进度风险，而不是补造日期；若该缺项影响合同要求的完成条件，则状态
按合同标为部分完成，并明确“开题文本已生成，资源档期未确认”，同时保留全部已核验成果。
