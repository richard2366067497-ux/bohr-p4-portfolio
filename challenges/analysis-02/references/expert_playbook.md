# 专家参考手册 —— 统计分析与结果解读（analysis-02）

执行前**完整阅读本手册**，按 §2 六步门控推进，交付前逐项过 §6 自查表。

## 1. 交付什么

对含缺失值、异常值、重复记录的科研数据，交付 **可复算的数字 + 可执行代码 + 可读结论**：
回答「两组有无差异、差异多大、结论多确定、能否写进报告」，而不是给一个 p 值。
优先级：P0 统计正确性（方法与分布/设计匹配）＞ P1 清洗透明性（每步有规则/计数/日志）＞
P2 结果完整性（缺失/异常/重复/假设/图表/代码/字段）＞ P3 可复现性（代码+版本+种子+中间表）。

失败模式 → 正确：缺失删整行不报 → 报原始/删除/剩余 n（>15% 讨论偏倚）；异常 ±3SD 一刀切 → IQR/MAD
识别并说明处置；三组两两 t → 先 ANOVA/KW 再事后校正；不检假设就套参数法 → 小样本必做
Shapiro-Wilk + Levene；p<0.05 写「证明有效」→ 写「α=0.05 拒绝 H₀ + 效应量 + 95% CI + 领域判断」；
多重比较不校正 → 报原始与校正后 p。

## 2. 六步门控

`输入解析 → 数据清洗 → 描述统计 → 推断统计 → 效应量与CI → 解读与交付`；前一步未冻结不进入下一步。

1. **输入解析**：冻结 `data_dictionary`（字段名、类型、单位、允许范围、主键）；查单位一致性
   （mg vs μg、mm vs cm）；确认去重主键。*门控*：字段有类型与单位，否则标「字段不明」并暂停该字段。
2. **数据清洗**（顺序不可颠倒）：冻结 `cleaning_log`。①按主键/全行哈希去重，记
   `n_before/n_duplicates/n_after`；②逐字段缺失比例：<5% 可中位数/众数填补（注明），5–15% 讨论填补或
   完整案例分析，>15% 标记受限；③Tukey IQR（Q1−1.5IQR, Q3+1.5IQR）识别异常并记决策；④字符串数值
   coerce→NaN，日期统一。*门控*：清洗后行数 ≥ 原始 70%，日志完整。
3. **描述统计**：冻结 `descriptive_stats`。数值字段给 n, mean, SD, SE, median, Q1, Q3, IQR, min, max,
   skew, kurt；分类字段给 n、频数、百分比。均值/SD 多一位小数，百分比一位小数。*门控*：各组 n 之和=总数。
4. **推断统计**：冻结 `inference_results`，按 Q1–Q4 选**唯一**方法：
   Q1 组数（1 组→单样本 t/Wilcoxon；2 组独立→独立 t/Welch t/Mann-Whitney U；2 组配对→配对 t/Wilcoxon；
   ≥3 组独立→ANOVA/Welch ANOVA/Kruskal-Wallis，事后 Tukey HSD/Games-Howell/Dunn；重复测量→RM-ANOVA/Friedman）；
   Q2 正态性（n<50/组→Shapiro-Wilk；n≥50→Shapiro-Wilk+Q-Q）；Q3 方差齐性（Levene，敏感时 Brown-Forsythe）；
   Q4 多重比较（k 次→Bonferroni α/k 或 BH-FDR）。*门控*：附正态与方差齐结果，依据链可追溯。
5. **效应量与 CI**：冻结 `effect_sizes`。Cohen's d 的 CI 用非中心 t 分布法或 bootstrap（B=2000, seed=42）；
   η²_p 用 F 分布非中心参数法。*门控*：每个效应量带 CI，CI 方向与 p 一致（不含 0 ↔ p<α）。
6. **解读与交付**：`result.json` + 报告 + 可执行代码。模板：「α=0.05 时 [检验名] 显示 [组A] 与 [组B]
   在 [变量] 上差异[有/无]统计学意义（t(df)=X.XX, p=X.XXX, 95% CI [L,U]）；d=X.XX（95% CI [L,U]），按
   Cohen(1988) 属[小/中/大]效应。注意：[正态/方差齐]、[样本量]、[缺失影响]。」
   *门控*：含全部 output_contract 字段，代码可复现全部数字。

## 3. 公式与容差

- 合并标准差 \(S_{pooled}=\sqrt{\frac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}}\)；Cohen's d \(=(\bar X_1-\bar X_2)/S_{pooled}\)；
  Hedges' g \(=d(1-\frac{3}{4(n_1+n_2)-9})\)（n<20 推荐）。
- 均值差 95% CI \(=(\bar X_1-\bar X_2)\pm t_{0.025,df}S_{pooled}\sqrt{1/n_1+1/n_2}\)；
  Welch 自由度 \(df=\frac{(S_1^2/n_1+S_2^2/n_2)^2}{\frac{(S_1^2/n_1)^2}{n_1-1}+\frac{(S_2^2/n_2)^2}{n_2-1}}\)。
- 偏 η² \(=SS_{effect}/(SS_{effect}+SS_{error})\)；配对 \(d_z=M_{diff}/SD_{diff}\)；秩双列 \(r=Z/\sqrt N\)；
  Cramér's V \(=\sqrt{\chi^2/(n\min(r-1,c-1))}\)。
- 容差：均值 ±0.01；p ±0.001；d ±0.02；CI 边界 ±0.05；Shapiro-Wilk W ±0.005。基准（Cohen 1988）：d 0.2/0.5/0.8；η² 0.01/0.06/0.14。

## 4. 领域陷阱

分类变量（组别编码 1,2,3）只算频数与百分比；Likert/ordinal 用 Mann-Whitney 或有序 logistic；比例数据用
χ² 或 logistic 回归；SD 描述离散度、SE 描述均值精度，误差棒不可互换；p>0.05 写「未检测到显著差异」；
统计效应大小 ≠ 临床意义；ANOVA 显著后必须事后比较并校正；非参数仍假设独立性与同分布形状；
量纲：μg/mL=mg/L、°C vs K、MPa vs psi（1 MPa=145.038 psi）、时间秒/分/时可混、SQLite 数值可能为 TEXT、
日期多格式需统一。依据：Cohen (1988)；Wilcox (2017)；Borenstein et al. (2009)；APA 7th。

## 5. 交付物与 locator

必需：`result.json` + 清洗日志（n_before−affected=n_after 可复核）、描述统计、推断结果（依据链可追溯）、
效应量（含 CI 方法与 seed）、可执行代码、可读报告、环境版本。图表：分布用直方图+密度+箱线；两组用带
jitter 箱线图+均值±CI；多组用箱线图矩阵+事后标注；相关性用散点+回归线+r。每个数字的 locator：
`{文件} → {字段/行号} → {公式}`，如 `descriptive_stats → row: compressive_strength, group: A → mean`。

## 7. 虚构案例（自洽校验）

比较外加剂 A/B 的 28 天抗压强度（MPa）。原始 13 行含 1 重复（id=1）、1 缺失（id=3）、1 异常（102.3）。
清洗：去重 13→12；id=3 完整案例分析排除（A 组 n=4）；A 组 IQR 上限 41.10，故 102.3 Winsorize 至 41.10。
清洗后 A（n=5）M=37.740 SD=2.203，B（n=6）M=31.300 SD=1.259。Shapiro W=0.932/0.958（p=0.619/0.794），
Levene F(1,9)=1.078 p=0.326 → 独立样本 t：\(S_{pooled}=1.743\)、\(SE_{diff}=1.055\)、t=6.104、df=9、
p<0.001，d=3.695、g=3.378、均值差 95% CI=[4.053,8.827]（不含 0 ↔ p<0.001）。解读：A 与 B 差异有统计学
意义（t(9)=6.104, p<0.001, 95% CI [4.05,8.83] MPa），d=3.70 远超 0.8 大效应；注意 1 异常已 Winsorize、
1 缺失被排除、样本量小已校正、正态与方差齐均通过、建议补样验证。
