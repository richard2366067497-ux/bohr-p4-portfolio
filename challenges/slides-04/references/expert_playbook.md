# 专家参考手册 —— 学术汇报幻灯片（PPTX）自动化交付（slides-04）

## 1. 交付什么（判分要点）

核心目标不是"生成一份好看的 PPT"，而是交付一套**可复核、可编辑、证据可追溯**的学术汇报产物。每套交付必须包含：

- 可编辑 `pptx`：真实继承模板母版、版式、占位符，而不是把内容粘进空白页。
- 导出渲染件：`PDF` 及至少 1 张 `PNG` 预览，且与 `pptx` 渲染一致。
- 页级证据映射：每页内容对应论文的图、表、章节或数据定位。
- 渲染与版本记录：源文件、导出件、字体/模板、修改记录、运行状态。
- `result.json`：包含 `case_id`、状态、来源定位、不确定性、变更记录等原始输出契约字段。

### 1.1 验收维度

| 验收维度 | 关键考察点 |
|-|-|
| 实际效果 | 模板真实套用；页内文字/数字/图号与源材料一致；六类要素覆盖；他人可独立复跑 |
| 使用增益 | 相比基础生成流程质量提升；减少排版耗时与返工；有公平对照证据 |
| 创新增益 | 内容-版式映射、字号间距规则、图表缩放策略、批量一致性校验等方法改进 |
| 可靠体验 | 调用易用；不同模板/页数/字体环境下稳定；异常处理明确 |
| 生态贡献 | 文档完整；资源可复用；沉淀可分享的规则与实践 |

### 1.2 常见失败模式：错误做法 → 正确做法

| 错误做法 | 正确做法 |
|-|-|
| 论文原文整段粘进默认模板，母版/版式未继承 | 先解析模板母版、版式、占位符，将内容写入对应版式，保留主题字体与主题色 |
| 文本框溢出后把字号压到不可读（如 8pt） | 设定字号下限（正文≥14pt，标题≥20pt），溢出时优先拆分内容或调整版式，不突破下限 |
| 图表图片拉伸变形 | 按容器等比缩放或裁切，保留坐标轴与图例可读性，记录缩放比例 |
| 图号与正文引用错位 | 建立图号-引用映射表，生成后逐页校验 |
| 只修封面和前三页，其余页面仍是旧模板 | 批量应用规则到整册，逐页检查版式继承 |
| 导出 PDF 后字体被替换、图片丢失 | 导出前嵌入字体，导出后用 `pdffonts` 检查字体嵌入，用 `pdftotext` 对比文本 |
| 只交付 pptx，无证据映射与渲染记录 | 同时交付 `evidence_map.json`、`render_log.json`、`result.json` |

## 2. 分步流程与门控

从输入材料到交付物的九个步骤，每步有冻结产物与通过条件：

| 步骤 | 冻结产物 | 门控（通过条件） |
|-|-|-|
| 1. 输入解析 | `input_manifest.json`：列出 case.json、task.md、paper.pdf、figures/、template.pptx 等实际文件路径与哈希 | 所有必需文件存在且可读；PDF 页数、图片数量、模板版式数量已记录 |
| 2. 证据提取 | `evidence_extract.json`：研究问题、方法、结果、限制；每项带 `locator`（如 `paper.pdf:page=3:para=2`） | 至少提取 4 类主线要素；每条主张有来源定位；无事实性改写 |
| 3. 主线设计 | `storyline.json`：页级主张、讲解顺序、图表引用计划 | 页数符合 task.md 要求；每页 1 个主主张 + 2-3 个支撑点；图表引用与正文一致 |
| 4. 模板分析 | `template_profile.json`：母版、版式、占位符、主题字体、主题色、版心尺寸 | 识别出至少 1 个母版和 3 个版式；记录主题色 HEX 值；占位符缺失时给出替代方案 |
| 5. 页级映射 | `page_map.json`：每页 → 版式 → 占位符 → 内容 → 证据 locator | 每页有明确版式；内容与证据一一对应；无溢出（或溢出已处理） |
| 6. 生成 pptx | `deck.pptx` | 文件可打开；母版/版式继承真实；无占位符丢失；字号、颜色、对齐符合规则 |
| 7. 渲染校验 | `deck.pdf`、`deck_preview.png`、`render_log.json` | PDF 页数与 pptx 一致；字体全部嵌入；文本差异率 <1%；PNG 渲染无异常 |
| 8. 证据映射与记录 | `evidence_map.json`、`change_log.md`、`result.json` | 每页有 locator；变更记录完整；result.json 包含所有必需字段 |
| 9. 输出打包 | `/app/output/` 下所有交付物 | 文件齐全；路径有效；无临时文件混入 |

**时间分配参考**（总 900s）：输入解析 60s；证据提取 120s；主线设计 90s；模板分析 60s；生成 pptx 180s；渲染校验 120s；修复 120s；记录 60s。留 90s 余量应对异常与重试。

## 3. 量化口径、公式与容差

### 3.1 关键指标定义与公式

| 指标 | 定义/公式 | 单位 | 可接受波动 | 计算示例 |
|-|-|-|-|-|
| 页数符合率 | 实际页数 / 要求页数 × 100% | % | ≥90% | 要求 12 页，实际 12 页，符合率 100% |
| 每页主张数 | 主主张数 / 内容页数 | 个/页 | 1-2 个/页 | 12 页中 10 页内容页，主主张 10 个，平均 1.0 |
| 文本框溢出率 | 溢出文本框数 / 总文本框数 × 100% | % | 0% | 总 48 个文本框，溢出 0 个，溢出率 0% |
| 字号层级 | 标题字号 ≥ 20pt，正文 ≥ 14pt，注释 ≥ 10pt | pt | 标题≥20，正文≥14 | 标题 24pt，正文 16pt，注释 10pt |
| 对比度 | WCAG 对比度 = (L1+0.05)/(L2+0.05)，L 为相对亮度 | 比值 | 正文≥4.5:1，大标题≥3:1 | 主题色 #1F4E79 与白色对比度约 8.6:1，通过 |
| 图片缩放比例 | 实际显示尺寸 / 原始尺寸（等比） | 比值 | 0.5-2.0，且无变形 | 原始 1200×800px，容器 10×6.67cm，比例 1.5，等比缩放 |
| 图号引用一致性 | 正文引用图号与图片编号匹配数 / 总引用数 × 100% | % | 100% | 引用 5 个图号，全部匹配，一致性 100% |
| 母版继承率 | 使用母版/版式的页数 / 总页数 × 100% | % | ≥90% | 12 页中 12 页使用版式，继承率 100% |
| 导出文本差异率 | `diff` 字符差异数 / 总字符数 × 100% | % | <1% | 总 3200 字符，差异 10 字符，差异率 0.31% |
| 证据映射覆盖率 | 有 locator 的内容页数 / 总内容页数 × 100% | % | ≥90% | 10 页内容页中 9 页有 locator，覆盖率 90% |

### 3.2 文本框溢出检测公式

```
可容纳字符数 ≈ (容器宽度 / 单字符宽度) × (容器高度 / 行高)
行高 = 字号 × 行距倍数
单字符宽度 ≈ 字号 × 0.6（中文）或 0.35（英文）
```

示例：容器 24cm × 6cm，字号 18pt，行距 1.2。
单字符宽度 ≈ 18pt × 0.6 = 10.8pt ≈ 0.38cm（1pt ≈ 0.0353cm）。
每行字符数 ≈ 24 / 0.38 ≈ 63 字符。
行高 ≈ 18pt × 1.2 = 21.6pt ≈ 0.76cm。
可容纳行数 ≈ 6 / 0.76 ≈ 7.9 行，取 7 行。
可容纳字符数 ≈ 63 × 7 = 441 字符。
若实际文本 420 字符，则不溢出；若 480 字符，则溢出 39 字符，需缩减字号至 16pt 或拆分内容。

### 3.3 渲染一致性校验命令

```bash
# 导出 PDF
libreoffice --headless --convert-to pdf --outdir /app/output /app/output/deck.pptx

# 检查字体嵌入
pdffonts /app/output/deck.pdf

# 提取 PDF 文本与 pptx 文本对比
pdftotext /app/output/deck.pdf /tmp/pdf.txt
python extract_pptx_text.py /app/output/deck.pptx > /tmp/pptx.txt
diff <(tr -d '[:space:]' < /tmp/pptx.txt) <(tr -d '[:space:]' < /tmp/pdf.txt) | wc -l

# 渲染 PNG 预览
pdftoppm -png -r 150 /app/output/deck.pdf /app/output/deck_preview
```

## 4. 领域陷阱与事实性错误（错误做法→正确做法）

### 4.1 容易犯的事实性错误

- **数据改写**：不得将"效率从 22.1% 提升至 25.3%"写成"约 25%"或"显著提升"。必须逐字保留数字与单位。
- **图号错位**：正文引用"图 2"但图片实际编号为"图 3"。必须建立图号-引用映射表。
- **单位错误**：如将"mA/cm²"写成"mA/cm2"或"mA cm⁻²"。必须保留原论文单位格式。
- **字体回退**：中文字体缺失导致回退为宋体或黑体，版式错乱。必须指定中英文字体搭配，如中文"思源黑体"、英文"Calibri"。
- **对比度不足**：浅色文字放在浅色背景上。必须计算 WCAG 对比度，正文≥4.5:1。
- **矢量图与位图混排**：矢量图导出为低分辨率位图导致模糊。必须保留矢量图或使用高分辨率位图（≥300dpi）。
- **备注错位**：讲稿备注与页面内容不对应。必须逐页检查备注与主主张一致。

### 4.2 单位/量纲陷阱

- 字号单位：pt（点）与 px（像素）不可混用。1pt ≈ 1/72 英寸，1px 取决于屏幕 DPI。
- 长度单位：cm、mm、inch 转换。1 inch = 2.54 cm = 25.4 mm。
- 图片分辨率：dpi（每英寸点数）与像素尺寸。300dpi 下 10cm 宽需要 10/2.54×300 ≈ 1181 像素。
- 对比度计算：使用 WCAG 相对亮度公式，不可用 RGB 差值代替。

### 4.3 文献依据要求

- 每条主张必须带 `locator`，格式：`paper.pdf:page=<页码>:para=<段落号>` 或 `paper.pdf:fig=<图号>` 或 `paper.pdf:table=<表号>`。
- 不得使用"论文提到""研究表明"等模糊表述。
- 引用图表时，必须同时给出图表编号和页码。

## 5. 交付物、证据与 locator

| 文件/章节 | 内容 | 自证可核验方式 |
|-|-|-|
| `SKILL.md` | 用途、适用条件、调用方式、输入输出、异常处理 | 按说明可独立运行；YAML frontmatter 有效 |
| `scripts/` | 模板分析、证据提取、pptx 生成、渲染校验脚本 | 脚本可执行；路径有效；版本号记录 |
| `config/` | 字号阶梯、颜色主题、对比度阈值、缩放规则 | 参数含义齐全；可被他人复用 |
| `template_adapter/` | 模板母版/版式/占位符映射规则 | 记录模板版本与适配逻辑 |
| `deck.pptx` | 可编辑演示文件 | 可打开、播放、编辑；母版继承真实 |
| `deck.pdf` | 导出渲染件 | 页数与 pptx 一致；字体嵌入；文本差异率 <1% |
| `deck_preview.png` | 渲染预览图 | 与 PDF 渲染一致；无异常 |
| `evidence_map.json` | 每页内容 → 论文 locator | 每页有 locator；引用准确 |
| `render_log.json` | 导出命令、字体检查、文本对比、像素差异 | 记录完整；可复跑 |
| `change_log.md` | 修改记录：溢出处理、字号调整、图片缩放等 | 逐条记录；与最终文件一致 |
| `result.json` | `case_id`、状态、来源、不确定性、变更记录 | 包含所有原始输出契约字段；诚实标注限制 |

locator 规则：每页内容必须锁定到论文的具体位置（页码、图号、表号或章节），并保证正文引用与图表实际编号一致。

## 7. 虚构案例（自洽校验）

### 7.1 输入

- `case_id`: `ppt-710fbc72-demo`
- `task.md`: 要求 12 页学术组会汇报，15 分钟，观众为课题组，需覆盖研究问题、方法、结果、限制。
- `paper.pdf`: 12 页论文《高效钙钛矿太阳能电池的界面工程》，含 5 个图、2 个表。
- `figures/`: `fig1.png`（1200×800px）、`fig2.png`（1200×900px）、`fig3.svg`、`fig4.png`（800×600px）、`fig5.png`（1600×1200px）。
- `template.pptx`: 大学学术模板，16:9，母版 1 个，版式 6 个（封面、节标题、内容、两栏、图表、致谢），主题色 `#1F4E79`，中文字体"思源黑体"，英文字体"Calibri"。

### 7.2 关键中间量

**证据提取**（`evidence_extract.json` 片段）：
```json
{
  "research_question": "界面缺陷如何限制钙钛矿太阳能电池效率？",
```

- `deck.pdf` 12 页，与 pptx 一致。

- `pdftotext` 提取文本 3200 字符，与 pptx 文本差异 10 字符，差异率 0.31%。
- PNG 预览渲染正常，无图片丢失。
