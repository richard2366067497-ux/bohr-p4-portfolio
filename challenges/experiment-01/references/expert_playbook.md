## 1 判分要点与失败模式

交付物是**一份可排期、可执行、可被同行评审的实验方案**，而非研究目标复述或教科书式通用流程。
一个有经验的实验人员拿到它应能不额外追问即开始排期操作。

| 关注点 | 判定标准 |
|--------|----------|
| 假设可检验性 | 假设能写成"若 X 变化 Δ，则 Y 变化 ≥ δ"的条件句 |
| 变量操作定义 | 每个变量有测量方法、单位、量程、精度 |
| 对照排他性 | 每个对照明确排除哪一类混杂因素 |
| 资源可落地性 | 设备型号/量程/耗材规格/时间预算均已绑定 |
| 风险可处置性 | 每种失败模式有判据、止损点和替代路径 |

常见失败（错误 → 正确）：

| # | 错误做法 | 正确做法 |
|---|----------|----------|
| F1 | 假设写成"探究 A 对 B 的影响" | "当 A 从 a1 增至 a2 时，B 预期变化 ≥ δ（α=0.05, power=0.8）" |
| F2 | 变量只有名称无操作定义 | 每个变量附测量仪器、方法、单位、量程、分辨率 |
| F3 | 只设空白对照 | 空白 + 阳性 + 梯度对照（≥3 水平） |
| F4 | 设备写"分光光度计" | 写明型号、波长范围、带宽 |
| F5 | 时间写"若干小时" | 步骤分钟数 + 并行甘特图 + 关键路径总时长 |
| F6 | 风险写"注意安全" | 失败模式、概率等级、判据阈值、止损点、替代方案 |
| F7 | 参数不写来源 | 标注来源：设备手册 / 文献 [DOI] / 预实验数据 |
| F8 | 无版本与变更记录 | 首版 v1.0，每次修改附 change log 与理由 |
| F9 | 样本量拍脑袋 | 功效分析：效应量 d、α、power → 最小样本量 n |
| F10 | 预算缺失或虚估 | 耗材单价 × 用量 + 设备机时费 × 时长逐项列出 |

## 2 求解框架（6 步法）与门控

逐步推进，**前一步未冻结不进入下一步**：

| 步 | 动作 | 冻结产物 | 门控 |
|----|------|----------|------|
| S1 | 解析目标 → 拆 1–3 个可检验假设，写成条件句 | `hypothesis_table` | 每个假设中所有变量均有操作定义 |
| S2 | 列自变量/因变量/混杂，填操作定义、仪器、量程、分辨率 | `variable_registry` | 无"待定"字段；每变量绑定 ≥1 可执行测量方法 |
| S3 | 为每个自变量设空白/阳性/剂量梯度（≥3），注明排除的混杂 | `control_matrix` | 每个假设 ≥1 个证伪对照 |
| S4 | 拆步骤（单人单次粒度），绑设备/耗材/参数，标依赖、算关键路径、估时长、功效分析、逐项预算 | `protocol_schedule` | 关键路径 ≤ 时间窗；预算 ≤ 约束预算 |
| S5 | 提取关键参数，标允许区间、最优值、来源、超限处置 | `parameter_spec` | 无参数来源为空 |
| S6 | 枚举失败模式（每步 ≥1），标判据/概率等级/止损点/替代路径，设全局止损 | `risk_registry` | 每种 H 级风险有替代路径 |

**映射到本 Skill 产物**：S1–S3↔`plan_report.md` 的六要素（假设与变量/对照）；S4↔时长与
`arithmetic_ledger.json`；S5↔参数区间与来源；S6↔风险段；三版本对比↔`plan_revised.json` 与
`version_diff.md`；六条校验规则↔`validation_report.json`；复现↔`reproduce.md`；证据↔`evidence.json`。

## 3 量化口径（逐条可复算）

### 3.1 样本量功效分析（两独立样本 t 检验）

```
n = 2 × ((z_α/2 + z_β) / d)²
```

| 符号 | 含义 | 常用取值 |
|------|------|----------|
| z_α/2 | 显著性水平对应 z 值 | α=0.05 → 1.96 |
| z_β | 检验功效对应 z 值 | power=0.80 → 0.84 |
| d | Cohen 效应量 | 小 0.2 / 中 0.5 / 大 0.8 |

示例：d=0.5, α=0.05, power=0.80 → n = 2×((1.96+0.84)/0.5)² = 2×5.6² = 62.72 → **每组 63**。
若 3 实验组 + 1 对照组，总样本量 = 4 × 63 = **252**。

### 3.2 时间成本（关键路径法）

有依赖的步骤串行、无依赖的可并行；关键路径 = 最长串行链；总时长 = 关键路径 + 缓冲（建议 15%）。

| 步骤 | 时长 (min) | 前置 | 并行 |
|------|-----------|------|------|
| S1 样品制备 | 45 | 无 | A |
| S2 试剂配制 | 30 | 无 | B |
| S3 反应 | 120 | S1,S2 | — |
| S4 表征 | 60 | S3 | — |
| S5 数据整理 | 30 | S4 | — |

关键路径 S1(45)→S3(120)→S4(60)→S5(30) = **255 min**；含 15% 缓冲 = 293 min ≈ 4.9 h。

### 3.3 预算估算口径

| 类别 | 计算方式 | 示例 |
|------|----------|------|
| 耗材 | 单价 × 数量 × (1+10% 损耗) | 比色皿 ¥15 × 252 × 1.1 = ¥3,961 |
| 试剂 | 单价 × 用量/规格 | PBS ¥80/500mL × 2 = ¥160 |
| 设备机时 | 时费率 × 关键路径时长 | ¥200/h × 4.9h = ¥980 |
| 人工 | 时薪 × 操作时长 × 人数 | ¥50/h × 4.9h × 1 = ¥245 |

本 Skill 的 `arithmetic_ledger.json` 采用同一口径：`金额 × 单价` 逐项加总为单次成本，
`× 重复数` 为总成本；逐行写出并自检（行和 = 单次成本；单次 × 重复 = 总成本；≤ 预算）。

### 3.4 风险等级与参数允许偏差

| 等级 | 概率 | 处置 | | 参数类型 | 允许偏差 |
|------|------|------|-|----------|----------|
| H | >30% | 替代路径 + 预案演练 | | 温度（恒温设备） | ±1 °C |
| M | 5–30% | 判据 + 止损点 | | 温度（马弗炉） | ±3 °C |
| L | <5% | 记录即可 | | 时间（>1 h） | ±5% |
| | | | | 浓度（体积法） | ±2% |
| | | | | pH（校准后） | ±0.1 |
| | | | | 称量（万分之一） | ±0.1 mg |

## 4 领域陷阱与单位

| 错误 | 正确 |
|------|------|
| 混同 SEM 与 TEM 分辨率 | SEM 典型 1–10 nm；TEM 可达 0.1 nm |
| 认为 XRD 可测非晶相含量 | XRD 主测晶相；非晶需 PDF/Raman 辅助 |
| 摩尔浓度与质量浓度混淆 | mol/L vs g/L 换算需分子量，写公式时注明 |
| 认为超声功率 = 标称功率 | 实际传递功率通常为标称 30–70%，需校准 |
| 高温未考虑热电偶位置偏差 | 样品实际温度与设定可差 10–30 °C |
| ppm 含义模糊 | 明确写 mg/kg 或 mg/L 或 μmol/mol |
| rpm 与 RCF 混用 | RCF = 1.118×10⁻⁵ × r(mm) × rpm²，标明用哪个 |
| sccm 与 mL/min 不分 | sccm 为标准状态 (0°C,1atm)；mL/min 为实际状态 |

关键参数来源优先：设备手册 > 已发表论文（附 DOI）> 预实验数据；不可引用百度百科/维基/未验证博客。

## 6 完整案例（水热法合成 TiO₂ 纳米棒）

> 目标：使纳米棒平均长度达 200±30 nm、长径比 ≥5。约束：预算 ≤ ¥8,000；时间窗 ≤ 5 工作日；
> 设备：水热釜(100 mL,≤250 °C)、管式炉(≤1200 °C)、SEM(3 nm)、XRD、TEM(可选 ¥500/h)。

**假设**：H1 水热温度 160→200 °C 使长度增加 ≥50 nm；H2 NaOH 5→15 M 使长径比提升 ≥2；
H3 煅烧 ≥450 °C 时锐钛矿纯度 ≥95%（均 α=0.05, power=0.8）。

**变量登记（节选）**：水热温度（自变量，热电偶，100–250 °C，±1 °C）；纳米棒长度（因变量，
SEM+ImageJ 量测 ≥50 根，10 nm–10 μm，3 nm）；晶相纯度（XRD Rietveld，10–80° 2θ，0.02°）。

**对照**：空白（不加钛前驱体，排除基底自身成核）；阳性（文献 180°C/10M，长度≈150 nm）；
温度梯度 160/170/180/190/200 °C；浓度梯度 5/8/10/12/15 M。

**关键路径**：S1(30)→S2(15)→S3(720)→S4(45)→S5(360)→S6(180)→S7(60)→S9(60) = 1470 min = 24.5 h；
含 15% 缓冲 ≈ 28.2 h，分 5 天执行每天 ≈5.6 h，满足时间窗。

**样本量**：d=0.8 → n = 2×((1.96+0.84)/0.8)² = 24.5 → **每组 25**；10 组 × 25 = 250 次测量。

**预算（节选）**：钛酸四丁酯 ¥180 + NaOH ¥70 + 乙醇 ¥100 + 内衬 ¥300 + SEM(¥200/h×10h)=¥2,000
+ XRD(¥150/h×5h)=¥750 + 管式炉(¥80/h×30h)=¥2,400 + 损耗 10% ¥580 = **¥6,380 ≤ ¥8,000**。

**风险（节选）**：团聚严重（M，SEM >50% 面积，连续 2 组出现 → 加 PVP 0.5 wt% 重做）；
长度不达标（M，最优组 <170 nm → 延长水热至 18h）；XRD 杂峰（L，非锐钛矿 >5% → 提高煅烧温度）。
全局止损：累计 3 组失败 或 时间 >5 天 或 支出 >¥7,500 → 暂停并出中间报告。

## 7 专家注意点（逐条排雷）

1. **可执行优先**：每个描述都要能落成"谁、用什么、做什么、多久"，否则降级为"待确认"项。
2. **数量自洽**：样本量 × 组数 = 总测量数；预算 = 各项加总 ±5%；关键路径 = 最长串行链。
3. **对照证伪**：对每个假设问"哪个对照能证伪它"。
4. **来源可查**：数值型引用必须可追溯（DOI/卷期页码/手册章节）；无法确认标注"待验证"。
5. **假设≠事实**：未确认内容写"假设"或"待确认"，不写成可执行步骤。
6. **并行标注**：无依赖步骤标并行，避免把总时长简单相加而高估工期。
7. **硬约束 vs 软约束**：硬约束（安全阈值）不可违反；软约束可在论证下放宽，文中须标注类型。
8. **缺失即声明**：输入缺料时明确写缺什么、影响是什么、如何补充。
