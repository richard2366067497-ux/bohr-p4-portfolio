# 专家参考手册 —— 科研数据分析流水线（analysis-05）

执行前**完整阅读本手册**，按 §2 八步流程推进，交付前逐项过 §7 自查表。本领域把科研材料表做成
可复核的数据分析交付：导入 → 清洗（行数守恒）→ 描述与推断统计 → 真实 SVG 图件 → 报告，
全部数字来自同一套登记表，每个打印出来的数字都能回算到源列与源行。

## 1. 质量维度（判分要点）

- **实际效果（40）**：五段是否在同一环境串通；数值、统计口径、图形是否算对；题目要求的字段、检查点、
  产物是否覆盖；证据链是否完整到可重跑。
- **使用增益（25）**：相比朴素做法，分析质量是否稳定提升；是否减少人工改代码、补字段、重跑次数；是否用公平对照证明。
- **创新增益（15）**：是否形成朴素做法不具备的能力——步骤编排、检查点设计、失败回退的实质改进。
- **可靠体验（10）**：能否正确触发；不同数据形态、规模、重复运行下是否稳定；对空表、列缺失、类型不符、
  除零、编码错误、数据库连接失败的识别与处置。
- **生态贡献（10）**：文档完整；脚本、题集、样例数据、字段字典、评分表可被他人直接部署复跑。

## 2. 求解流程（8 步，每步有冻结产物与门控，前一步未过门控不得进入下一步）

0. **读取输入与环境**：读 `case.json` 取 case_id、数据文件路径、任务说明路径；读 `task.md` 解析要求/检查点/约束；
   读 `environment/resources.yaml` 确认可用工具与库版本。*冻结* `input_snapshot.json`。
   *门控*：数据文件存在可读；任务无歧义；记原始输入哈希。
1. **导入与字段对齐**：按扩展名选读取方式（CSV→`read_csv`，SQLite→`sqlite3`）；检查字段名/类型/单位；
   多表识别主键并对齐；输出字段映射（原始名 → 标准名 → 类型 → 单位）。*冻结* `raw_data.csv` + `field_mapping.json`。
   *门控*：所有必需字段存在；类型与字典一致；无编码错误。
2. **数据质量审计**：逐列统计缺失数/缺失率/唯一值数/重复行数/异常候选；记形状（行×列）、内存占用。
   *冻结* `quality_audit.json`。*门控*：审计完整，无未解释的缺失或异常。
3. **清洗规则制定与执行**：明确缺失填补（中位数/均值/删除）、异常阈值（IQR 1.5 或 z>3）、重复处理（保留首次/最后/合并）；
   执行并记每步前后行数/列数/受影响行号。*冻结* `cleaning_rules.json` + `cleaned_data.csv` + `cleaning_log.txt`。
   *门控*：规则与实际执行一致；清洗后可复算；**无静默丢数据**。
4. **统计分析与假设校验**：按任务选描述统计/t/ANOVA/相关；先检前提（Shapiro-Wilk、Levene、独立性）；
   报效应量、置信区间、p 值。*冻结* `statistics_results.json`。*门控*：方法选择有依据；前提结果明确；数字可复算。
5. **可视化与图表选型**：按形态与意图选图（组间比较箱线/小提琴、趋势折线、分布直方图）；坐标轴标单位，
   误差线表示 SD 或 CI；保存图表数据源。*冻结* `figures/*.png` + `figure_data.csv`。
   *门控*：图表可读，坐标轴、聚合层级、误差表示与底层数据一致。
6. **报告生成与数字回填**：自动生成报告，正文数字/表格/图形从同一分析对象回填；含方法、结果、不确定性、异常说明。
   *冻结* `report.md` + `report.pdf`。*门控*：报告数字与 `statistics_results.json` 完全一致；无手工输入数字。
7. **质量检查与打包**：检查所有输出存在可读；`result.json` 含全部必需字段；记运行状态、失败步骤、不确定性。
   *冻结* `result.json` + `output_manifest.json`。*门控*：他人可按 manifest 复跑；无缺失文件。

## 3. 常见失败模式（错误做法 → 正确做法）

| 错误做法 | 正确做法 |
|---|---|
| 只输出结论和一张截图，无中间数据 | 保留原始快照、清洗规则、每步行数变化、统计输出、图表数据源 |
| 静默删除缺失/异常，不记规则 | 明确填补或删除规则、优先级、影响行数；异常值标记而非默认删除 |
| 规则写一套、实际执行另一套 | 规则表与实际代码/日志一一对应，可逐条核对 |
| 图表与正文数字不同源 | 图表数据直接来自清洗后 DataFrame，报告数字从同一对象回填 |
| 不检查假设直接做 t/ANOVA | 先做 Shapiro-Wilk、Levene，报告结果并说明方法选择依据 |
| 把 p 值当效应量，只报「显著」 | 同时报效应量（Cohen's d / η²）、置信区间、均值差 |
| 硬编码答案或预生成结果 | 读取实际 `case.json` 与 `task.md`，动态执行分析 |
| 不读实际文件，凭标签假设内容 | 用 `read_csv`/`sqlite3.connect` 读实际数据，核对字段名与类型 |
| `result.json` 缺字段或不可解析 | 严格含 `case_id`、`status`、`results`、`evidence`、`uncertainty` |
| 遇到异常直接崩溃，无部分结果 | 捕获异常，保存诚实部分结果，标注失败步骤和原因 |
| 路径写死，换环境跑不通 | 用相对路径或从环境变量读，所有资源在包内 |
| 不记录版本与运行时间 | 记录数据源版本、脚本版本、运行时间、库版本 |

## 4. 量化口径与公式

- **缺失率**：`缺失数 / 总行数 × 100%`（%，1 位小数）；同源重复运行应完全一致，不同抽样可 ±0.5%。
- **重复记录率**：`完全重复行数 / 总行数 × 100%`；默认保留首次、删后续；判定须基于**所有字段完全一致**，不能仅凭主键。
- **异常值（IQR 法）**：下界 `Q1 − 1.5×IQR`，上界 `Q3 + 1.5×IQR`；偏态时可用 z>3 或 MAD，但须说明理由。
- **效应量 Cohen's d（两组独立）**：`d = (mean₁ − mean₂) / s_pooled`，
  `s_pooled = √[((n₁−1)s₁² + (n₂−1)s₂²)/(n₁+n₂−2)]`；|d|<0.2 小、0.2–0.5 中、0.5–0.8 大、>0.8 很大，保留 2 位小数。
- **独立样本 t**：`t = (mean₁ − mean₂)/SE`，`SE = s_pooled×√(1/n₁+1/n₂)`，`df = n₁+n₂−2`；p 保留 3 位小数，
  `p<0.001` 记 `p<0.001`。
- **方差齐性 Levene**：p≥0.05 用 Student t；p<0.05 用 Welch t。
- **正态性 Shapiro-Wilk**：p≥0.05 接受正态；p<0.05 考虑非参数（Mann-Whitney U）或变换；n>50 可能过敏感，结合 Q-Q 图。

**计算示例（Iris，setosa vs versicolor 的 sepal length）**：n₁=n₂=50，mean₁=5.006 sd₁=0.352，
mean₂=5.936 sd₂=0.516；均值差 0.930 cm；`s_pooled=√[((49×0.352²+49×0.516²)/98)]=√[(6.071+13.049)/98]=0.4417`；
`SE=0.4417×√(1/50+1/50)=0.08834`；`t=0.930/0.08834=10.53`，df=98，p<0.001；`d=0.930/0.4417=2.10`；
95% CI `=0.930±1.984×0.08834=[0.755,1.105] cm`。

## 5. 领域知识清单

**数据集事实（当前固定案例）**

| 数据集 | 行数 | 特征数 | 类别/目标 | 单位 |
|---|---|---|---|---|
| Iris | 150 | 4（sepal/petal length/width） | 3 类各 50 | 厘米（cm） |
| Wine | 178 | 13 个化学成分 | 3 类（class 0/1/2） | 各特征不同：mg/L、OD 等 |
| Concrete | 1030 | 8 个成分 + 1 目标 | 抗压强度 | 成分 kg/m³，龄期天，强度 MPa |

**容易犯的事实性错误**
1. 把类别编码当连续变量（Iris species 不能算均值/做 Pearson）。
2. 忽略单位（Iris 特征 cm，Wine 各特征不同，Concrete 强度 MPa、成分 kg/m³）。
3. 缺失值补 0（严重扭曲分布；应中位数/均值填补或删除并记规则）。
4. 重复记录误判（仅凭主键可能漏完全重复行；须查所有字段）。
5. 统计前提不检验（直接 t/ANOVA 结论不可靠）。
6. 多重比较不校正（用 Tukey HSD 或 Bonferroni）。
7. 把 p 值当效应量（p<0.05 只说明有统计学意义，必须报效应量）。
8. 图表坐标轴不标单位。
9. 数据库字段类型错误（SQLite 数值可能存为 TEXT，读后需转换）。
10. 忽略异常值影响（应标记并说明处理方式，不能静默删除）。

**依据**：数据来源注明（Iris/Wine/Concrete 来自 UCI）；统计方法引用标准教材或文献（Shapiro-Wilk、Levene、
Cohen's d）；用非参数检验注明理由；所有数字可追溯到原始行号或统计输出。

## 6. 交付物与可核验性（`/app/output/`）

`result.json`（case_id、status、results、evidence、uncertainty，含全部 output_contract 字段）；
`cleaned_data.csv`（行数/列数与日志一致，可复算）；`cleaning_rules.json`（每条对应日志执行记录）；
`cleaning_log.txt`（每步行数变化、受影响行号）；`statistics_results.json`（统计、效应量、置信区间、方法依据）；
`figures/*.png`（数据源存 CSV，坐标轴标单位）；`report.md`/`report.pdf`（数字与统计结果一致）；
`quality_audit.json`（缺失率、重复率、异常候选）；`output_manifest.json`（文件路径与哈希）。
**可核验三要素**：locator（如「均值差 0.930 cm，来源 `statistics_results.json` 中 `t_test.mean_diff`」）；
逐字引用（报告数字与统计输出逐字一致，不四舍五入后不一致）；复算命令
（如 `python scripts/run_analysis.py --input /input/case.json --output /app/output`）。

## 7. 防扣分自查表（交付前逐项通过）

7. 是否对缺失/异常/失败查询明确说明而非静默修改？ 8. 是否检查统计前提（正态性、方差齐性、独立性）？
9. 是否报告效应量（Cohen's d / η²）与置信区间，而非只报 p？ 10. 是否对多重比较校正（Tukey HSD / Bonferroni）？
11. 图表与统计结果是否同源、坐标轴是否标单位？ 12. 报告数字与统计输出是否逐字一致？
13. `result.json` 是否含全部必需字段且可解析？ 14. 是否记录运行状态、失败步骤、不确定性？
15. 是否处理空表、列缺失、类型不符、除零、编码错误、数据库连接失败？ 16. 是否所有输出路径有效、无个人文件依赖？
17. 是否提供可复算命令与输出文件清单？ 18. 是否不伪造数据、不硬编码答案、不虚构基准分数？

## 8. 虚构案例（自洽校验）

输入：`case.json`（case_id `iris-001`，data_file `/input/iris.csv`，task_file `/input/task.md`）；
task 要求清洗 Iris、比较 setosa 与 versicolor 的 sepal length、画箱线图、写报告。
中间量：第 1 步读取 150×5，字段 `sepal_length_cm` 等 float + `species` object；第 2 步缺失
`sepal_width_cm` 2 行（行 12/89，率 1.3%），完全重复 1 对（行 34/56），versicolor `sepal_length_cm` 行 98=7.9 超上界 7.3；
第 3 步用 species 中位数填补缺失、去重保留首次（150→149）、异常标记保留（setosa 50 / versicolor 50 / virginica 49）；
第 4 步 setosa mean=5.006 sd=0.352、versicolor mean=5.936 sd=0.516，Shapiro-Wilk p=0.459/0.338 正态，
Levene p=0.151 方差齐，独立样本 t：t=10.53、df=98、p<0.001、Cohen's d=2.10、95% CI [0.755,1.105] cm；
第 5 步箱线图 `boxplot_sepal_length.png`（x=species，y=sepal length (cm)）；第 6 步报告含数据描述、清洗规则、
统计结果、图表、结论。`result.json` 记 cleaning（rows_before 150 / rows_after 149 / missing_filled 2 /
duplicates_removed 1 / outliers_flagged 1）、statistics、evidence 路径与 uncertainty（异常行 98 已标记保留；
缺失按物种中位数填补，建议敏感性分析）。所有数字可由清洗后数据复算，完全自洽。
