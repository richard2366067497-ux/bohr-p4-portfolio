## 1. 任务本质与判分要点

### 1.1 任务本质

交付物不是预写的“结果与讨论”，而是一个 **面对未知案例仍能运行的写作 Skill**：读取真实
材料，将数据、图表和统计输出转化为可编辑章节，同时建立“正文句子—数值—原始位置—计算
过程—文献”的证据链。材料/化学工艺知识用于防止领域性误读，但不能替代实际输入。

### 1.2 判分要点（优先级从高到低）

1. **正确、可核验**：数值、单位、误差棒、统计量及推断强度与材料一致。
2. **完整、分得清**：结果陈述观察，讨论负责解释、文献对照和局限；阴性结果、不一致证据
   不得消失。
3. **可执行、有增益**：能被正确触发，减少重复核对，并留下真实运行记录；不自报未经对照
   实测的分数或提速比例。
4. **异常可恢复**：缺图、读数不清、单位冲突、统计缺失、引用无法确认时，交付诚实部分结果，
   而不是补造内容。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 根据案例名称猜实验和结论 | 读取 `/input/case.json`、`task.md` 及实际附件，以原文为准 |
| 从位图目测出“精确”数值和显著性 | 优先使用数据表、统计输出；图像数字化只能标为近似，不能反推检验结果 |
| 将 `mean±SD` 写成 `mean±SEM` | 原样记录误差类型、样本量和单位；换算必须给出公式及依据 |
| 结果段插入机理，讨论段重复报数 | 结果回答“观察到什么”，讨论回答“说明什么、与何证据一致、边界何在” |
| 把 `p>0.05` 写成“两组相同” | 写成“未检出统计学差异”，并保留效应方向、区间和检验效能限制 |
| 把相关、预测或单组前后变化写成因果 | 只有设计和检验确实支持时才用因果语言，否则改为“相关”“提示”“可能” |
| 只列引用，不说明文献关系 | 明确“支持/不一致/间接支持”，同时比较对象、条件和终点 |
| 删除阴性结果或异常值 | 按材料如实交代；排除数据必须有原任务或统计依据 |
| 只交章节，没有定位和修改记录 | 同步交付证据映射、复算入口、不确定性和变更记录 |
| 为追求完整而猜测缺失信息 | 将“材料未提供”“图像无法辨认”“来源冲突”“工具失败”分别标注 |

## 3. 量化口径与判定规则

### 3.1 描述统计

独立重复数为 \(n\) 时：

\[
\bar{x}=\frac{\sum x_i}{n},\qquad
s=\sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}},\qquad
SEM=\frac{s}{\sqrt n}.
\]

小样本均值区间通常为 \(\bar{x}\pm t_{0.975,n-1}SEM\)，不能机械使用 1.96。
技术重复不能冒充独立实验重复。

### 3.2 差异表达

\[
\Delta=x_B-x_A,\qquad \Delta_{\rm rel}=100\frac{x_B-x_A}{x_A}.
\]

转化率、选择性等百分量的绝对差用“百分点”，相对差用“%”。基准为零或接近零时不报告
相对变化。

### 3.3 材料工艺派生量

若转化率和选择性均基于同一摩尔口径，则

\[
Y_i(\%)=X_i(\%)\times S_i(\%)/100.
\]

应逐批次计算后再汇总；仅由组均值相乘得到的量标为“由均值换算”，不能冒充独立重复均值。

### 3.4 统计表述、读数优先级与波动

- **统计表述**：同时报告效应量、区间、检验名称和样本量；`p` 值不衡量效应大小。多终点或
  多组比较须沿用材料的校正方法。只有点估计而无检验时，可写“数值上较高”，不能写“显著提高”。
- **读数优先级**：原始数据/统计输出 > 表格与图注 > 矢量图标签 > 位图数字化。来源冲突不得
  自行平均，应并列记录并请求确认。
- **可接受波动**：转写容差为零；复算显示值允许不超过末位半个单位的舍入差。例如保留一位
  小数时，绝对差通常不超过 0.05，但必须检查中间舍入。不存在通用的“实验波动 5% 即合理”规则。
- **语气分级**：“观察到”对应描述统计；“差异有统计学证据”对应明确检验；“提示/可能”对应
  间接解释；“证明/导致”仅在设计、控制和统计均支持时使用。

## 4. 领域知识清单

1. 转化率、选择性、产率必须确认是摩尔、碳、质量还是体积口径；`wt%`、`vol%`、`mol%` 不可互换。
2. 百分数相减是百分点，例如 94% 降至 91% 是下降 3 个百分点，而非下降 3%。
3. 催化剂质量归一化、活性金属归一化和比表面积归一化速率含义不同，单位分别为如
   \(\mathrm{mol\,g_{cat}^{-1}\,h^{-1}}\) 等，不能混写。
4. `sccm` 依赖约定的标准状态；没有温度、压力定义时不得擅自换算摩尔流量。GHSV、空速和
   停留时间也不能仅凭名称互换。
5. XRD 峰位移动不能单独证明特定元素进入晶格；XPS 单一结合能峰不能独立证明价态或配位
   结构；局部 TEM 图不能代表整体粒径分布。
6. “未观察到失活”不等于“稳定性已证明”；必须说明考察时长、检测限及是否有等效性检验。
7. 活性提高不自动证明活性位点增多，产率提高也不自动证明碳平衡闭合；机理推断需表征、
   动力学或对照实验支撑。
8. 文献必须支持其所在句子的具体论断。核对作者、题名、年份、DOI/PMID 及实验条件；
   不同温度、空速或样本体系下只能作定性对照，不能直接比较幅度。
9. 上述规则是领域插件；遇到非材料案例时沿用证据链和统计边界，不强行套用产率公式。

## 6. 完整虚构案例

**以下仅为虚构接口演示，不是正式测试答案。** `case_id=DEMO-MAT-01`。

### 6.1 输入

任务要求比较催化剂 B 与 A 在 200 ℃、2 h 下的表现；三次为独立批次。`table1.csv` 给出：

| 组别 | 转化率 \(X\)，三次重复/% | 选择性 \(S\)，三次重复/% |
|---|---|---|
| A | 70.5，72.0，73.5 | 93.2，94.0，94.8 |
| B | 79.8，81.0，82.2 | 90.3，91.0，91.7 |

其他材料：

- `stats.txt` 第 4 行：主要终点转化率采用双侧 Welch 检验。
- `fig2.png` 面板 b 图注：“24 h 内未见明显持续下降”，未提供等效性检验。
- 虚构文献 `demo_ref.pdf` 第 3 页含短句：“B samples showed higher conversion under the
  tested conditions.”；其反应条件与本研究不同。

### 6.2 关键中间量

A、B 的转化率分别为 \(72.0\pm1.5\)% 和 \(81.0\pm1.2\)%（均值±SD）：

\[
\Delta_X=81.0-72.0=9.0\text{ 个百分点},\qquad
\Delta_{X,\rm rel}=100\times9/72=12.5\%.
\]

由原始数据复算 Welch 检验：\(t=8.1150\)，\(df=3.8161\)，双侧 \(p=0.0015279\)，
差值 95% CI 为 **5.8614–12.1386 个百分点**。

选择性分别为 \(94.0\pm0.8\)% 和 \(91.0\pm0.7\)%，B 低 **3.0 个百分点**。逐批次计算产率：

- A：65.706%、67.680%、69.678%，均值±SD 为 **67.688%±1.986%**。
- B：72.0594%、73.7100%、75.3774%，均值±SD 为 **73.7156%±1.6590%**。
- 产率差为 **6.0276 个百分点**，相对增加 \(100\times6.0276/67.688=8.9050\%\)。

材料没有提供选择性和产率的统计检验，因此二者只作描述性报告。

### 6.3 示例章节输出

**结果。** 在 200 ℃、2 h 条件下，A 与 B 的转化率分别为 72.0%±1.5% 和 81.0%±1.2%
（均值±SD，\(n=3\)）。B 的转化率高 9.0 个百分点（95% CI：5.86–12.14；Welch
\(t(3.816)=8.115\)，双侧 \(p=0.001528\)）[D1–D2]。A 与 B 的选择性分别为 94.0%±0.8% 和
91.0%±0.7%，B 数值上低 3.0 个百分点；由逐批次转化率和选择性计算，两组产率分别为
67.7%±2.0% 和 73.7%±1.7%[D1,D3]。选择性和产率未提供统计检验，故不作显著性判断。
图 2b 在 24 h 观察窗内未显示明显持续下降，但该结果不能证明长期稳定性或组间等效[D4]。

**讨论。** B 在转化率提高的同时出现选择性数值下降，但计算产率仍较高，提示本条件下存在
活性—选择性权衡，而非所有性能指标同步改善。虚构文献 L1 同样报告 B 类样品转化率较高，
与本研究方向一致；由于其反应条件不同，不能据此比较提升幅度。活性位点差异可能是转化率
变化的原因，但本材料没有相应表征，该解释仅为待验证假设。主要局限包括独立批次较少、
仅考察单一温度、选择性和产率缺少推断统计、未提供碳平衡，以及稳定性观察仅限 24 h。

### 6.4 示例证据与状态输出

| 编号 | 定位与复算 |
|---|---|
| D1 | `table1.csv`，A/B 两组三行，`X`、`S` 列 |
| D2 | `stats.txt` 第 4 行；Welch 复算输出 \(t=8.1150,p=0.0015279\) |
| D3 | 公式 `Y=X*S/100`；输入 D1，输出 67.688 和 73.7156 |
| D4 | `fig2.png` 面板 b 及图注逐字短句，不添加统计结论 |
| L1 | `demo_ref.pdf` 第 3 页短引文；仅支持“方向一致”，不支持机理 |

复算核心命令可保存为 `audit/recalculate.py`：

```python
import numpy as np
from scipy.stats import ttest_ind

xa = np.array([70.5, 72.0, 73.5])
xb = np.array([79.8, 81.0, 82.2])
sa = np.array([93.2, 94.0, 94.8])
sb = np.array([90.3, 91.0, 91.7])
print(ttest_ind(xb, xa, equal_var=False))
print(xa * sa / 100, xb * sb / 100)
```

预期检验输出为 `t=8.1150267、p=0.00152788`，两组产率序列与上文一致。结构化结果应标记为
已完成但含不确定性，并列出“选择性/产率检验未提供、机理未验证、长期稳定性未知”；
正式运行时，状态枚举和字段名必须服从原案例契约。
