# 结果与讨论章节模板（references/templates/results_discussion_template.md）

本包按此骨架生成 `manuscript.md`；也可以反过来当人工写作的检查清单。占位符用 `‹…›` 标注，
**不得把 `‹…›` 原样写进成稿**（脚本会把它当空壳 token 清洗）。

## 1 Results（只写观察）

```markdown
## Results

- **‹token›** — ‹来源片段› ‹[n]›          # 每个读数一行：token + 上下文 + 来源标记
- ‹无读数时›：材料中未抽取到可量化读数，本节只说明缺口。

> 本节不解释原因；数值与单位按材料原样记录，不做换算。
```

## 2 Discussion（解释必须挂靠数据或文献）

```markdown
## Discussion

- 记录的读数为：‹token…›；仅作观察陈述。
- ‹verdict› ‹文献论断›（‹source_id›, ‹locator›）。     # verdict ∈ 与之一致 / 与其存在张力
- 未定位到独立文献来源，因此不作跨研究比较。            # 无文献时必须显式说明
- 我们推测 ‹观察到的模式› 是一个线索；这只是待检验的假设，不是结果。
- 以上为相关性描述，尚未建立因果机制。
```

## 3 Limitations（四项分列，写方法层面）

```markdown
## Limitations

- **抽样与样本量**: ‹本次实际定位到的 n 或"材料未说明"›
- **测量与单位**: 单位按材料原样记录，未做换算
- **统计处理**: 仅在材料给出时报告显著性与效应量
- **可推广性**: 结论限于所述条件，不外推
```

## 4 Sources

```markdown
## Sources

[n] ‹来源文件› — ‹来源片段前 120 字›
```

## 5 人工确认清单（`human_review` 对应项）

- [ ] 位图图表里的读数——按尺寸清点后**用眼读数**，机器未 OCR；
- [ ] 扫描 PDF 的数值——无文本层，需手工录入；
- [ ] 文献可得性——离线包只对照给定片段，未检索外部数据库；
- [ ] 统计显著性的表述——只在材料写明时才写。
