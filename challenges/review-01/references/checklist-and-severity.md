# 检查项、规则号与判据（rules 2026-11-18）

本文件是审查口径的唯一规范。脚本 `scripts/audit_leads.py` 只负责按规则**找到可能有问题的那一段**；
每条候选是否成立、定什么性质、给什么严重度，由评审 Agent 按本文件判定后写进工作稿。

## 1. 六类检查项 + 规范

| facet | 中文 | 查什么 | 典型缺口 |
|---|---|---|---|
| `struct` | 结构与完整性 | 章节齐备与顺序、摘要与正文/结论是否对应、图与表的引用存在性 | 缺方法/结果章节、摘要数值正文无对应、引用图 3 却无图注 |
| `consistency` | 事实/数值一致性 | 同一量在摘要/正文/表格/图注间是否一致、样本量口径、单位与术语统一 | 摘要 48 例而方法 36 例、同一量两种单位、术语前后不一 |
| `citation` | 引用支持 | 正文引文与参考文献表是否配对、编号是否越界、条目是否残缺、引文是否支持论断 | 引 [9] 但只有 7 条、条目无年份、论断与引文方向相反 |
| `method` | 方法设计 | 对照、样本量、抽样、随机化、盲法、重复与批次、指标选择是否说明 | 有对照但未描述、无 n、无重复次数 |
| `statistics` | 统计报告 | 检验方法、显著性、误差与置信区间、效应量、分母 | 报 p 值不报检验、均值无离散度、百分比无分母 |
| `logic` | 论证链 | 从假设到结论的缺环、强断言、因果与相关混淆、外推范围 | 结论出现结果中不存在的新数值、「相关」写成「导致」 |
| `compliance` | 学术规范 | 数据/代码可用性、伦理与知情同意、利益冲突、资助、缩写与格式 | 三类声明全缺、缩写未定义 |

## 2. 规则号总表

每条规则的产出都是候选（`candidate`），字段为「为什么标出」+「需要你回答的问题」。

| 规则 | facet | 检出内容 | 默认严重度 | 成立条件（Agent 判据） | 常见误报与抑制 |
|---|---|---|---|---|---|
| `ST-01` | struct | 缺少必备章节（摘要/引言/方法/结果/结论/参考文献） | major（缺结果/参考文献为 critical） | 回原文确认该章节确实不存在，且不是以别名存在 | 方法章常叫 Experimental / 材料与方法；别名词表未覆盖 → 排除 |
| `ST-02` | struct | 结果章出现在方法章之前 | minor | 确属行文顺序倒置而非预印本格式 | 双栏/预印本模板差异 → 排除 |
| `ST-03` | struct | 摘要中的数值未在任何正文段出现 | major | 换算/图表/单位改写后仍找不到对应 | 百分比与绝对值互为换算、四舍五入 → 排除 |
| `CO-01` | consistency | 多处样本量口径不一致 | critical | 属同一队列却给出不同 n；不同子实验各自 n 合法 | 分组 n 与总 n 并存属正常 → 排除 |
| `CO-02` | consistency | 正文引用图/表 N，但未检出对应题注 | major | 题注确实缺失（不是抽取失败） | 图为独立图片文件、扫描件题注丢失 → `unchecked_items` |
| `CI-01` | citation | 有正文引文但无参考文献表 | critical | 参考文献不在另一文件（.bib/单独 refs） | 另有参考文献文件 → 排除 |
| `CI-02` | citation | 引文编号越界（> 参考文献条目数） | major | 编号风格核对后仍越界 | 编号自 0 起、合并引用格式 → 排除 |
| `CI-03` | citation | 参考文献条目未被正文引用 | minor | 非「进一步阅读」列表 | 该列表确为延伸阅读 → 排除 |
| `CI-04` | compliance | 数字型与作者-年份型引文混用 | minor | 目标期刊不允许混用 | 期刊允许混合/预印本过渡 → 排除 |
| `CI-05` | citation | 参考文献条目缺年份等关键字段 | minor | 条目确为残缺（非抽取截断） | PDF 抽取把年份切到下一行 → 排除 |
| `ME-01` | method | 未检出样本量说明 | major | 表格/图注/注册号也没有 | 材料仅含摘要 → `unchecked_items` |
| `ME-02` | method | 未检出对照/比较条件 | major | 研究属比较设计却无对照组 | 描述性/单臂研究 → 排除 |
| `ME-03` | method | 未检出随机化/盲法说明 | major | 干预类研究（人/动物/临床） | 机械、材料、计算类研究 → 排除 |
| `ME-04` | method | 未检出重复/批次信息 | minor | 结论依赖重复性 | 单次观测的描述性工作 → 排除 |
| `ST-11` | statistics | 全文未检出统计检验名称 | major | 报告了 p 值/显著性却无检验名 | 全文无推断统计 → 不适用，排除 |
| `ST-12` | statistics | 全文未检出显著性/p 值报告 | major | 结论依赖组间比较 | 纯描述性/理论文章 → 排除 |
| `ST-13` | statistics | 未检出误差度量（SD/SEM/CI/效应量） | minor | 报告了均值却无离散度 | 只报单一测量值 → 排除 |
| `ST-14` | statistics | 出现「±」但未定义是 SD/SEM/CI | minor | 图注/表注也未定义 | 文内另有定义 → 排除 |
| `ST-15` | statistics | 报 p 值但未指明检验 | major | 表注/图注也没有 | 检验在补充材料 → 记 `pending_review` |
| `ST-16` | statistics | 报百分比但无分母/样本量 | minor | 分母无法从表格推出 | 前文已给 n → 排除 |
| `LO-01` | logic | 强断言（证明/首次/所有/必然）无 hedging | major | 断言超出设计与样本范围 | 引用他人结论的转述 → 排除 |
| `LO-02` | logic | 观察性设计使用因果动词 | major | 设计与因果表述不匹配 | 有干预实验支撑 → 排除 |
| `LO-03` | logic | 结论出现结果章节没有的数值 | major | 结果表/图换算后仍无对应 | 由结果数值推算而来（如 27%→「约 30%」）→ 排除 |
| `CP-01` | compliance | 未检出数据可用性声明 | minor | 目标期刊强制要求 | 短文体裁/预印本不要求 → 排除或降 suggestion |
| `CP-02` | compliance | 未检出利益冲突声明 | minor | 同上 | 同上 |
| `CP-03` | compliance | 未检出资助声明 | minor | 同上 | 同上 |
| `CP-04` | compliance | 涉及人/动物但无伦理审批 | major | 非公开数据二次分析 | 公开数据集/豁免情形 → 排除 |
| `AX-01` | compliance | 缩写多次出现但无首次定义 | minor | 首次出现处也无「全称(缩写)」 | 通用缩写（DNA/ANOVA/SEM）→ 排除 |
| `AX-02` | compliance | 同一单位/符号两种写法（℃/°C、CO2/CO₂） | suggestion | 期刊要求统一 | 排版偏好 → 排除或降级 |

## 3. 严重度锚点

| 严重度 | 一句话判据 | 例 |
|---|---|---|
| `critical` | 若照稿发表，主结论或可复现性不成立 | 样本量前后矛盾、结论数值无出处、方法缺关键对照 |
| `major` | 发表前必改，影响读者对结果的解释 | 报 p 值无检验名、结论外推到全部材料、引文不支持论断 |
| `minor` | 报告与表述缺陷，不影响结论成立 | 图号错配、引文表冗余、单位不统一 |
| `suggestion` | 改进建议 | 补一段局限性讨论、调整章节顺序 |

定级自检：把这条问题读给作者听，如果他会说「这确实是错的，必须改」→ critical/major；
「有道理但不影响结论」→ minor；「看你喜好」→ suggestion。

## 4. 候选处置流程（每个候选都必须走完）

```
候选 C-00x
 ├─ 回原文读该段（show --seg <uid>）
 ├─ 问题真实且能定位？ ──否──> rejected_candidates{reason}
 │        │是
 ├─ 性质是什么？ fact_error / insufficient_evidence / reporting_gap /
 │                method_flaw / statistical_misreport / logic_gap /
 │                compliance / citation_unsupported / improvement
 ├─ 严重度？ critical / major / minor / suggestion（给 severity_reason）
 ├─ 材料不足或需外部核实？ ──是──> verdict_type=pending_review + 缺什么
 └─ 写 finding（quote 逐字、revision 落到句子）
```

排除理由必须具体，以下写法不合格：「不适用」「误报」「没问题」。合格示例：
「机械疲劳试验为单批试样，随机化/盲法在本设计下不适用，属学科惯例」。

## 5. 误报抑制表（写 finding 前逐条自问）

| # | 抑制规则 | 处置 |
|---|---|---|
| 1 | 学科写作惯例（单批试验无盲法、理论文无伦理声明、短文无独立讨论节） | 不报或只给 suggestion |
| 2 | 期刊格式差异（引文风格、章节编号、单位写法） | 题面无目标期刊要求时 ≤ suggestion |
| 3 | 作者明确声明的假设/局限、转述他人观点 | 不作为矛盾或夸大立案 |
| 4 | 材料缺口（图未提供、参考文献另附、扫描页模糊） | `unchecked_items` / `pending_review`，不判稿件缺陷 |
| 5 | 同一句同一缺陷的多个候选 | 合并为一条，`candidate_ids` 全留 |
| 6 | 纯语言偏好（「更学术的表达」） | 不入清单 |
| 7 | 数值差异可被换算/舍入解释 | 先换算，解释得通就不报 |
| 8 | 作者使用的合理近似（「约 30%」对应 27%） | 不报 |

## 6. 覆盖表写法

七项都要出现，`checked=true` + `items_checked` + `note`。不适用写成
`checked=true, note="材料为纯理论推导，样本量与随机化不适用"`；真没查写成 `checked=false` 并在
`unchecked_items` 写清原因与下一步。示例：

```
struct      6  摘要/引言/方法/结果/讨论/结论/参考文献逐节核对，均存在
consistency 5  样本量、百分比、图号、单位一致性逐项比对
citation    5  正文 [1]-[4] 与 5 条参考文献逐条配对
method      4  对照、样本量、重复、随机化逐项检查；随机化不适用
statistics  4  检验名、p 值、离散度、分母逐项检查
logic       3  结论外推、因果语言、新数值三条路径核查
compliance  5  数据可用性/利益冲突/资助/伦理/缩写
```
