# 专家参考手册：参考文献与引用管理（citation-ledger-sync）

执行任何命令、产出任何交付物之前，先读本手册；按 §2 八步推进，交付前逐项过 §7 检查表。

## 1. 判分要点

### 1.1 真正要交付什么

本任务要求提交一个**可被平台加载并实际运行的 Skill 包**，而非预生成答案。Skill 在 3 个未知固定科研案例上，围绕"参考文献与引用管理"完成指定动作，并交付可复核结果。核心交付物包括：

1. **SKILL.md**：有效 YAML frontmatter（name/description），写清用途、适用条件、调用方式、输入输出、异常处理。
2. **运行必需脚本与资源**：实际依赖的脚本、配置、模板、词表等，路径有效，不依赖未说明的个人文件。
3. **使用与方法说明**：完整调用步骤、关键方法、限制、失败处理、自查方法。
4. **最小调用示例**：至少一组输入、调用方式和示意输出，标明为示例。
5. **每个案例的结构化结果**：目标产物（可编辑稿件/文献表）、事实与来源映射、版本与边界、运行状态与不确定性。

平台执行时，原始输入位于 `/input/case.json` 和 `/input/task.md`，工作目录 `/app/work`，最终结果写入 `/app/output`，必须包含 `result.json` 且含 `case_id` 及所有 output_contract 字段。可编辑 Office 产物需同时提供真实渲染的 PDF/PNG 预览。

### 1.2 评委看哪几件事

| 维度 | 关键考察点 |
|-|-|
| 实际效果（40） | 任务完成度、结果正确性、完整性、可核验性；引用是否落到真实可定位文献；正文论断与文献是否匹配 |
| 使用增益（25） | 相比基础 Agent 的质量/效率提升，且通过公平对照证明 |
| 创新增益（15） | 新增能力（如编号连锁更新、论断级匹配）、方法改进、创新证据 |
| 可靠体验（10） | 调用易用性、运行稳定性、异常处理 |
| 生态贡献（10） | 文档完整性、资源可复用性、分享推广价值 |

### 1.3 常见失败模式：错误做法 → 正确做法

1. **只提交提示词，无实际脚本/规则** → 必须提供可执行的脚本、配置、规则文件，平台能据此运行。
2. **引用插到整段末尾或图表注附近** → 必须定位到具体论断句，使用句子级 locator（如段落索引+句子索引）。
3. **编号手动更新，正文与文末不一致** → 必须用脚本自动重排编号，并做对称差校验。
4. **去重只看标题完全相同** → 必须基于 DOI、标题归一化、作者+年份+卷期页等多字段判据，并记录合并依据。
5. **格式转换丢失 DOI、卷期页** → 必须保留关键字段，转换后逐条校验字段完整性。
6. **来源核验只查"文献是否存在"** → 必须逐句判定正文论断与所引文献主题/结论是否匹配，证据不足要标注。
7. **输出 PDF/图片代替可编辑稿件** → 必须输出可编辑格式（如 .docx），同时附 PDF/PNG 预览。
8. **result.json 缺字段或 case_id** → 必须包含所有 output_contract 字段，case_id 与输入一致。
9. **虚构数据或补造材料外事实** → 禁止新增材料外事实；材料不足、冲突必须明确标注。
10. **忽略运行预算（64 次模型请求、900 秒、16384 tokens/响应）** → 必须增量保存部分交付物，先保底再优化。
11. **不读取实际文件，凭标签假设内容** → 必须读取 `/input/case.json`、`task.md` 及实际材料，不依据错误领域标签补造数据。
12. **资源文件超限（50 个 UTF-8 文本文件、500KB/个、2MB 总、无符号链接）** → 提交前检查文件数量、大小和类型。

## 3. 专家方法与量化口径

### 3.1 关键指标定义与公式

| 指标 | 定义 | 公式 | 可接受波动 |
|-|-|-|-|
| 引用定位准确率 | 插入位置正确的引用数 / 总插入引用数 | `P_loc = N_correct_loc / N_inserted` | ≥ 95% |
| 编号一致性 | 正文编号集合与文末列表编号集合的对称差占比 | `C_num = 1 − |S_intext Δ S_bib| / |S_intext ∪ S_bib|` | = 100% |
| 去重合并准确率 | 正确合并数 / 应合并数；误合并数 / 不应合并数 | `P_merge = N_correct_merge / N_should_merge`；`F_merge = N_wrong_merge / N_should_not_merge` | P_merge ≥ 95%，F_merge = 0 |
| 格式转换字段保留率 | 关键字段（DOI、卷期页、文献类型标识）保留数 / 应有字段数 | `P_field = N_preserved / N_expected` | ≥ 95% |
| 来源核验覆盖率 | 已核验引用数 / 总引用数 | `C_verify = N_verified / N_total` | = 100% |
| 论断匹配率 | 匹配论断数 / 已核验论断数 | `P_match = N_matched / N_verified_claims` | ≥ 90% |
| 可回溯率 | 有来源映射的引用数 / 总引用数 | `C_trace = N_mapped / N_total` | = 100% |
| 人工修改量 | 需人工修改的引用数 / 总引用数 | `E_manual = N_manual / N_total` | 越低越好，目标 < 10% |

### 3.2 计算示例（数字自洽）

某案例：稿件原有 9 条引用，插入 3 条，删除 1 条，最终 11 条引用。

- **编号一致性**：正文 `S_intext = {1..11}`，文末 `S_bib = {1..11}`。对称差 `|S_intext Δ S_bib| = 0`，并集 = 11。`C_num = 1 − 0/11 = 100%`。
- **格式转换字段保留率**：11 条中，10 条有 DOI，1 条无 DOI 但有卷期页。关键字段共 11×3=33 个，实际保留 33 个。`P_field = 33/33 = 100%`。
- **来源核验覆盖率**：11 条中 10 条 DOI 解析成功，1 条无 DOI 但通过数据库检索确认。`C_verify = 11/11 = 100%`。
- **论断匹配率**：9 个需引用论断中 8 个匹配，1 个证据不足标注。`P_match = 8/9 = 88.9%`，需人工确认 1 条并在 result.json 中标注。
- **人工修改量**：基础 Agent 需人工修改 8/11=72.7%；Skill 后需人工修改 1/11=9.1%。增益 = 72.7 − 9.1 = **63.6 个百分点**。

### 3.3 量化口径注意事项

- 所有百分比保留一位小数，不四舍五入到整数。
- 编号一致性必须为 100%，任何偏差视为严重错误。
- 去重误合并必须为 0，否则可能合并同名作者的不同文献。
- 来源核验覆盖率必须为 100%，未核验条目必须标注"未核验"并列入不确定性。
- 论断匹配率低于 90% 时，必须逐条列出不匹配的论断和原因。

## 4. 领域知识清单（易犯错误、单位/口径陷阱、依据要求）

### 4.1 容易犯的事实性错误

1. **混淆顺序编码制与著者-出版年制**：GB/T 7714—2015 顺序编码制正文用 `[1]`，文末按引用顺序排列；著者-出版年制正文用 `(作者, 年份)`，文末按作者字母/拼音排列。不可混用。
2. **中英文题名重复误判为不同文献**：同一文献可能有中文题名和英文题名，需通过 DOI 或作者+年份+卷期页合并。
3. **预印本与正式版重复**：arXiv 预印本与期刊正式版 DOI 不同但内容相同，需合并并保留正式版信息。
4. **同名作者不同文献误合并**：仅凭作者+年份可能误合并，必须结合标题、卷期页、DOI。
5. **文献类型标识错误**：期刊论文 `[J]`、专著 `[M]`、会议论文 `[C]`、学位论文 `[D]`、电子资源 `[EB/OL]`。不可混淆。
6. **DOI 格式错误**：DOI 应统一为小写，去除 `https://doi.org/` 前缀，保留 `10.xxxx/yyyy`。
7. **卷期页缺失**：格式转换时若源数据缺卷期页，必须标注缺失，不可编造。
8. **et al. 规则错误**：GB/T 7714 规定 3 人以内全列，超过 3 人列前 3 人加"等"或"et al."；APA 7th 规定 3-20 人全列，21 人以上列前 19 人加省略号。
9. **上标样式不一致**：顺序编码制正文引用标记通常为上标，不可与正文平排混用。
10. **图表注引用遗漏**：图表数据来源需在图表注中标注引用，不可只标注正文。

### 4.2 单位/口径陷阱

- 本领域无物理量纲，但需注意**字段完整性百分比**、**编号差集大小**等量化指标的单位为"条""个"，不可混淆。
- 时间戳、访问日期格式统一为 ISO 8601（`YYYY-MM-DD`）。
- 文件大小单位统一为 KB/MB，不可混用。

### 4.3 文献依据要求

- 每条引用必须可定位到真实文献记录，优先使用 DOI、PubMed ID、CNKI 链接等。
- 正文论断与所引文献主题/结论必须匹配，不可"挂名引用"。
- 材料不足、冲突、无法核验的内容必须明确标注，不得猜测。
- 所有修改必须保留来源或修改记录，可逐条回溯。
