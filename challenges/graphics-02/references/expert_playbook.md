# 专家参考手册 —— 科研图表生产线（graphics-02）

## 1. 交付什么（判分要点）

要交付的不是“一张好看的图”，而是一条**可复核、可复现、可继续编辑**的科研图表生产线。每个案例必须产出四类结果：

1. **可编辑源文件**（SVG / PPTX / 分层文件）：实体、关系、图例、数据映射正确，文字可编辑，图层可分离。
2. **导出件**（PDF / PNG）：目标格式、尺寸、分辨率、字体嵌入、色彩空间满足投稿要求。
3. **来源与修改记录**：每个关键图元能回溯到源数据字段、行号、版本；异常有说明。
4. **结构化结果** `result.json`：包含 `case_id`、`status`、`sources`、`uncertainty`、`change_records` 等字段。

验收实际看三件事：

- **图上的每个图元能否回到源数据字段**（可追溯）；
- **标注与图例是否与数据一致**（数值、单位、系列对应无误）；
- **交付物是否可编辑、可复核、可直接投稿**（分层、矢量、字体嵌入、分辨率达标）。

判分要点归纳为：数值一致、可复算、可追溯、可编辑、可复现、异常有交代。

## 2. 分步流程与门控

从输入材料到交付物共 8 步，每步有**冻结产物**与**门控**（门控未通过不得进入下一步）。

### 步骤 0：读取输入与资源
- 读取 `case.json`、`task.md` 与全部材料文件（PDF / CSV / 图片等）。
- **冻结产物**：`case_id`、源文件清单、任务类型（生成 / 编辑）、目标图型。
- **门控**：确认文件存在、可解析；PDF 解析成功，无缺页。

### 步骤 1：提取实体、关系、数据、图面约束
- 从材料中提取数据表、实体列表、关系、目标图型、样式要求（期刊模板、字号、线宽、配色、面板布局）。
- **冻结产物**：`data_tables.json`、`entities.json`、`constraints.json`。
- **门控**：每个数据字段有来源 locator（文件:页:行/列）；实体名称无拼写错误。

### 步骤 2：数据清洗与映射建模
- 将源数据映射为图元：柱高、点位置、色阶、扇区角度、误差线长度。
- 处理空值、量级异常、标签过长等问题。
- **冻结产物**：`mapping.json`（图元 ID → 源数据字段、行号、数值、单位）。
- **门控**：所有数值可复算，无未处理的空值；误差线类型明确（SD / SEM / CI）。

### 步骤 3：生成可编辑源文件
- 使用脚本（Python matplotlib / plotly、SVG 原生、python-pptx 等）生成分层源文件。
- **冻结产物**：`figure_source.svg` 或 `figure_source.pptx`。
- **门控**：文件可打开，文字可编辑，图层存在。

### 步骤 4：样式调整
- 按期刊 / 模板调整字号、线宽、配色、图例位置、面板布局、留白。
- **冻结产物**：`style_config.yaml`、调整后的源文件。
- **门控**：样式参数有记录，且与源文件一致。

### 步骤 5：标注校验
- 检查轴标签与单位、刻度范围、图例与系列对应、误差线与显著性标注含义、样本量与图注一致性。
- **冻结产物**：`validation_report.json`。
- **门控**：所有检查项通过或有明确说明；无遮挡、无缺失。

### 步骤 6：导出与检查
- 导出 PDF / PNG，检查分辨率、色彩空间、字体嵌入、透明背景。
- **冻结产物**：`figure.pdf`、`figure.png`、`export_check.json`。
- **门控**：导出参数满足要求；PDF 字体已嵌入；PNG DPI ≥ 300。

### 步骤 7：打包交付
- 写 `result.json`，包含所有输出字段、来源、修改记录、不确定性。
- **冻结产物**：`/app/output/result.json`。
- **门控**：字段完整，可独立复核；复算命令可运行。

## 3. 量化口径、公式与容差

### 3.1 数据映射准确率
- 定义：图元数值与源数据字段一致的比例。
- 公式：`1 - (不一致图元数 / 总图元数)`
- 目标：100%；可接受：≥95%。

### 3.2 误差线长度
- SD（标准差）：`SD = sqrt(Σ(xi - x̄)² / (n-1))`
- SEM（标准误）：`SEM = SD / √n`
- 单位与数据相同。图中必须标注误差线类型。
- 示例：n=3，数据 [1.2, 1.5, 1.8]，x̄=1.5，SD=0.3，SEM=0.173。误差线上下限 = x̄ ± SD 或 x̄ ± SEM。

### 3.3 柱高映射
- 公式：`柱高(px) = 数值 × 比例因子`
- 比例因子：`绘图区高度(px) / 数据最大值`
- 示例：数据最大值 100，绘图区高度 400px，比例因子 4px/单位。数值 25 → 柱高 100px。

### 3.4 散点位置
- 公式：`x = (x_i - x_min) / (x_max - x_min) × 绘图区宽度 + 左边距`
- 示例：x 范围 0–10，绘图区宽 500px，左边距 50px，x_i=5 → x = 50 + 5/10×500 = 300px。

### 3.5 色阶映射
- 公式：`颜色索引 = floor((value - min) / (max - min) × (n_colors - 1))`
- 示例：min=0，max=100，n_colors=5，value=60 → 索引 = floor(60/100×4) = 2。

### 3.6 扇区角度
- 公式：`角度 = 数值 / 总和 × 360°`
- 示例：A=30，B=70，总和=100，A 角度 = 108°。

### 3.7 字体嵌入检查
- 命令：`pdffonts figure.pdf`
- 要求：`emb` 列全部为 `yes`，无“未嵌入”标志。

### 3.8 分辨率
- 公式：`像素尺寸 = 物理尺寸(英寸) × DPI`
- 示例：单栏图宽 3.5 英寸，300 DPI → 宽度 = 1050px。

### 3.9 色彩空间
- 在线：RGB；印刷：CMYK。
- 检查命令：`identify -verbose figure.png | grep Colorspace`。

### 3.10 可接受波动（容差）
- 数值复算误差 < 0.5% 或 < 0.1 单位（取大者）。
- 示例：源数据 1.234，图中 1.23，误差 0.004 < 0.00617，可接受。

## 4. 领域陷阱与事实性错误（错误做法→正确做法）

### 4.1 常见失败模式

| 错误做法 | 正确做法 |
|---|---|
| 手填数值，图与源数据表对不上 | 从源数据表读取数值，保留行列 locator，脚本生成图元 |
| 图例按默认顺序，与系列错配 | 显式建立“系列名→颜色/形状”映射，图例顺序与数据系列一致 |
| 坐标轴量级或单位写错（如 μg/mL 写成 mg/mL） | 从源材料提取单位，轴标签带单位，量级转换有记录 |
| 基因 / 蛋白 / 物种名拼错、斜体正体错误 | 使用受控词表校验，基因斜体、蛋白正体、物种斜体 |
| 中文标注乱码或被替换成方框 | 使用支持中文的字体（如 Noto Sans CJK），导出时嵌入或转曲 |
| 多面板对齐错位 | 使用共享轴、网格对齐，面板尺寸由脚本计算 |
| 导出位图或文字被转曲，无法再编辑 | 保留 SVG/PPTX 源文件，PDF 文字保持可编辑 |
| 分辨率不足、色彩空间错误 | 导出前检查 DPI ≥ 300，RGB/CMYK 按期刊要求 |
| 无法回溯数据来源 | 每个图元带 source locator（文件:页:行/列），写入 mapping.json |
| 只说“图做好了”，没有校验记录 | 输出 validation_report.json，逐项标注通过 / 失败 |

### 4.2 容易犯的事实性错误
1. **科学实体名称**：基因名斜体（如 *TP53*），蛋白名正体（如 p53），物种名斜体（如 *Homo sapiens*）。必须从源材料确认，不擅自改。
2. **单位与量纲**：浓度单位 μM、nM、mg/mL；时间单位 h、min、s；温度 °C。轴标签必须带单位，量级正确。常见错误：把 μg/mL 写成 mg/mL，差 1000 倍。
3. **误差线含义**：SD、SEM、CI 不可混用。若源数据只给 SEM，不能标成 SD。图注必须说明。
4. **显著性标记**：\* p<0.05，\*\* p<0.01，\*\*\* p<0.001，ns 不显著。必须与统计结果对应。
5. **样本量**：n 值必须在图注或图中标注。常见错误：n=3 但图中只有 2 个点。
6. **图表类型**：柱状图用于分类比较，折线图用于趋势，散点图用于相关性，箱线图用于分布。不能混用。
7. **坐标轴范围**：柱状图 y 轴应从 0 开始；折线图可非零但需标注截断。常见错误：柱状图不从 0 开始，夸大差异。
8. **图例顺序**：应与数据系列顺序一致，不能按字母重排。
9. **中文标注**：使用支持中文的字体（如 Noto Sans CJK），导出时嵌入或转曲，避免乱码。
10. **文献依据**：若图中数据来自文献，需在来源记录中标注文献 DOI 或 PMID，不能只写“文献”。

### 4.3 单位 / 量纲陷阱
- 浓度：μM（微摩尔/升）、nM（纳摩尔/升）、mg/mL（毫克/毫升）。1 μM = 1000 nM；1 mg/mL = 1000 μg/mL。
- 时间：h（小时）、min（分钟）、s（秒）。1 h = 60 min = 3600 s。
- 温度：°C 与 K 不可混用。0°C = 273.15 K。
- 质量：μg、mg、g。1 mg = 1000 μg；1 g = 1000 mg。
- 体积：μL、mL、L。1 mL = 1000 μL；1 L = 1000 mL。

### 4.4 文献依据要求
- 数据来源必须可追溯：文件路径、页码、行号、版本号。
- 若数据来自已发表文献，记录 DOI 或 PMID。
- 若数据来自实验记录，记录实验编号、日期、仪器型号。
- 不得伪造数据或来源。

## 5. 交付物、证据与 locator

| 文件 / 章节 | 内容要求 | 自证可核验方式 |
|---|---|---|
| `/app/output/result.json` | `case_id`、`status`、`sources`、`uncertainty`、`change_records` | JSON schema 校验通过，字段完整 |
| `figure_source.svg` / `.pptx` | 分层源文件，文字可编辑 | 用 Inkscape / PowerPoint 打开，文字可编辑，图层存在 |
| `figure.pdf` | 矢量导出件，字体嵌入 | `pdffonts figure.pdf` 显示 emb=yes；`pdfinfo` 显示页面尺寸正确 |
| `figure.png` | 预览位图，DPI ≥ 300 | `identify -verbose figure.png` 显示 DPI ≥ 300，尺寸符合要求 |
| `mapping.json` | 图元 ID → 源数据字段、行号、数值、单位 | 每个图元有 locator（文件:页:行/列），可复算 |
| `validation_report.json` | 标注校验结果 | 每项检查有通过 / 失败状态和说明 |
| `style_config.yaml` | 样式配置 | 参数与源文件一致 |
| `sources.json` | 来源与版本记录 | 每个数据字段有来源文件、版本、提取时间 |
| 复算命令 | 在 README 或 result.json 中提供 | 他人可运行得到相同图，如 `python3 -B scripts/main.py selfcheck --input /input --output /app/output --work /app/work` |

**locator 规则**：一切关键图元都必须带 `源文件:页:行/列` 形式的位置标识，写入 `mapping.json`，保证任意图元都能定位回原始字段。

## 7. 虚构案例（自洽校验）

### 7.1 输入
- `case.json`：
```json
{
  "case_id": "case-001",
  "task": "生成柱状图",
  "source": "data.csv",
  "style": "nature"
}
```
- `data.csv`：
```
condition, mean, sd, n
Control, 1.2, 0.3, 3
Drug_A, 2.5, 0.5, 3
Drug_B, 3.8, 0.7, 3
```
- `task.md`：要求柱状图，误差线为 SD，y 轴标签“Relative expression”，单位“a.u.”，图例显示条件名，字号 8pt，线宽 0.5pt，单栏宽 3.5 英寸。

### 7.2 关键中间量
- **数据映射**：柱高 = mean 值。绘图区高度 2.5 英寸 = 600px（300 DPI），数据最大值 3.8，比例因子 = 600/3.8 ≈ 157.9 px/单位。
  - Control 柱高 = 1.2 × 157.9 ≈ 189.5px
  - Drug_A 柱高 = 2.5 × 157.9 ≈ 394.7px
  - Drug_B 柱高 = 3.8 × 157.9 ≈ 600px
- **误差线长度**：SD × 比例因子。
  - Control: 0.3 × 157.9 ≈ 47.4px，上下限 [0.9, 1.5]
  - Drug_A: 0.5 × 157.9 ≈ 78.9px，上下限 [2.0, 3.0]
  - Drug_B: 0.7 × 157.9 ≈ 110.5px，上下限 [3.1, 4.5]
- **轴范围**：y 轴从 0 开始，最大值取数据最大值 + 最大 SD = 3.8 + 0.7 = 4.5，向上取整到 5.0。刻度：0, 1, 2, 3, 4, 5。
- **颜色映射**：Control #999999，Drug_A #E69F00，Drug_B #56B4E9（色盲友好）。
- **字体**：Arial 8pt，线宽 0.5pt。
- **导出**：PDF 单栏宽 3.5 英寸，高 2.5 英寸；PNG 1050×750px（300 DPI）。

### 7.3 输出
- `figure_source.svg`：分层，柱体、误差线、轴、标签、图例各一层。
- `figure.pdf`：矢量，字体嵌入。
- `figure.png`：1050×750px，300 DPI，RGB。
- `mapping.json`：
```json
[
  {"glyph_id": "bar_Control", "source_field": "data.csv:row2:mean", "value": 1.2, "unit": "a.u."},
  {"glyph_id": "bar_Drug_A", "source_field": "data.csv:row3:mean", "value": 2.5, "unit": "a.u."},
  {"glyph_id": "bar_Drug_B", "source_field": "data.csv:row4:mean", "value": 3.8, "unit": "a.u."},
  {"glyph_id": "errorbar_Control", "source_field": "data.csv:row2:sd", "value": 0.3, "type": "SD"},
  {"glyph_id": "errorbar_Drug_A", "source_field": "data.csv:row3:sd", "value": 0.5, "type": "SD"},
  {"glyph_id": "errorbar_Drug_B", "source_field": "data.csv:row4:sd", "value": 0.7, "type": "SD"}
]
```
- `validation_report.json`：检查项全部通过，包括轴标签“Relative expression (a.u.)”、图例顺序、误差线类型 SD、样本量 n=3 标注。
- `result.json`：
```json
{
  "case_id": "case-001",
  "status": "success",
  "sources": {"data.csv": "version 1, sha256:abc123"},
  "uncertainty": "无",
  "change_records": ["初始生成"]
}
```

### 7.4 复算命令
```bash
python3 -B scripts/main.py selfcheck --input /input --output /app/output --work /app/work
```
运行后得到相同文件，可独立复核。
