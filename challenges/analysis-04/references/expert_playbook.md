执行前**完整阅读本手册**，按 §2 流程推进，交付前逐项过 §7 自查表。本领域交付一段自足的科研分析代码，

## 1. 质量维度（判分要点）

- **实际效果（40）**：是否从给定数据与数据字典出发完成全链路（读取 → 加载 → 清洗 → 统计/可视化/查询 →
  运行代码 → 结果验证 → 异常说明 → 结构化结果）；数值/图表/查询是否与数据、口径、金标准一致；
  是否留下可独立重跑的证据。
- **使用增益（25）**：相比朴素做法，正确率、一次跑通率是否提升；调试轮次、人工改数成本是否下降；是否有公平对照。
- **创新增益（15）**：是否形成朴素做法不具备的能力——代码生成约束、环境隔离、结果校验、错误恢复的实质改进。
- **可靠体验（10）**：能否正确触发；不同数据形态/环境是否稳定；对缺列、类型不符、依赖缺失、查询为空、
  数值溢出的识别与处置。
- **生态贡献（10）**：文档完整；脚本、环境文件、样例数据、金标准可复用。

## 2. 求解流程（每步有冻结产物与门控）

0. **读取输入与任务说明**：解析 `case.json` 的 case_id、数据文件路径、数据字典路径、任务要求、输出约束；
   读 `task.md` 的具体步骤。*冻结* `input_summary.json`。*门控*：case_id 非空；数据文件可读；任务已解析。
1. **环境与依赖检查**：读 `environment/resources.yaml`；缺依赖则按锁定的 `requirements.txt` 安装；
   建隔离环境。*冻结* `environment_info.json`（Python/包版本、安装命令、退出状态）。*门控*：所有必需包导入成功。
2. **数据加载与探查**：CSV 用 `read_csv`，SQLite 用 `sqlite3`；检查行数、列名、dtypes、缺失、重复、异常
   （IQR/Z）；算原始 SHA256。*冻结* `raw_snapshot.json`、`raw_data_head.csv`。*门控*：行数 >0；列名与字典匹配
   （允许大小写/空格差异但须建映射）；哈希非空。
3. **清洗与转换**：按任务与字典定规则（缺失/异常/重复/单位/类型），每步记输入列、操作、参数、输出列、影响行数。
   *冻结* `cleaning_rules.json`、`cleaned_data.csv`、`cleaning_log.txt`。*门控*：清洗后行数/列数合理；策略已记录；无静默修改。
4. **统计分析与可视化**：执行所需统计（描述/分组/假设/回归）；出图并设标题、轴标签（含单位）、图例；
   存 PNG/PDF（SVG 可编辑可选）。*冻结* `analysis_results.json`、`figures/*.png`、`analysis_code.py`。
   *门控*：统计与原始数据一致（均值可复算）；图件存在可打开。
5. **结果验证**：与金标准（数据集描述、已知文献值）或字典对照；检查数值、结构、图表、查询结果；
   识别「跑通了但算错了」的静默错误。*冻结* `validation_report.json`（每个关键数字的期望/实际/差异/是否通过）。
   *门控*：差异在可接受范围内（如 <0.001）或已记录差异原因。
6. **异常处理与失败说明**：对缺列、类型不符、依赖缺失、查询为空、溢出、权限不足，执行识别/重试/降级/终止/转人工；
   保留失败现场（traceback、命令行、退出状态）。*冻结* `exceptions.json`。*门控*：所有异常均有说明，无静默失败。
7. **交付物生成**：汇总到 `/app/output`；生成 `result.json`（case_id、主结果、证据/来源定位、状态、不确定性）；
   确保全部 output_contract 字段填写完整；可编辑产物（CSV/SVG）+ PDF/PNG 预览。*门控*：`result.json` 有效、
   字段齐全、路径有效。

## 3. 常见失败模式（错误做法 → 正确做法）

1. **依赖未声明或版本漂移** → 锁定版本（如 `pandas==2.1.4`）并在 `SKILL.md` 写明安装命令。
2. **路径写死本机** → 用相对路径或从 `case.json` 读数据路径。
3. **字段名与数据字典对不上** → 先读字典建字段映射表，用映射后的标准名访问列。
4. **缺失值当 0 参与均值** → 显式 `dropna` 或按策略填补，并在规则表记录。
5. **重复记录未去重就分组** → 先查 `duplicated().sum()`，按业务规则决定去重/保留，记录前后行数。
6. **t 检验前提未检查就报 p** → 先 Levene；方差不齐用 Welch；严重偏态用 Mann-Whitney U。
7. **图表轴/单位/图例与原始数据不一致** → 从字典读单位（cm、MPa），在轴标签与图例显式标注并核对。
8. **查询条件漏字段导致行数偏多** → 先 `SELECT COUNT(*)` 验证，再与字典/任务预期对照。
9. **环境版本与随机种子未记录** → 固定 `seed=42`/`random_state=42`，日志记 Python 与包版本。
10. **出错不定位原因就换代码** → 捕获异常，记完整 traceback、命令行、退出状态到 `exceptions.json`，再决定处置。
11. **结果不可复核** → 每个关键数字附 locator 与复算命令。
12. **用预制答案代替实际运行** → 实际执行脚本，保留运行日志与退出状态，结果从输出文件读取。
13. **对缺失/异常静默修改** → 在 `exceptions.json` 记原始值、处理方式、理由、影响行数。

## 4. 量化口径与公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 缺失率 | `缺失数 / 总行数 × 100%` | 逐列，保留 1 位小数 |
| 重复率 | `重复行数 / 总行数 × 100%` | `df.duplicated().sum()` |
| 均值 | `μ = Σxᵢ / n` | 浮点保留 4 位有效数字 |
| 样本标准差 | `s = √(Σ(xᵢ−μ)²/(n−1))` | 分母 n−1 |
| IQR | `Q3 − Q1` | 用 `percentile` |
| 异常值（IQR 法） | `x < Q1−1.5×IQR` 或 `x > Q3+1.5×IQR` | 标记，不自动删除 |
| 独立样本 t | `t = (μ₁−μ₂)/√(s₁²/n₁+s₂²/n₂)` | 先 Levene；方差不齐用 Welch |
| Cohen's d | `d = (μ₁−μ₂)/s_pooled` | s_pooled 见下 |
| 合并标准差 | `s_pooled = √(((n₁−1)s₁²+(n₂−1)s₂²)/(n₁+n₂−2))` | 效应量分母 |
| 置信区间（95%） | `μ ± 1.96×(s/√n)` | 均值估计 |

**单位**：从数据字典读取（Iris 特征 `cm`、Concrete 强度 `MPa`、Wine 化学成分可能 `mg/L`/`g/L`），
图表与报告必须标注。**可接受波动**：浮点相对容差 `1e-6`；均值与金标准绝对差 `<0.001`；
随机种子固定后重跑应一致；**数据库查询行数必须与预期完全一致**。
**计算示例（Iris setosa sepal length）**：n=50，Σxᵢ=250.3，μ=5.006，Σ(xᵢ−μ)²=6.0885，s²=6.0885/49=0.124255，
s=0.3525；与 UCI 描述均值 5.006、SD 0.3525 一致，差异 <0.001，通过。

## 5. 领域知识清单

1. 缺失值默认为 0（均值/SD/回归中必须显式处理）。
2. 重复记录未去重（分组前必须检查）。
3. t 检验前提未检查（方差不齐用 Welch；严重偏态用 Mann-Whitney U）。
4. 混淆相关系数与因果（报告禁用因果语言）。
5. 有效数字不一致（均值 4 位、SD 3 位、p 3 位小数如 `p=0.032`）。
6. 图表单位缺失（轴标签须含单位如 `Sepal Length (cm)`，图例与字典一致）。
7. 数据库查询条件漏字段（如漏 `age>0`/`strength>0`）。
8. 随机种子未固定（抽样/划分/初始化须固定 `random_state`）。
9. 环境版本未记录（不同 pandas/numpy/scipy 可能差异）。
10. 路径写死（换环境失败）。

**单位/量纲**：Iris 四特征 `cm`，类别 setosa/versicolor/virginica；Concrete 强度 `MPa`、成分 `kg/m³`、
龄期 `day`（不同列单位不同，不可直接比较）；Wine 化学成分 `mg/L` 或 `g/L`，酒精常为 `% vol`。
**依据**：引用金标准须注明来源（UCI Machine Learning Repository、Bezdek Iris 变体、
Concrete Compressive Strength 数据集）；不得伪造文献/来源；外部描述在 `validation_report.json` 记 URL/DOI；
无法验证的明确标「未找到金标准，无法验证」。
