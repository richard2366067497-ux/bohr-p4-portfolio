# 专家参考手册 —— 学术演示稿生成（slides-02）

## 1. 交付什么（判分要点）

本任务的产物不是“一份 PPT 大纲”，而是一套**能够在科研案例上实际运行、从论文产出可复核学术演示稿的能力**。对每个案例，最终产物必须包含：

- **可编辑演示文件**（如 `.pptx`）：页级结构、主张、图表、讲稿/备注齐全；
- **页级证据映射**：每页内容能定位到论文图、表、章节或数据；
- **渲染与版本记录**：源文件、导出 PDF/PNG、字体/模板检查、修改记录；
- **结构化结果 `result.json`**：包含 `case_id`、输入标识、主结果、证据/来源定位、运行状态、不确定性、变更记录。

考察的依据是**实际运行结果与可核验记录**，而非文字自述。验收维度如下：

| 维度 | 关键考察点 |
|---|---|
| 实际效果 | 页数、页序、叙事角色、讲稿备注、导出件是否齐备；数字/图表/图注/引用编号与原文一致；六类要素覆盖；源文件、页级金标准、导出件、diff、日志可复核复跑 |
| 使用增益 | 相同输入下页面质量是否提升；返工页数、重排次数、导出复查轮次是否减少 |
| 创新增益 | 是否具备页序规划、模板槽位填充、图表数据绑定、局部编辑能力；方法是否实质改进；有无创新证据 |
| 可靠体验 | 调用是否简单；不同论文类型/模板/重复运行是否稳定；缺图、位图无法取数、模板槽位不足、字体缺失、页数超限、导出失败等异常是否被识别并处置 |
| 生态贡献 | 文档完整性、资源可复用性、分享推广价值 |

## 2. 分步流程与门控

| 步骤 | 输入 | 冻结产物 | 门控条件 |
|---|---|---|---|
| 0. 解析输入与约束 | `case.json`, `task.md`, 论文 PDF, 模板文件 | `input_summary.json`：案例 ID、论文路径、模板路径、页数/受众/时间约束、可用图表清单 | 所有路径有效；约束字段完整 |
| 1. 提取与结构化 | 论文 PDF、数据表 | `extracted_facts.json`：研究问题、方法、结果、限制、关键数字、图表清单、引用编号 | 每个关键事实有原文定位；无凭空数据 |
| 2. 页级规划 | `extracted_facts.json` + 约束 | `page_plan.json`：每页标题、核心主张、图表引用、讲稿要点、叙事角色 | 页数符合要求；每页有唯一主张；图表编号与原文一致 |
| 3. 模板槽位填充 | `page_plan.json` + 模板 | 可编辑 `.pptx` 文件 | 使用母版占位符；字体/配色/页脚符合模板；无内容溢出 |
| 4. 证据映射 | `page_plan.json` + 原文 | `evidence_map.json`：每页对应论文图/表/章节/数据定位及逐字引用 | 每页至少 1 条证据；引用准确 |
| 5. 渲染与校验 | `.pptx` | 导出 PDF/PNG + `render_report.json`：字体嵌入、溢出、裁剪、页数检查 | 无字体替换；无文字溢出；无图片裁剪；页数正确 |
| 6. 版本记录与打包 | 所有中间产物 | `result.json` + 版本文件 + 运行日志 | `result.json` 包含所有必需字段；版本可回溯；日志完整 |

**门控原则**：任一步骤未通过门控，不得进入下一步；若无法通过，必须在 `result.json` 中记录 `status: "partial"` 和 `uncertainty`，并说明限制。

## 3. 量化口径、公式与容差

| 指标 | 定义 | 公式 | 单位 | 可接受波动 |
|---|---|---|---|---|
| 页数符合度 | 实际页数与要求页数的偏差 | `abs(实际页数 - 要求页数) / 要求页数` | % | ≤ 0%（即完全一致；若允许 ±1 页需在 `task.md` 中明确） |
| 证据覆盖率 | 有证据映射的页数占总页数比例 | `有证据映射页数 / 总页数` | % | 100% |
| 数字一致率 | 抽查关键数字与原文一致的比例 | `一致数字数 / 抽查数字总数` | % | 100% |
| 模板符合度 | 使用母版占位符的页数占总页数比例 | `使用母版页数 / 总页数` | % | 100% |
| 渲染缺陷率 | 存在字体替换/溢出/裁剪的页数占总页数比例 | `缺陷页数 / 总页数` | % | 0% |
| 版本可回溯性 | 每轮修改是否有文件、diff、原因记录 | `有完整记录的版本数 / 总版本数` | % | 100% |
| 效率增益 | 采用本方法后相对原有流程减少的人工修改页数或轮次 | `(改进前修改页数 - 改进后修改页数) / 改进前修改页数` | % | ≥ 20% 可视为有效增益 |

**计算示例**：某案例要求 **12 页**，实际生成 **12 页**，证据映射覆盖 **12 页**，抽查 **10 个关键数字**全部与原文一致，模板母版使用 **12 页**，渲染缺陷 **0 页**，版本记录 **3 轮**均完整。

- 页数符合度 = `abs(12-12)/12 = 0%` ✅
- 证据覆盖率 = `12/12 = 100%` ✅
- 数字一致率 = `10/10 = 100%` ✅
- 模板符合度 = `12/12 = 100%` ✅
- 渲染缺陷率 = `0/12 = 0%` ✅
- 版本可回溯性 = `3/3 = 100%` ✅

若原流程平均需人工修改 **8 页**，采用本方法后需修改 **2 页**，则效率增益 = `(8-2)/8 = 75%` ✅

## 4. 领域陷阱与事实性错误（错误做法→正确做法）

### 4.1 通用制作陷阱

1. **整段复制论文摘要/段落进文本框** → 每页只保留 1 个核心主张，用短句或关键词，讲稿放备注。
2. **关键数字按印象取整或抄错** → 所有数字必须从原文逐字提取，保留有效位数和单位，证据映射中记录原文定位。
3. **图表用占位图或凭空生成曲线** → 优先引用原图；若需重绘，必须有数据表或可提取数据源，并注明“重绘自 Fig.X 数据”。
4. **覆盖模板母版、字体、配色、页脚** → 只填充内容占位符，不修改母版；若必须调整，记录 diff 并说明原因。
5. **导出 PDF 后字体替换、文字溢出、图片被裁** → 导出后逐页渲染检查，记录字体嵌入、溢出、裁剪情况。
6. **多轮迭代后无法回到上一版** → 每轮保存版本文件，记录改动内容和原因，保留 diff。
7. **没有页级证据映射** → 每页输出一个 `evidence` 字段，包含论文定位（如 `Sec. 3.2, Fig. 4, Table 2`）和逐字引用。
8. **忽略输入约束（页数、受众、时间）** → 先解析 `task.md` 中的约束，页规划时显式校验页数、受众、时长。
9. **虚构缺失数据或软件状态** → 论文缺图、位图无法取数时，明确标注“无法取数，使用原图引用”，不编造。
10. **只生成文本不生成可编辑文件** → 必须生成真实 `.pptx` 和导出 PDF/PNG，且文件可打开、可编辑。

### 4.2 本领域容易犯的事实性错误

1. **混淆方法、结果与讨论**：方法页只写“做了什么”，结果页只写“观察到什么”，讨论页才写“为什么重要”。
2. **图注编号错位**：Fig. 3 的内容写成 Fig. 4；正文引用 [12] 写成 [13]。
3. **单位写错**：`mM` 写成 `μM`，`nm` 写成 `μm`，`g/L` 写成 `mg/mL`。
4. **统计显著性抄错**：`p < 0.05` 写成 `p < 0.5`；`n = 6` 写成 `n = 3`。
5. **实验条件漏写**：温度、时间、pH、转速、光照强度等关键条件缺失。
6. **图表数据与正文不一致**：正文写“降解率 94.7%”，图上标注却是“91.4%”。
7. **引用编号与参考文献列表不对应**：正文引用 [15] 但参考文献只有 14 条。

### 4.3 单位/量纲陷阱

- 浓度：`mol/L`、`mM`、`μM`、`nM`，注意大小写和前缀。
- 长度：`nm`、`μm`、`mm`，材料领域常用 `nm` 表示粒径或膜厚。
- 温度：`°C` 与 `K` 不可混用；反应温度常写 `25 °C` 或 `298 K`。
- 转速：`rpm` 与 `×g` 不可混用；离心条件需明确。
- 电压/电流：`V`、`mA`、`mV`，电化学测试注意参比电极。
- 比表面积：`m²/g`，常用 BET 法。
- 带隙：`eV`，注意有效数字。

### 4.4 文献依据要求

- 每个事实必须有论文定位，格式如 `Sec. 3.2, para. 2` 或 `Fig. 4A`。
- 关键数字必须逐字引用原文，不得改写或四舍五入。
- 图表若为原图引用，需注明“原图引自 Fig.X”；若重绘，需注明数据来源（如 `Table 2` 或 `Fig. 5 数据提取`）。
- 模板约束：字体、字号层级、配色、页脚必须与母版一致，不得覆盖。
