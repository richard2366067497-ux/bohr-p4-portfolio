# 引文追踪与关联文献发现 · 专家参考手册（expert_playbook）

> 本手册随包分发，供执行前阅读。交付的不是“答案”，而是**以种子论文为起点、可独立运行、可复核、
> 可复现的追踪流程与资源**。执行时按 §2 八步框架推进、按 §3 量化口径计算、按 §4 排雷、按 §7 自查。

---

## §1 任务本质与判分要点

以**种子论文**为起点，沿引用关系（前向 / 后向）与关联信号（共被引、文献耦合、作者/机构、
数据集/任务）扩展文献，输出**可追溯的候选集、排序/筛选依据、证据记录、状态说明与遗漏说明**。

| 维度 | 核心关注 |
|-|-|
| 实际效果 | 是否真以种子为起点扩展；引用方向是否正确；身份合并是否正确；是否覆盖关键被出处、后续改进、平行工作；每条能否独立复核 |
| 使用增益 | 相比基础 Agent 是否提升追踪质量、减少人工核验；是否有公平对照 |
| 创新增益 | 是否具备基础 Agent 不具备的能力（跨库身份对齐、方向感知扩展、可解释路径） |
| 可靠体验 | 易触发、易用；跨学科/数据源/重复运行稳定；空结果、歧义、冲突、限流、权限异常有处置 |
| 生态贡献 | 文档齐全；脚本/词表/边表/去重规则可复用 |
| GitHub | 提交目录根路径放 `GITHUB_URL.txt`，链接可公开访问 |

**三条硬约束**：结果可复核（每条附数据源、查询、时间戳、locator）；不编造文献或数据；
实际运行产出 `result.json`，提交目录不冒充正式案例结果。

## §2 八步框架（含冻结产物与门控）

| 步骤 | 动作 | 冻结产物 | 门控 |
|-|-|-|-|
| 0 读取输入 | 读 `case.json` / `task.md` / 材料 / `resources.yaml` | `case_id`、种子标识、约束、数据源清单 | 种子可解析；至少一个数据源可用 |
| 1 种子身份规范化 | 取 DOI、标题、作者、年份、卷期 | `seed_identity.json` | 至少一个唯一标识（DOI 或 标题+第一作者+年份） |
| 2 后向追踪 | 从参考文献列表取被引，记边 `种子→被引` | `backward_edges.jsonl` | 每条边有来源 |
| 3 前向追踪 | 查施引文献，记边 `施引→种子` | `forward_edges.jsonl` | 无前向记录标空，不编造 |
| 4 关联发现 | 共被引 / 耦合 / 作者 / 数据集扩展平行工作 | `related_candidates.jsonl` | 每条关联有信号类型与依据 |
| 5 身份合并与去重 | 合并预印本/会议/期刊/增补版；识别同名不同文 | `merged_entities.jsonl` | 合并证据可追溯 |
| 6 排序与筛选 | 按相关性、方向、证据强度排序并应用停止判据 | `ranked_results.jsonl` | 排序依据明确、可复算 |
| 7 路径解释与网络 | 为关键远端文献给最短/最可信引用链，构建以种子为中心的网络 | `paths.jsonl`、`network_graph.json` | 每跳标注方向、数据源、语境线索 |
| 8 生成交付物 | 写 `result.json`（全部 `output_contract` 字段 + `case_id`）、证据、状态、遗漏 | `/app/output/result.json` 等 | 字段完整、无编造、限制已标注 |

## §3 量化口径（公式 + 判等 + 停止）

| 指标 | 公式 | 可接受 |
|-|-|-|
| 后向覆盖率 | 成功解析参考文献数 / 种子参考文献总数 = `|E_retrieved| / |E_known|` | ≥90% 优，80–90% 良 |
| 前向召回率 | 检索施引数 / 已知施引数（多源合并后） = `|C_retrieved| / |C_known|` | ≥80% |
| 关联精确率 | 相关数 / 返回总数 = `|Rel_retrieved| / |Retrieved|` | ≥60% |
| 关联召回率 | 相关数 / 已知相关总数 = `|Rel_retrieved| / |Rel_known|` | ≥80% |
| 身份合并准确率 | 正确合并对数 / 总合并对数 = `|Merge_correct| / |Merge_total|` | ≥90% |
| 路径可信度 | 路径上各边置信度的最小值 = `min(edge_confidence)` | ≥0.8 可信 |
| 去重键 | `norm_title|first_author_surname|year` | 完全匹配视为同一实体 |

**排序得分**：`Score = 0.5×引用关系强度 + 0.3×关联信号 + 0.2×证据可信度`

- 引用强度：直接引用（前向/后向）=1.0，间接引用（路径长 2）=0.7，共被引/耦合=0.5；
- 关联信号：方法相关=0.9，主题相关=0.7，作者相关=0.5；
- 证据可信度：DOI 匹配=0.95，标题匹配=0.85，作者年份匹配=0.7。

**计算示例（自洽）**

- 后向：种子参文 28 条，解析 DOI 25 条 → 覆盖率 25/28 = **89.3%**。
- 前向：Crossref 45 条 + EuropePMC 38 条，合并去重 52 条（重叠 31）；已知 60 条 → 召回率 52/60 = **86.7%**。
- 关联：共被引 12 + 耦合 8，合并 15（重叠 5）；核验相关 11 → 精确率 11/15 = **73.3%**；已知相关 14 → 召回率 11/14 = **78.6%**。
- 合并：原始 95 条，5 对重复，合并后 90 条；5 对中 4 对正确 → 准确率 4/5 = **80%**（低于阈值，需加作者全名匹配）。
- 排序：DimeNet（前向直接，方法相关，DOI 匹配）=0.5×1.0+0.3×0.9+0.2×0.95=**0.96**；
  SchNet（共被引，方法相关，DOI 匹配）=0.5×0.5+0.3×0.9+0.2×0.95=**0.71**；
  Faber et al.（前向直接，主题相关，标题匹配）=0.5×1.0+0.3×0.7+0.2×0.85=**0.88**。

**停止判据**

- 最大扩展层级 ≤ 3（种子为第 0 层）；每层新增 ≤ 50 条；
- 当某层新增文献中相关比例 < 10% 时停止；
- 示例：第 1 层 30、第 2 层 45、第 3 层 12，第 4 层新增 3 且相关 0 → 停止。

## §4 领域陷阱（错误 → 正确）

1. **只做关键词检索** → 必须从种子出发沿引用扩展，关键词仅作辅助信号。
2. **只取一层引用** → 支持多层级扩展并设停止判据（≤3 层、新增相关 <10%）。
3. **引用方向混淆** → 明确前向（施引→种子）与后向（种子→被引），每条边记方向。
4. **身份未合并** → 预印本/会议/期刊/增补版合并，保留合并证据。
5. **高被引当高相关** → 用共被引/耦合/方法主题关联排序并说明依据。
6. **结果不可复核** → 每条附数据源、查询、时间戳、locator。
7. **空结果/权限问题编造文献** → 诚实标注状态，不补造。
8. **只给列表不给证据路径** → 给引用链，逐跳标方向与数据源。
9. **忽略异常处理** → 明确限流、缺元数据、同名歧义、撤稿与更正的处置。
10. **提交预制答案** → 实际运行产出运行时产物。

**事实性清单**

- 混淆预印本与期刊版：同一论文的 arXiv 与期刊版应合并。
- 会议版与期刊版（如 NeurIPS 与 JMLR）应合并。
- 同名不同文：仅凭标题相似或第一作者相同就合并（忽略其他作者、年份、卷期）会错。
- 作者顺序变化通常不改变论文身份，但需谨慎。
- 撤稿论文必须标记，不作有效依据；更正文献需链接原文献，不单独当新文献。
- 数据集论文与方法论文须区分（引用方向不同）。

**量纲/口径陷阱**

- 引用次数 ≠ 相关性；共被引高 ≠ 方法相关，须结合标题/摘要。
- 文献耦合强度需归一化（Jaccard/cosine），避免绝对共引次数偏差。
- 路径并非跳数越多越好；最短路径可能更可信，但每条边须验证真实性。

**数据源限制**：Crossref 可能缺预印本前向引用，需结合 EuropePMC/Semantic Scholar/OpenAlex；
EuropePMC 非生物医学覆盖不全；Semantic Scholar 更新延迟、限流严；OpenAlex 覆盖广但元数据参差。
**多源交叉验证**：至少两个数据源确认同一引用边，才标记高可信。

## §5 交付物清单

| 文件/章节 | 必需内容 | 自证可核验 |
|-|-|-|
| `SKILL.md` | YAML frontmatter（name, description）+ 用途、调用方式、输入输出、异常处理 | 描述与实际一致 |
| `result.json` | `case_id`、候选、排序/筛选、元数据、来源定位、状态、不确定性、变更记录 | 每条有 locator，可独立复核 |
| 证据记录 | 每条查询/筛选/排序/追踪依据（查询语句、数据源、时间戳、返回数、筛选条件） | 可复算 |
| 身份合并记录 | 原始标识、合并后标识、合并理由 | DOI 相同 / 标题相似 / 作者年份匹配 |
| 引用路径 | 逐跳方向、数据源、语境线索 | 可复现 |
| 引用网络 | 节点与边有标识 | 可复现 |
| `README.md` | 使用说明、依赖、配置、种子样例、边表字段、去重规则、维护 | 他人可独立使用 |
| 最小调用示例 | 输入、调用方式、示意输出（标明示例） | 说明接口与完整流程 |

每条引用边必须有数据源依据（Crossref / EuropePMC / PDF 参考文献 / OpenAlex），不能仅凭记忆。

## §6 虚构案例演示（示意，不冒充正式结果）

输入种子：`{"case_id":"CASE-001","seed":{"doi":"10.5555/demo.2020.001","title":"Graph Neural Networks for Molecular Property Prediction","authors":["Smith, J.","Doe, A."],"year":2020},"task":"从种子扩展前向/后向各 2 层，发现关联文献，输出排序与证据"}`

- 种子身份：规范化标题 `graph neural networks for molecular property prediction`；第一作者姓 `smith`；
  年 2020；去重键 `graph neural networks for molecular property prediction|smith|2020`。
- 后向：参文 28 → 解析 DOI 25 → 覆盖率 89.3%；方法出处 Gilmer et al. 2017（MPNN），数据出处 Wu et al. 2018（MoleculeNet）。
- 前向：Crossref 45 + EuropePMC 38 → 合并 52（重叠 31）→ 召回率 86.7%；后续改进 Klicpera et al. 2020（DimeNet）、批评 Faber et al. 2021。
- 关联：共被引 12 + 耦合 8 → 合并 15（重叠 5）；方法相关 Schütt et al. 2018（SchNet）、主题相关 Vamathevan et al. 2019。
- 合并：种子预印本与期刊版合并为同一实体；另 2 对会议/期刊版合并，总量 95 → 90。
- 排序：DimeNet 0.96、Faber et al. 0.88、SchNet 0.71；停止：第 4 层新增 3 且相关 0 → 停止。
