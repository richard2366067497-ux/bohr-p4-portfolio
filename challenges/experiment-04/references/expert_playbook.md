# 专家参考手册 · 实验方案比较与选择（plan-choice-sensitivity）

> 本手册是本 Skill 的核心方法论基准：**执行前必读**。所有交付物（标准字典、候选矩阵、成本台账、
> 翻转报告、决策备忘）的**框架、检查表与评分口径**均以本手册为准。与 `SKILL.md` 冲突时：
> 契约键名以 `SKILL.md` 为准，方法/口径以本手册为准。

## 1 判分要点与失败模式

核心**不是设计实验方案，而是比较和选择**：构造可比候选、填入统一矩阵、给出可辩护的选择与
可量化的舍弃理由，并标注假设与待确认项。

| 关注点 | 权重方向 | 判定标准 |
|--------|----------|----------|
| 比较矩阵统一可比 | 实际效果 | 字段一致、单位一致、来源可查 |
| 选择结论有证据链 | 实际效果 + 使用增益 | 文献/设备手册/报价单 → 判断，逐条挂来源 ID |
| 成本核算完整 | 实际效果 + 创新增益 | 机时 + 耗材 + 人力 + 排期 + 返工 |
| 风险可处置 | 实际效果 + 可靠体验 | 触发条件、后果量级、缓解、回退 |
| 可被独立复算 | 可核验性 | locator、公式、原始数据 |

常见失败（错误 → 正确）：

| # | 错误做法 | 正确做法 |
|---|----------|----------|
| F1 | 三方案各写一段叙述，结构不同无法横比 | 先定义统一字段表（≥7 类），再逐方案填行 |
| F2 | 成本只算耗材单价，漏机时费和人力 | 成本 = 耗材 + 机时 + 人力 + 外测 + 返工预期，统一 CNY |
| F3 | 时间只算执行，不算准备与表征排队 | 时间 = 准备 + 排期 + 执行 + 表征 + 分析，分列 |
| F4 | 风险写"存在一定风险" | 风险 = 触发条件 + 概率 + 后果 + 缓解 + 回退 |
| F5 | 参数范围无来源 | 每参数标来源类型：`[设备手册]` `[文献]` `[预实验]` `[经验]` |
| F6 | 结论靠语气强度 | 每个判断挂具体来源 ID（如 `[Ref-3]`、`[设备手册-S4]`） |
| F7 | 搬文献通用流程不核对设备 | 逐条核对设备清单，标"可用/不可用/需外送" |
| F8 | 方案不足或全不可行时无处理 | 至少 2 个可行方案；全不可行须说明原因与替代方向 |
| F9 | 一次性投入与按次消耗混算 | 分开列：一次性（购置/改造）vs 按次（耗材/机时/外测） |
| F10 | 不确定度不标注 | 关键数值标 ±范围或置信等级（高/中/低） |

## 2 求解框架（Step 0–5）与门控

| 步 | 动作 | 冻结产物 | 门控 |
|----|------|----------|------|
| S0 | 读 case/task/附件，提取研究目标、硬约束、材料清单、输出格式 | `parsed_input.json` | 目标与硬约束明确；有歧义记假设并标 `[待确认]` |
| S1 | 构造 3 个候选（方法路线、步骤、关键参数、设备耗材） | `candidates.json` | 方案在方法路线上有实质差异（非同法微调） |
| S2 | 建统一比较矩阵（见 §2.1 的 7 类字段） | `comparison_matrix.{json,md}` | 所有方案同字段；每个数值有来源标注 |
| S3 | 定义评分规则 → 加权总分 → 排序 → 敏感性分析（权重 ±20%） | `scoring.json` | 推荐方案在 ±20% 内不翻转（翻转则标"边界决策"） |
| S4 | 写推荐优势 + 每个被弃方案的致命缺陷 + 翻转条件 | `decision.json` | 每个结论 ≥1 条可查证据 |
| S5 | 组装交付物并跑 §5 自查 | `result.json` + 附件 | 自查 15 项全通过或标注未通过项及原因 |

### 2.1 统一比较矩阵必须包含的 7 类字段

| 字段类别 | 子字段（最少） | 单位/格式 |
|----------|----------------|----------|
| 目标对齐 | 研究目标匹配度 | 高/中/低 + 理由 |
| 成本 | 耗材费、机时费、人力费、外测费、返工预期成本 | CNY，精确到元 |
| 时间 | 准备、排期、执行、表征、分析 | 人·天，精确到 0.5 天 |
| 可行性 | 设备可用、耗材可得、人员技能、安全审批 | 可用/需协调/不可用 |
| 风险 | 触发条件、概率、后果、缓解、回退 | 结构化条目 |
| 证据强度 | 文献支撑数、预实验数据、历史成功案例 | 计数 + 来源 ID |
| 参数窗口 | 关键参数范围及来源 | 数值 ± 范围 + 来源标签 |

**映射到本 Skill 产物**：S2↔`criteria_matrix.json`（标准字典 + 权重和校验 + min-max 归一化区间
+ 逐候选得分与覆盖率）；S3 敏感性↔`flip_report.json`（逐假设扫描 + 二分阈值 + `stable` 判定）；
成本↔`cost_ledger.json`；证据↔`evidence.json`；对比表↔`version_diff.md`；决策↔`decision_memo.md`。

## 3 量化口径（逐条可复算）

### 3.1 成本核算

```
总成本(CNY) = 耗材费 + 机时费 + 人力费 + 外测费 + 返工预期成本
  耗材费 = Σ(单品单价 × 用量 × (1 + 损耗率))
  机时费 = 设备小时单价 × 使用小时数
  人力费 = 人员日薪 × 投入人·天
  外测费 = 外送表征单项费 × 样品数
  返工预期成本 = 预估返工概率 × 单次返工成本
```

示例：前驱体 X 单价 500 元/瓶(10 g)、用量 3 g/次、损耗 10%、需 5 次
→ 500×(3/10)×1.1×5 = **825 元**；衬底 Y 50 元/片 ×1 ×5 = 250 元；耗材合计 = 1075 元。

### 3.2 时间核算

```
总日历天数 = 准备 + 排期等待 + 执行 + 表征排队 + 数据分析
人力投入(人·天) = 样品预处理 + 实验操作 + 数据处理
  准备时间 = max(耗材采购等待, 样品预处理)   — 可并行取最大
  表征排队 = max(各表征排队时间)             — 可并行送样取最大
```

示例：准备 max(采购 7, 清洗 0.5)=7；排期 3；执行 2.5；表征 max(XRD 2, SEM 5, XPS 10)=10；分析 2
→ 总日历 **24.5 天**，人力 **5 人·天**。

### 3.3 风险量化

| 概率等级 | 定义 | 数值映射 | | 后果等级 | 定义 | 成本映射 |
|----------|------|----------|-|----------|------|----------|
| 高 | >30% | 0.3–0.5 | | 严重 | 全部返工 | ≥ 单次成本 100% |
| 中 | 10–30% | 0.1–0.3 | | 中等 | 部分补做 | 单次 30–70% |
| 低 | <10% | 0.01–0.1 | | 轻微 | 微调重做 | 单次 <30% |

**返工预期成本 = 概率 × 后果成本**。示例：温度均匀性不达标概率 0.2，后果全部返工（单次 1875 元）
→ 0.2 × 1875 = **375 元**。

### 3.4 评分矩阵与敏感性

| 维度 | 权重 | 评分规则 |
|------|------|----------|
| 目标匹配度 | 20% | 高=10, 中=6, 低=3 |
| 总成本 | 20% | 10 × (最低成本/该方案成本) |
| 总时间 | 15% | 10 × (最短时间/该方案时间) |
| 可行性 | 20% | 全可用=10，1 项需协调=7，2 项=4，有不可用=0 |
| 风险 | 15% | 10 × (最低返工成本/该方案返工成本) |
| 证据强度 | 10% | 来源数 ≥5=10，3–4=7，1–2=4，0=0 |

敏感性：各维度权重 ±20% 扰动，若推荐不翻转 → **稳健决策**；翻转 → **边界决策** 并标翻转条件。

## 4 领域陷阱与单位

| 陷阱 | 说明 | 正确处理 |
|------|------|----------|
| 设备能力夸大 | 不区分 FE-SEM / W-SEM | FE-SEM ≈1 nm，W-SEM ≈3–5 nm |
| 温度范围越限 | 管式炉标"可达 1600 °C"但型号上限 1200 | 必须核对输入材料的设备型号 |
| 耗材可得性误判 | 假设试剂随时可买 | 常规试剂 1–3 天，特殊试剂 2–8 周 |
| 表征时间低估 | 只算测量 30 min | 总时间 = 制样 + 排队 + 测量 + 导出 |
| 安全审批遗漏 | 涉及 HF/有机溶剂/高温高压未提审批 | 须标注安全审批需求 |
| 人力成本漏算 | 只算操作时间 | 新设备/新方法首用需额外 1–3 天培训 |
| 机时单位混用 | 小时/天/班次 | 统一为小时，1 班次 = 8 小时 |
| 货币混用 | USD/CNY/EUR | 统一 CNY，标汇率来源与日期 |

来源优先级：设备手册 > 同行评审文献 > 预印本 > 实验室历史记录 > 经验估计；每方案 ≥2 条引用；
不可用来源标注 `[来源不可用-待补充]`，不可编造。

## 6 完整案例（硅片 MoS₂ 薄膜制备路线选择）

> 目标：硅片上制备 50±5 nm MoS₂ 薄膜。硬约束：设备=管式炉(≤1000 °C)/磁控溅射/CVD(≤1100 °C)；
> 预算 ≤15000 CNY；时间窗 ≤30 天；H₂S 需额外安全审批约 5 天。

**候选**：A CVD 直接生长（850 °C/15 min/Ar 50 sccm [Ref-1]）；B 磁控溅射 + 后退火硫化
（溅射 100 W，退火 700 °C，H₂S 5% [Ref-2]）；C 溶液旋涂 + 热解（3000 rpm/30 s，600 °C/2h [Ref-3]）。

**成本**：A = 11000（耗材 2500 + CVD 机时 4000 + 人力 1500 + 外测 2000 + 返工预期 1000）；
B = 11800（耗材 3200 + 机时 2600 + 人力 2000 + 外测 2000 + 返工 2000）；
C = 8900（耗材 1800 + 机时 1200 + 人力 1000 + 外测 2500 + 返工 2400）。

**时间**：A 20 天 / B 39 天（超窗口）/ C 18.5 天；人力分别为 4.5 / 5.5 / 4.5 人·天。

**评分**：A = 10×0.20 + 8.09×0.20 + 9.25×0.15 + 10×0.20 + 10×0.15 + 7×0.10 = **9.21**；
B = **6.17**；C = **7.73**。敏感性：所有 ±20% 权重扰动下 A 始终最优 → **稳健决策**。

**结论**：推荐 A。舍弃 B 的致命缺陷是**时间超窗口**（39 > 30 天，Mo 靶材 14 天货期 + H₂S 审批 5 天）；
舍弃 C 因薄膜均匀性证据不足（`[Ref-3]` 仅报道小面积均匀）、返工概率高达 0.3。
翻转条件：若 CVD 排期 >12 天 → C 成唯一时间可行选项；若预算收紧至 10000 CNY → A 超预算需重评。

## 7 专家注意点（逐条排雷）

1. **统一字段先于填数**：先定义字段表与单位，再逐方案填行，否则无法横比。
2. **可并行取最大**：准备/表征排队用 max 而非求和，避免高估工期。
3. **一次性 vs 按次分开**：设备购置与耗材机时不得混为一谈。
4. **结论挂证据**：每个判断都要落到具体来源 ID，禁止无来源断言。
5. **硬约束优先**：违反硬约束的方案直接淘汰，不进入评分排序。
6. **数字自洽**：分项加总 = 总计；成本/时间与矩阵行一致，误差 <5%。
7. **翻转条件必写**：给出"若 XX 变化，应改选 Y"的触发边界。
8. **不确定度可见**：关键数值标 ±范围或置信等级，缺失来源标注而非编造。
