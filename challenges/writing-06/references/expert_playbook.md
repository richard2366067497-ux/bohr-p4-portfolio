## 1. 任务本质与判分要点

### 1.1 任务本质

交付物不是“润色全文”或“重写一篇”，而是对真实稿件完成 **有原文证据的结构诊断，并生成
作者可执行、可复核、可继续编辑的修改方案**。六个必查维度为：研究问题与贡献对齐、章节结构
与叙事顺序、论证链与论据对应、段落关系、重复内容、结论边界。某维度可以“已检查，未发现
主要问题”，但不能为凑数虚构缺陷。

### 1.2 判分要点（优先级从高到低）

1. **实际效果**：定位准确、动作具体、链条闭合、证据可回溯。
2. **使用增益**：减少人工拆解、定位与核对；同稿对照与增益由平台实测，不自报提分或效率数据。
3. **创新增益**：结构缺陷与语言偏好、事实疑点被正确区分。
4. **可靠体验**：异常可恢复，部分结果诚实保存。
5. **生态贡献**：方法可被同款任务复用而无需重写。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 罗列“逻辑应更清晰”等通用原则 | 每个问题绑定章节、段落、句子及逐字证据 |
| 上交一篇无法对照的全文改写 | 给出移动、合并、拆分、删除、收窄等原子编辑动作 |
| 预设稿件一定有因果夸大或章节冗余 | 从实际文本出发；检查覆盖六类，但不强制六类都有问题 |
| 只写“见讨论部分” | 使用稳定 locator，并附短引文和文档版本 |
| 把口语化、术语偏好当结构错误 | 区分结构缺陷、语言偏好和事实疑点，只将前者计入主诊断 |
| 将同一根因在多处出现拆成多个问题刷数量 | 建一张主问题卡，列出全部关联位置 |
| 无证据便补机制、文献、统计显著性 | 删除、收窄或列入人工确认，不新增材料外事实 |
| 仅凭段落相似便判重复 | 排除必要呼应、术语复现和“结果陈述—讨论解释”的功能差异 |
| PDF 解析失败后猜正文 | 标记解析异常，保留可用部分并降低结论范围 |
| 缺少参考文献即判论证无效 | 区分“材料缺失”“无法判断”和“确认无支撑” |
| 自称效率提高 50%、准确率达 95% | 只报告实际测量值；无基线、无人工标注时不计算此类指标 |
| 只交付 `result.json` 或只交付报告 | 同时满足原始 `output_contract`，并提供可编辑证据化产物 |

## 2. 求解框架（6 步法）

| 步骤 | 动作 | 冻结产物 | 门控 |
|---|---|---|---|
| S1 读取合同与盘点输入 | 读取 `case.json`、`task.md` 及真实附件，提取 `case_id`、受众、体裁、输出字段、禁止事项 | 运行清单：输入路径、SHA-256、解析器状态、原始输出字段 | `case_id` 唯一；缺文件、截断、乱码分别记录，不依据领域标签补造内容 |
| S2 建立可追溯原稿地图 | 保留标题层级、正文段落、图表题注、公式和参考文献；按“章节路径—P 段落—S 句子”编号 | `source_map`：locator、原文、页码（若有）、解析置信状态 | 所有后续引文必须能精确匹配原稿；疑似缺章或截断不得静默修补 |
| S3 抽取研究链和事实底账 | 抽取研究问题、贡献主张、方法、结果、结论、限制；建立“论断—证据”表 | 研究链表、事实底账、缺失信息表 | 每个核心结论可追到结果、图表、合法引文，或被标为 unsupported/uncertain |
| S4 执行六维诊断并去重 | 先章节内、再跨章节；区分观察、推断和建议；按“核心结论受损＞论证断裂＞叙事阻碍＞局部重复”排序 | 原子问题卡：`issue_id`、主/关联维度、位置、逐字引文、判断依据、严重度、置信度 | 无证据候选不得进入主结果；六维均有检查结论；同根因不重复计数 |
| S5 生成可执行编辑计划 | 每个动作写明操作类型、源位置、目标位置、保留内容、修改后文本或目标状态、前置动作、人工确认项 | 有依赖顺序的 `edit_plan` | 不得引入新实验、新引文或新事实；动作之间不得互相覆盖 |
| S6 闭环复核与交付 | 重跑“研究问题→方法→结果→结论→限制”矩阵，检查数字、单位、引文、定位与修改差异 | 诊断报告、机器可读问题表、修改记录、验证摘要 | 合同字段完整、JSON 可解析、引文匹配、数字一致；未通过项进入 `partial`，不写成 `completed` |

**映射到本 Skill 产物**

| 步骤 | 对应产物 |
|---|---|
| S1 | `result.json`（`case_id`、`output_contract`、`degradations`）、`<work>/inventory.json` |
| S2 | `consistency_report.md` 的文件清单与标题层级；finding 的 locator |
| S3 | `argument_map.json`（研究问题句、主张-证据链、unsupported 计数） |
| S4 | `structural_review.json`（六维结论、finding 全量、维度覆盖、逐字引文核验率） |
| S5 | `edit_plan.md`、`outline_after.md`（含 `draft.json` 注记并入） |
| S6 | `pending_human.json`、`semantic_audit.json`、`metrics.json`、`result.json` |

## 3. 量化口径与判定规则

### 3.1 问题卡统一结构

推荐问题卡采用统一结构：

`位置证据 → 结构功能判断 → 对研究链的影响 → 编辑动作 → 修改后边界 → 复核方法`

### 3.2 指标（用于自查，不是官方评分，也不能替代人工判断）

| 指标 | 定义与公式 | 建议口径 |
|---|---|---|
| 六维检查覆盖率 | 已实质检查维度数 ÷ 6 × 100% | 目标 100%；“无问题”也须有检查依据 |
| 有效定位率 | 含可解析 locator 和精确引文的问题卡数 ÷ 问题卡总数 | 目标 100%，不允许跨轮次漂移 |
| 可执行动作率 | 同时含操作、源位置、目标/目标状态的问题卡数 ÷ 总问题卡数 | 目标 100% |
| 论断证据闭合率 | 有直接证据支撑的核心论断数 ÷ 核心论断总数 | 描述原稿状态，不作为论文质量分 |
| 数字保真率 | 与来源一致或标注为派生计算的数字数 ÷ 输出数字总数 | 目标 100%；派生值须给公式和输入 |
| 重复候选相似度 | 3-gram 集合的 Jaccard：\(J=|A\cap B|/|A\cup B|\) | \(J\ge0.65\) 进入人工语义复核；0.40–0.65 仅在功能相同时复核 |
| 修改解决率 | 已有对应动作的问题卡数 ÷ 总问题卡数 | 不等于作者采纳率，更不等于质量增益 |

### 3.3 相似度示例与允许波动

示例：两段的 3-gram 集合大小分别为 12、16，交集为 12，则并集为 \(12+16-12=16\)，
\(J=12/16=0.75\)。它只能触发重复复核，不能单独证明应删除。

**允许波动**：百分比统一保留 1 位小数；相同输入与相同分词规则下，集合数、相似度、定位及
引文应零漂移。生成式表述和问题排序可以变化，但事实、数字、来源不得变化。没有固定金标准时，
不报告“召回率”；没有实际作者计时时，不报告“节省多少时间”。

## 4. 领域知识清单

- **不凭常识纠正科研事实。**材料、化学、生物等标签可能错误，论文原文和随附数据才是本次
  编辑依据。
- **区分独立实验与技术重复。**`n=3` 不可擅自写成“三个生物学重复”；均值±SD、SEM、
  置信区间不可互换。
- **保持单位与量纲。**不得混淆 `%` 与“百分点”、mM 与 mmol、转速与相对离心力、产率与
  选择性。绝对温度 °C 与 K 不可直接混用，但温度差的 1 °C 等于 1 K。
- **保留计算精度与比较基准。**“提高 25%”必须说明相对哪一组；不能把相对变化改成绝对差，
  也不能由均值差异推出统计显著。
- **不越界解释因果。**机理表征、动力学同位素实验、对照或统计设计与结论强度必须匹配；
  只有速率数据时不能补写电子转移机制。
- **文献只能沿用已核验来源。**不得凭记忆补 DOI、作者、年份或结论；缺参考文献时标记来源
  缺口。正文的原创论断与文献转述也要分开。
- **图表缺失不等于结果不存在。**只能写“当前材料无法核对图 X”，不能虚构图中趋势，
  也不能断言原研究未做该实验。

## 6. 完整虚构案例

> **以下为虚构接口示例，不是正式测试答案。** `case_id=DEMO-STRUCT-001`，
> 任务为“诊断结构问题并给出可执行修改方案”。

### 6.1 输入原稿节选

- **§1-P1：**“本文研究焙烧温度是否改变催化剂 A 的产氢速率，并比较 300、400、500 °C 三组。”
- **§1-P2：**“BET 测试在 77 K 下进行，样品测试前脱气。”
- **§1-P3：**“本研究揭示焙烧温度增强电子转移的机制。”
- **§2-P1：**“每组独立制备 3 个批次，在相同进料下测定 2 h 平均产氢速率。”
- **§3-P1：**“300、400、500 °C 组分别为 8.0±0.4、10.0±0.5、9.0±0.4 mmol·g⁻¹·h⁻¹（n=3，均值±SD）。”
- **§4-P1：**逐字重复 §3-P1。
- **§4-P2：**“速率提高证明电子转移增强。”
- **§5-P1：**“400 °C 显著提高产氢速率 25%，适用于所有 A 类催化剂。”

原稿未提供显著性检验或电子转移表征。

### 6.2 关键中间量

相对 300 °C 组，400 °C 组的均值变化为：

\[
\frac{10.0-8.0}{8.0}\times100\%=25.0\%
\]

单位为 `mmol·g⁻¹·h⁻¹`；绝对差为 `2.0 mmol·g⁻¹·h⁻¹`，不能写成“提高 2.0%”。

| 核心论断 | 支撑状态 | 依据 |
|---|---|---|
| 400 °C 组观测均值最高 | 支持 | §3-P1 |
| 相对 300 °C 组高 25.0% | 支持，派生计算 | §3-P1 及上述公式 |
| 电子转移增强 | 无直接支撑 | 未提供机理测量 |
| 显著且适用于所有 A 类催化剂 | 越界 | 无统计检验，且仅测试一种催化剂 |

因此原稿论断证据闭合率为 \(2/4=50.0\%\)。§3-P1 与 §4-P1 非空且完全相同，故 \(J=1.00\)，
仍需结合段落功能判断后删除重复陈述。

### 6.3 输出修改方案

| ID | 维度、定位与证据 | 可执行动作 |
|---|---|---|
| D1 | 研究问题/贡献对齐，关联论证链；§1-P3“揭示……机制”、§4-P2“证明……”超出 §2-P1/§3-P1 证据 | 将 §1-P3 收窄为“本文比较 300–500 °C 焙烧对催化剂 A 产氢速率的影响”；将 §4-P2 改为“本实验未测量电子转移，不能据此确定机制” |
| D2 | 章节结构；§1-P2 为表征细节，中断研究问题与贡献的衔接 | 将 §1-P2 原句整体移至 §2“表征”位置，不修改数值和条件 |
| D3 | 重复内容；§4-P1 逐字重复 §3-P1 | 保留 §3-P1，删除 §4-P1；讨论仅保留有新增解释的内容 |
| D4 | 结论边界；§5-P1 含“显著”和“所有” | 替换为限定性结论（见下） |

**建议执行顺序：**D2 → D3 → D1 → D4。

**D4 修改后文本：**

> “在本文 300、400、500 °C 及相同进料条件下，400 °C 组的 2 h 平均产氢速率最高
> （10.0±0.5 mmol·g⁻¹·h⁻¹，n=3，均值±SD），相对 300 °C 组高 25.0%。本结果不构成统计
> 显著性或电子转移机制的证据，也不外推至其他催化剂。”

### 6.4 输出状态与复核结果

- 六维检查覆盖率：\(6/6=100.0\%\)；段落关系未发现另一项独立主要缺陷，不凑数。
- 有效定位率：\(4/4=100.0\%\)；可执行动作率：\(4/4=100.0\%\)。
- 数字保真率：\(100.0\%\)；25.0% 明确标为派生值。
- `status="completed"`：结构诊断任务本身可完成；原稿的证据不足记录在不确定性中，
  而非伪装成运行失败。
- 人工确认项：若作者坚持保留“显著”，须补充实际统计检验、统计量、自由度和精确 P 值；
  若坚持保留机理主张，须补充对应机理证据。不得由现有均值和 SD 静默补做事后检验。
- 修改记录：D1–D4 均可独立采纳或驳回；未使用任何外部来源，未新增实验事实。

## 7. 交付前门控

- 逐项勾选 §5 专家检查表；任一项未通过，先修复再交付。
- 确认每个 finding 都能沿“locator → 逐字引文 → 编辑动作 → 目标状态”走通。
- 确认六维均有检查结论，且同一根因未被拆成多张问题卡刷数量。
- 确认未新增材料外事实、文献、数值或“显著性”结论；异常已分类记录。
