# 专家参考手册 —— 研究前沿与趋势分析（事件台账优先）

本手册是 research-frontier-event-timeline 的**执行前必读**方法论：规定未知科研案例上"时间趋势－主题演化－
代表性工作－研究空白"四类产物的提取口径、量化公式、证据定位规范与交付自查清单。执行时按本手册推进，产出后逐项过 §6。

## 1. 任务本质与判分要点

### 1.1 真正要交付什么

不是"前沿清单"，而是**四类可独立复核的产物**，每个结论都回链到具体文献段落（locator），并区分
"材料事实 / 合理推断 / 无法确定"：

1. **时间趋势**：按年份/时间窗统计产出量、主题占比、增长速率，区分波动与拐点，说明数据口径。
2. **主题演化**：追踪主题词的出现、合并、分裂、衰退，识别术语漂移，给出阶段划分依据。
3. **代表性工作**：各阶段选代表作，说明入选口径与覆盖范围，避免只用总被引排序。
4. **研究空白**：从反复未解决问题、方法失效、证据冲突未决识别空白，给出检索范围与排除条件。

### 1.2 评委看哪几件事

| 维度 | 权重 | 关键考察点 |
|---|---|---|
| 实际效果 | 40 | 四类产物可检查、正确、完整、可核验；年份口径、主题归属、代表作与结论是否与原文一致；检索式、统计表、结论回链能否独立复算 |
| 使用增益 | 25 | 相比基础 Agent 的质量提升（趋势更准、空白更可靠）与效率提升（减少重复检索、手工统计）；需公平对照证明 |
| 创新增益 | 15 | 是否形成基础 Agent 不具备的时间切片统计、主题演化追踪、代表作选取、空白判定能力；相对已有工具边界是否清晰 |
| 可靠体验 | 10 | 调用简单、运行稳定、异常处理到位（检索为空、年份缺失、主题歧义、文献量爆炸、证据冲突、权限不足） |
| 生态贡献 | 10 | 文档完整、资源可复用；脚本、词表、题集、评分表能否被他人复用 |

### 1.3 常见失败模式（错误做法 → 正确做法）

| 错误做法 | 正确做法 |
|---|---|
| 把检索结果前若干条当"前沿" | 按年度分布与主题演化证据识别前沿，前沿必须有时间趋势支撑 |
| 把关键词热度当"趋势" | 区分离散波动与真实拐点，用阈值规则或变化点检测（如相邻年变化 >30% 且绝对增量 ≥3 篇） |
| 把术语换说法当"新兴主题" | 建同义词表，归并术语漂移，确认主题首次出现且有后续增长 |
| 把被引最高的一批当"代表作" | 按阶段选取，覆盖不同子主题，优先方法首创，避免遗漏长尾方法首创工作 |
| 把"没检索到"当"研究空白" | 给出检索范围、数据库、时间窗、语言、文献类型等排除条件，证明不是检索遗漏 |
| 结论无回链 | 每条趋势判断、演化结论、空白主张回链到具体文献段落（如 `Smith 2022, Fig. 3, 第4段`） |
| 数据口径不清 | 明确在线发表、见刊、预印本分别统计，说明对结论的影响 |
| 主观判断无参考答案与不确定性 | 写明参考答案、来源定位、可接受范围与不确定性 |
| 运行失败无日志 | 保留检索式、脚本日志、版本记录，失败时可定位和恢复 |
| 输出不可复算 | 提供检索式、时间切片口径、主题归并规则、统计表与复算命令 |

## 2. 求解框架（步骤 0–9，含冻结产物与门控）

每步有**冻结产物**与**门控条件**，未过门控不得进入下一步。预算约 64 次模型请求 / 900 秒 / 单次回复 16384 token；
**尽早保存部分结果，增量改进**。

| 步骤 | 输入 | 操作 | 冻结产物 | 门控条件 |
|---|---|---|---|---|
| 0. 读取输入与资源清单 | `/input/case.json`、`task.md`、材料 | 解析 case_id、研究问题、约束、材料清单 | `case_meta.json` | case_id 存在，材料路径有效，读实际文件而非标签 |
| 1. 问题拆解与检索范围 | 任务说明 | 提取研究问题，拆解为对象/方法/比较/结果要素，定义检索范围 | `research_question.json` | 检索式覆盖 ≥2 个数据库/来源，纳排规则可执行 |
| 2. 文献收集与去重 | 候选文献 | 收集元数据，按 DOI 优先、其次标题+年份去重 | `papers_raw.json`、`papers_dedup.json` | 去重后 ≥10 篇（否则标记"文献量不足"进入异常） |
| 3. 年份归一与时间切片 | 去重文献 | 统一年份口径，按年份统计产出量、主题占比、增长速率 | `trend_stats.csv` | 时间跨度覆盖要求，每年文献数完整，口径说明清楚 |
| 4. 主题归并与演化追踪 | 标题/摘要 | 提取主题词，建同义词表，识别出现/合并/分裂/衰退 | `topic_evolution.json` | 归并规则可复现，阶段划分有年份依据，演化事件有文献支撑 |
| 5. 代表性工作选取 | 去重文献、主题表 | 按阶段选代表作，覆盖子主题，优先方法首创 | `representative_works.json` | 每阶段 ≥1 篇，覆盖主要子主题，入选口径明确 |
| 6. 研究空白识别 | 文献、主题表 | 从反复未决/方法失效/冲突未决识别空白，给检索范围与排除条件 | `research_gaps.json` | 每个空白有排除证据（检索式+结果），非"没检索到" |
| 7. 证据矩阵与结论回链 | 全部中间产物 | 构建证据矩阵，每条结论回链到具体段落 | `evidence_matrix.csv` | 关键判断可回到材料，locator 格式统一 |
| 8. 不确定性评估 | 全部中间产物 | 列出冲突证据、偏倚、空白、无法确定项 | `uncertainty.json` | 不越过证据扩展结论，标注三类状态 |
| 9. 输出结构化结果与可编辑产物 | 全部中间产物 | 生成 `result.json`、可编辑图与 PDF/PNG 预览 | `/app/output/result.json`、`figures/`、`report.md` | 契约字段齐全，可编辑产物有预览，部分结果标限制 |

**门控示例**：步骤 2 去重后文献 <10 篇 → 触发"文献量不足"异常，缩小结论范围并明示，不得强行宣称前沿。

## 3. 专家方法与量化口径

### 3.1 时间趋势指标

- **年度产出量** \(N_y\)：某年文献数量。
- **主题占比** \(P_{t,y} = N_{t,y} / N_y\)。
- **增长速率** \(r = (N_{y2}-N_{y1})/N_{y1}\)，或 **CAGR** \(= (N_{y2}/N_{y1})^{1/(y2-y1)} - 1\)。
- **拐点判定**：相邻年份变化率 >30% **且**绝对增量 ≥3 篇，或用变化点检测（如 PELT）。
  例：2019→2020 产出 18→22，增长率 22.2%、增量 4，**不构成**拐点（<30%）；2020→2021 22→25，13.6%，不构成。
- **数据口径**：分别统计在线发表、见刊、预印本；两者年份差异大时须说明对趋势的影响。

### 3.2 主题演化指标

- **出现**：\(N_{t,y}\ge1\) 且此前所有年份 \(N_{t,y'}=0\)。
- **合并**：两主题共同出现在同一文献的比例上升（如 <10% → >30%）。
- **分裂**：一个主题分化出多个子主题，且子主题独立增长。
- **衰退**：连续 3 年占比下降，且末年占比低于峰值 50%。
- **术语漂移**：建同义词表，如 "moisture stability" 与 "humidity stability" 归并为"环境稳定性"。

### 3.3 代表性工作选取

- **入选口径**：每阶段 ≥1 篇，覆盖不同子主题，优先方法首创（用引用上下文或综述确认），避免只用总被引。
- **阶段代表性指数**（可选）：\(S = 0.4\times\text{归一化被引} + 0.3\times\text{方法新颖性} + 0.3\times\text{主题覆盖度}\)，权重需说明。

### 3.4 研究空白判据

- **反复未解决**：在 ≥3 篇中作为 open question 提出，且无后续解决证据。
- **方法失效**：在特定对象/尺度上无成功应用，检索式覆盖该对象+方法，结果为空或均为失败报告。
- **证据冲突未决**：≥2 篇结论相反，且无后续裁决。
- **排除条件**：明确检索范围、数据库、时间窗、语言、文献类型。

### 3.5 计算示例（数字自洽）

某主题 2018–2023 产出量 12, 15, 18, 22, 25, 28，则
CAGR \(=(28/12)^{1/5}-1\approx 18.5\%\)；主题 A 占比 2018 年 20% → 2023 年 35%，增长 15 个百分点；
2021 年增速从 22.2% 降至 13.6% 但绝对增量仍为 3 篇，不满足阈值（>30% 且 ≥3），**不构成拐点**。

## 4. 领域知识清单

### 4.1 容易犯的事实性错误

| 错误 | 正确做法 |
|---|---|
| 混淆材料名称（"钙钛矿" vs "钙钛矿氧化物"） | 确认具体化学式，不同体系分开归并 |
| 混淆工艺参数（K vs °C、Pa vs bar vs atm、M vs mol/kg） | 保留原始单位，统计时统一并标注换算 |
| 忽略实验条件（湿度/气氛/光照） | 不脱离条件引用结论 |
| 把模拟结果当实验事实 | 明确标注"模拟"或"计算" |
| 把预印本当见刊 | 确认文献状态，预印本须标注 |
| 把综述观点当原始证据 | 综述结论须回链到原始研究 |

### 4.2 单位/量纲陷阱

- 温度：0 °C = 273.15 K。
- 压力：1 bar = 100 kPa = 0.9869 atm。
- 浓度：1 M = 1 mol/L；mol/kg 需知道密度。
- 电流密度：1 mA/cm² = 10 A/m²。
- 波长：1 μm = 1000 nm。能量：1 eV = 96.485 kJ/mol。
- 效率/稳定性：% 与绝对效率、小时/天/年须统一基准。

**必须在证据矩阵中标注原始单位，统计时再统一。**

### 4.3 文献依据要求

- 每个事实性判断回链到具体段落（locator），如 `Smith et al. 2022, Fig. 3, 第4段`；不能仅凭标题或摘要下结论。
- 区分**材料事实**（文献明确报道）、**合理推断**（基于多篇综合）、**无法确定**（证据不足或冲突）。

## 7. 一个完整虚构案例演示

> 以下论文、数据与结果全部虚构，仅演示接口与计算，禁止作为正式案例答案复用。

**输入**：`case_id=case_perovskite_stability_2024`；研究问题"钙钛矿太阳能电池稳定性研究在 2018–2023 的时间趋势、
主题演化、代表性工作与研究空白"；约束 `time_window=[2018,2023]`、`databases=[Web of Science, Scopus]`、英文、article/review。

**关键中间量**：

- **检索式**：`TS=("perovskite solar cell*" AND stability)`，在 WoS 与 Scopus 执行。
- **去重后文献**：120 篇（WoS 80、Scopus 90，去重后 120）。
- **年度分布**：2018:15, 2019:18, 2020:22, 2021:25, 2022:28, 2023:32；CAGR \(=(32/15)^{1/5}-1\approx 16.4\%\)。
- **主题归并**："moisture stability" 与 "humidity stability" → "环境稳定性"；"thermal stability"、"light stability" 独立。
- **主题演化**：2018–2019 主主题"组分工程"（40%）；2020–2022"界面钝化"出现并增长（10%→30%）；2023"自修复"首现（5%）。
- **代表性工作**：2018 Smith et al.（组分工程，被引 500，方法首创）；2021 Chen et al.（界面钝化，300，方法首创）；
  2023 Wang et al.（自修复，50，方法首创、长尾覆盖）。
- **研究空白**：子主题"柔性钙钛矿稳定性"，检索式 `TS=("flexible perovskite" AND stability)` 仅 3 篇且均未解决机械弯曲下长期稳定性；
  排除条件：WoS+Scopus、2018–2023、英文、article/review、排除会议摘要。

**输出要点**（`result.json` 片段语义）：`case_id` 原样透传；`status="completed"`；
`sources=["WoS export 2024-01-15","Scopus export 2024-01-15"]`；`uncertainty=["2023 年数据可能不完整（在线发表滞后）",
"主题归并存在主观性，同义词表见 resources/synonyms.csv"]`；`change_records=["v1 初始统计 110 篇","v2 补 Scopus 去重后 120 篇"]`。
研究产物四件：年度分布（含 cagr 0.164 与年份口径说明）、主题演化阶段、代表作清单（带 selection_rationale）、研究空白（带 exclusion_conditions）。

**证据矩阵片段**（CSV）：`literature_id,source,year,topic,key_finding,evidence_locator,inclusion_rationale`
→ `Smith2018,WoS,2018,组分工程,混合阳离子提升稳定性,Fig. 3 第4段,阶段代表/方法首创`；
`Chen2021,Scopus,2021,界面钝化,钝化层降低缺陷密度,Fig. 2 第2段,阶段代表/方法首创`；
`Wang2023,WoS,2023,自修复,自修复聚合物提升寿命,Fig. 4 第1段,长尾方法首创`。

**可编辑产物**：`trend_plot.png`、`topic_evolution.png`，均附 PDF 预览。

**复算**：CAGR、年度分布、主题占比、空白检索式均可由上述输入独立验证（\(28/12\)、\(32/15\) 等算式可直接重算）。
