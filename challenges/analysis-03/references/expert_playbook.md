# 专家参考手册 —— 科研数据可视化与投稿级图件（analysis-03）

执行前**完整阅读本手册**，按 §2 流程推进，交付前逐项过 §7 自查表。本领域要把数据表做成
**可投稿图件 + 可复核证据链**：以声明的图件规格为唯一事实源，渲染器只执行规格，每个视觉元素都能回算到源数据行。

## 1. 质量维度（判分要点）

- **实际效果（40）**：是否真的产出图件 + 代码 + 图注；图上每个视觉元素是否与源数据一一对应；
  是否覆盖坐标轴、单位、图例、误差线、显著性标记、色标范围、图注、面板编号、导出格式与分辨率；
  从源数据到成图能否被他人独立复跑并逐元素核对。
- **使用增益（25）**：相比朴素做法，图表正确性、规范性、可读性是否提升；是否减少重画、格式调整、
  导出试错与人工核对；是否用公平对照证明「画得更准、更规范」。
- **创新增益（15）**：是否形成朴素做法不具备的能力——按数据结构推荐图型、图表元素与源数据一致性校验、
  目标期刊导出规格适配、灰度与色觉障碍检查、统计标注与图注自动生成。
- **可靠体验（10）**：能否正确触发；在宽表/长表、缺失列、字段类型混杂、中文列名、日期时间、不同规模、
  重复运行下稳定产出；对缺失、异常、重复、样本量不足、类别过多、导出失败、字体缺失的识别与处置。
- **生态贡献（10）**：文档完整、资源可复用、可分享推广。

## 2. 求解流程（每步有冻结产物与门控）

0. **读取输入与数据字典**：解析 case_id、任务要求、数据路径、字段语义、约束。*冻结* `input_summary`。
   *门控*：确认已读实际文件、未假设内容；字段语义已记录。
1. **数据清洗与口径确认**：检查缺失/异常/重复；定处理规则（删除/插补/保留标记）；统一字段类型。
   *冻结* `cleaned_data.csv`、`cleaning_rules.json`。*门控*：缺失率/异常数/重复数已量化；规则可复现。
2. **统计假设与描述统计**：按目的选方法；检查正态性（Shapiro-Wilk）、方差齐性（Levene/Bartlett）；
   算描述统计（均值、SD、SE、CI、中位数、IQR）；做组间比较（t/ANOVA/Kruskal-Wallis）或相关/回归。
   *冻结* `stats_summary.json`。*门控*：方法选择有依据；假设检验已记录；效应量已算。
3. **图表选择与编码映射**：按数据类型（连续/分类/时间序列/多变量/分组）与目的（分布/比较/相关/趋势/构成）
   选图型；决定位置/长度/颜色/形状/分面映射；处理类别过多、量纲差异、双轴、对数变换。
   *冻结* `chart_spec.json`。*门控*：图型与数据结构匹配；编码映射明确；**拒绝图型的原因已说明**。
4. **生成图件与图注**：运行绘图脚本；加坐标轴标目、单位、图例、误差线定义、显著性标记、样本量、统计方法；
   图注独立可读。*冻结* `figure.pdf/png`、`figure_caption.md`、`plot_script.py`。*门控*：每个视觉元素与源数据一一对应。
5. **导出与质量检查**：导出矢量或 ≥300 dpi 位图；检查字体嵌入、中文与特殊符号、画布尺寸、线宽、最小字号；
   灰度与色觉障碍可读性检查。*冻结* `exported_figure.pdf/png`、`quality_report.json`。
6. **结构化结果与证据打包**：生成 `result.json`（case_id、分析结果、质量与复现证据、异常说明、状态、不确定性、
   变更记录）；所有产物落 `/app/output`。*门控*：`result.json` 含全部必需字段；路径有效；可按记录复跑。

## 3. 常见失败模式（错误做法 → 正确做法）

1. **只给文字建议，不给图件** → 实际生成箱线图 PDF/PNG，并附绘图代码、图注、统计结果。
2. **图型与数据结构不匹配**（无序分类画饼图、时间序列画并列柱）→ 分组比较用箱线/小提琴；趋势用折线；
   构成用堆叠条形（类别 ≤5）。
3. **坐标轴处理不当**（截断基线、对数轴当线性轴、不标单位）→ 柱状基线从 0；对数轴明确标 `log₁₀(x)`；
   轴标目含变量名与单位。
4. **误差线含义不明** → 图注写明「均值±标准误（SE）」或「95% 置信区间」。
5. **编码不可读**（灰度/色觉障碍不可辨、类别过多硬塞）→ 用 Okabe-Ito / viridis 色盲友好配色、灰度可辨；
   类别 >8 考虑分面或降维。
6. **标注缺失**（无单位、图例、样本量、统计方法）→ 图注独立可读，含样本量、检验方法、显著性标记、误差线定义。
7. **导出不可用**（分辨率不足、字体未嵌入、中文乱码、尺寸不符）→ 矢量 PDF/EPS 或 ≥300 dpi PNG/TIFF；
   字体嵌入；中文用支持字体；画布匹配期刊单栏/双栏宽度。
8. **过程不可复核** → 保留原始快照、清洗规则、统计脚本、日志、软件版本；数字可追溯到源数据。
9. **静默修改异常** → 明确记录缺失处理规则、异常判据（IQR 1.5 或 Z>3），并在结果中说明。
10. **预制答案或伪造数据** → 实际读取 `case.json` 与 `task.md`，基于真实数据运行。

## 4. 量化口径与公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 缺失率 | `缺失数 / 总记录数 × 100%` | 逐列 |
| 异常判定 | IQR 法 `< Q1−1.5×IQR` 或 `> Q3+1.5×IQR`；Z 法 `\|Z\|>3` | 明确选一种并记录 |
| 均值 | \(\bar{x}=\frac{1}{n}\sum x_i\) | 原数据单位 |
| 样本标准差 | \(SD=\sqrt{\frac{1}{n-1}\sum (x_i-\bar{x})^2}\) | 分母 n−1 |
| 标准误 | \(SE=SD/\sqrt{n}\) | 作误差线须注明 |
| 95% CI | \(\bar{x}\pm t_{0.975,n-1}\times SE\) | t 临界值 |
| Cohen's d | \(d=(\bar{x}_1-\bar{x}_2)/SD_{pooled}\)，\(SD_{pooled}=\sqrt{\frac{(n_1-1)SD_1^2+(n_2-1)SD_2^2}{n_1+n_2-2}}\) | 效应量 |
| η²（ANOVA） | \(\eta^2=SS_{between}/SS_{total}\) | 效应量 |
| 分辨率 | 位图 ≥300 dpi；矢量无分辨率概念 | 导出设置 |
| 字体嵌入 | PDF 字体全部嵌入 | 用 `pdffonts` 检查 |

**可接受波动**：均值/SD 等保留 3–4 位小数，跨软件差异 ±0.001 内可接受；固定随机种子（如 `random_state=42`）
并记录；记录 Python/pandas/matplotlib/seaborn/scipy 版本。
**计算示例（Iris，sepal length，setosa vs versicolor）**：setosa n=50 mean=5.006 SD=0.352；
versicolor n=50 mean=5.936 SD=0.516。SE_setosa=0.352/√50=0.0498，SE_versicolor=0.516/√50=0.0730；
95% CI_setosa=[4.906,5.106]；SD_pooled=√(((49×0.352²)+(49×0.516²))/98)=0.4417；SE_diff=0.4417×√(1/50+1/50)=0.08834；
t=(5.006−5.936)/0.08834=−10.53，p<0.001；Cohen's d=−2.106。

## 5. 领域陷阱

1. 饼图用于无序分类比较（适合构成，不适精确比较；类别 >5 用条形图）。
2. 时间序列用并列柱（趋势应用折线）。
3. 对数轴当线性轴（刻度标注原始值或明确 `log₁₀(x)`）。
4. 误差线不说明是 SD/SE/CI。
5. 前提不满足仍用参数检验（非正态/方差不齐 → Mann-Whitney U / Kruskal-Wallis 或变换）。
6. 重复测量误当独立样本（用配对检验或混合效应模型）。
7. 单位混淆（如 mg/L 与 μg/mL 相差 1000 倍）。
8. 日期时间解析错误（字符串日期当文本排序）。
9. 中文乱码（未指定/未嵌入中文字体）。
10. 分辨率不足（默认 72 dpi，投稿需 ≥300 dpi）。

**单位/量纲**：浓度 mg/L、μg/mL、ppm、ppb 换算；对数变换后轴标原始单位但刻度为对数间隔；
百分比与比例（0.15 是 15% 还是 0.15% 须在图注明确）；温度 ℃ 与 K 不可混用。
**依据**：图件规范参考 APA 7th、Nature、Science；统计方法引用标准教科书或软件文档；
数据来源注明版本（Iris 150 条、Wine 178 条、Concrete 1030 条）；色盲友好配色参考 Okabe-Ito / viridis。

## 6. 交付物与可核验性

**图件**（每图一份）：`figure.pdf/png` + `figure_caption.md` + `plot_script.py`；`stats_summary.json`
（描述统计、检验结果、效应量）；`cleaning_rules.json`（缺失/异常/重复规则）；`quality_report.json`
（分辨率、字体嵌入、尺寸、配色检查）；`result.json`（case_id、分析结果、质量与复现证据、异常说明、状态、
不确定性、变更记录）。**每个数字附 locator**（如 `output/figures/iris_boxplot.pdf` 第 2 页，
或 `analysis_results.json → statistics.mean`）+ 复算命令；规则依据逐字引用数据字典/workorder。

## 7. 防扣分自查表（交付前逐项通过）

- 是否读取实际 `/input/case.json` 与 `task.md`，而非假设内容？
- 是否记录数据字典、字段语义与约束？
- 是否对缺失/异常/重复有明确规则并记入 `cleaning_rules.json`？
- 是否检查统计假设（正态性、方差齐性）并记录？
- 图型是否与数据类型和分析目的匹配？是否给出被拒图型的原因？
- 坐标轴是否从 0 开始（除非有理由）？对数轴是否标注？
- 误差线是否注明 SD/SE/CI？
- 图例、单位、样本量、统计方法说明是否齐全？图注是否独立可读？
- 配色是否色盲友好、灰度可辨？类别过多是否分面？
- 导出是否矢量或 ≥300 dpi 位图？字体是否嵌入？中文是否正常？
- 是否保留原始值、规则、日志、代码版本？是否提供最小调用示例（标明示例）？
- 是否对异常/失败明确说明，不静默修改？是否在 `/app/output` 生成 `result.json` 且含全部必需字段？

## 8. 虚构案例（自洽校验）

输入：150 行 iris，列 `sepal_length, sepal_width, petal_length, petal_width, species`，无缺失无重复。
中间量：IQR 法各组 sepal_length 无异常；Shapiro-Wilk setosa W=0.977 p=0.459、versicolor W=0.978 p=0.338、
virginica W=0.971 p=0.181（均 p>0.05 正态）；Levene W=2.41 p=0.058（方差齐）；描述统计
setosa n=50 mean=5.006 SD=0.352 SE=0.0498 CI=[4.906,5.106]，versicolor mean=5.936 SD=0.516 CI=[5.789,6.083]，
virginica mean=6.588 SD=0.636 CI=[6.407,6.769]；ANOVA F(2,147)=119.26 p<0.001 η²=0.619；Tukey HSD 各组间 p<0.001。
输出：箱线图 `iris_sepal_length_boxplot.pdf`（x=species，y=Sepal Length (cm)），图注含 n、ANOVA、Tukey、
正态与方差齐结论；`result.json` 记录图件/统计/清洗/质量证据路径与不确定性；复算命令
`python plot_iris_boxplot.py --input cleaned_data.csv --output figures/iris_sepal_length_boxplot.pdf --stats stats_summary.json`。
所有数字可由 `cleaned_data.csv` 复算，图件与统计结果一致。
