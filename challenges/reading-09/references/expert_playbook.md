## 任务理解与判分要点

### 真正要交付什么

本任务要求交付一个**可被 Agent 调用的 Skill 包**，而非预先生成的答案。Skill 在 3 个未知固定科研案例上运行，输入为 `/input/case.json`、`task.md` 及实际论文 PDF/材料，输出为结构化笔记与 `result.json`。核心交付物是：

1. **SKILL.md**：有效 YAML frontmatter，写清用途、适用条件、调用方式、输入输出、异常处理。
2. **运行必需脚本与资源**：PDF 解析、章节切分、字段抽取、知识点提取、笔记生成等脚本及配置。
3. **使用与方法说明**：完整调用步骤、字段字典、锚点格式、依赖、限制、失败处理、自查方法。
4. **最小调用示例**：至少一组输入、调用方式和示意输出，标明为示例。
5. **GITHUB_URL.txt**：公开可访问的 GitHub 链接。

运行后每个案例需返回结构化结果，包含：**输入标识、主结果、证据/来源定位、运行状态、不确定性**。关键结论必须回到原文具体位置（页码、段落、图表、公式），未报告/无法判断必须明确标注，不得写成事实。

### 评委看哪几件事

| 评分维度 | 分值 | 评委实际关注点 |
|-|-|-|
| 实际效果 | 40 | 笔记是否与论文章节对齐、字段齐备、可继续使用；论断/数值/变量是否与原文一致；锚点是否指向真正位置；关键章节与要素是否覆盖；每条关键笔记能否按锚点回原文 |
| 使用增益 | 25 | 加载 Skill 后，笔记的结构性与可靠性是否优于基础 Agent；是否减少整理耗时、人工补写、返工；是否有公平对照证明改善 |
| 创新增益 | 15 | 是否形成章节对齐、字段化、锚点回链、可检索笔记等基线不具备的能力；方法是否实质改进；是否有证据证明创新价值 |
| 可靠体验 | 10 | Agent 能否正确触发；不同论文类型/篇幅/重复运行下是否稳定；对扫描件、加密、双栏错序、图表公式缺失、超长文、非中文论文等异常是否识别与处置 |
| 生态贡献 | 10 | 文档是否齐全；脚本、模板、词表、示例是否可复用；是否沉淀可分享的案例、模板、Benchmark 与经验 |
| GitHub 链接 | 5 | 未登录可访问，能找到本次作品 |

### 常见失败模式（错误做法 → 正确做法）

1. **错误**：把论文压缩成一段通读摘要，套用通用模板（背景-方法-结果-结论）。  
   **正确**：按论文自身章节结构逐节提炼，保留章节标题与论证顺序，明确章节间承接关系。

2. **错误**：锚点只写“见论文”或“见第 3 节”，无法复核。  
   **正确**：锚点精确到页码、段落号、图表编号、公式编号，如 `Fig. 3b, p.4, para.2`，并附逐字引用。

3. **错误**：把“未报告”写成“无效果”或“不显著”。  
   **正确**：明确标注“原文未报告 p 值/数据”，与“报告了无显著差异”区分。

4. **错误**：忽略图表、公式、补充材料中的关键数据。  
   **正确**：提取图表编号、公式编号及变量定义，并回链到原文位置；补充材料单独标注。

5. **错误**：对扫描件/加密文档直接失败或强行 OCR 后当作原文。  
   **正确**：识别文档类型，降级处理，在 `result.json` 中标注“扫描件，无法提取文本，需人工接管”，不伪造数据。

6. **错误**：提交预制答案或正式测试输出。  
   **正确**：Skill 本体只包含规则、脚本、模板，实际运行由平台执行。

7. **错误**：`result.json` 缺少 `case_id`、`status`、`sources`、`uncertainty` 等字段。  
   **正确**：完整输出所有 `original output_contract` 字段，并记录运行状态与不确定性。

8. **错误**：术语缩写不处理，导致知识点条目重复或矛盾。  
   **正确**：建立同义词表（如 XRD = X-ray diffraction），归并同义条目，保留原始表述。

9. **错误**：双栏 PDF 按列提取导致阅读顺序错乱。  
   **正确**：按阅读顺序提取，检测双栏布局并合并为正确段落顺序。

10. **错误**：效率/质量增益仅文字自述，无对照记录。  
    **正确**：用同论文集合、同解析方式、同预算的公平对照，记录基础 Agent 与 Skill Agent 的耗时、结构化得分、锚点可核验率等量化指标。

## 求解框架

从输入材料到交付物的分步流程，每步有冻结产物与门控。

### 步骤 0：读取输入与任务识别

- **输入**：`/input/case.json`、`/input/task.md`、论文 PDF 及材料路径。
- **动作**：解析 `case.json` 获取 `case_id`、材料路径、任务类型；读取 `task.md` 识别具体要求（章节总结/论文卡片/知识点提取/来源回链等）。
- **冻结产物**：`input_summary.json`（含 case_id、任务类型、材料路径、输出要求）。
- **门控**：若 `case.json` 或 `task.md` 缺失，记录 `status="failed"`，原因写入 `result.json`，不继续。

### 步骤 1：PDF 解析与文本提取

- **动作**：调用 PDF 解析脚本，提取原始文本、章节标题、图表编号、公式编号、页码。检测双栏布局并按阅读顺序合并；检测扫描件/加密文档。
- **冻结产物**：`raw_text.json`（按页存储文本）、`layout_info.json`（双栏/单栏、图表公式位置）。
- **门控**：若文本提取失败或为扫描件，记录 `status="partial"`，标注“无法提取文本，需人工接管”，跳过后续自动抽取，仅输出可人工处理的元数据。

### 步骤 2：章节切分与对齐

- **动作**：基于论文自身标题层级（如 Introduction, Experimental, Results and Discussion, Conclusion）切分章节，不套用通用模板。记录每章起始页码、段落范围。
- **冻结产物**：`section_map.json`（章节标题、页码、段落范围、章节间承接关系）。
- **门控**：若章节标题缺失，使用正则匹配常见标题模式；若仍失败，标注“章节结构未识别”，按页码顺序切分并记录不确定性。

### 步骤 3：字段化抽取

- **动作**：按任务要求抽取研究问题、数据、方法条件、主要发现、结论、局限等字段。每个字段值附 locator（页码、段落、图表、公式）。区分“未报告”与“否定结果”。
- **冻结产物**：`fields.json`（字段名、字段值、locator、是否未报告）。
- **门控**：必填字段缺失时，记录 `status="partial"`，在 `uncertainty` 中列出缺失字段及原因。

### 步骤 4：知识点提取与归并

- **动作**：提取重要概念、变量、方法、结论，拆成可检索条目。处理术语缩写与同义表述（如 XRD = X-ray diffraction），归并重复条目，避免矛盾。
- **冻结产物**：`knowledge_items.json`（条目 ID、内容、类型、locator、同义词映射）。
- **门控**：若发现矛盾条目，保留双方并标注“原文存在矛盾/需人工确认”，不强行合并。

### 步骤 5：证据回链与核验

- **动作**：对每条关键笔记生成 locator，并做逐字引用校验。逐字引用必须与原文完全一致，否则降级为“转述”并标注。
- **冻结产物**：`evidence_links.json`（笔记 ID、locator、逐字引用、是否一致）。
- **门控**：若 locator 无法定位到具体段落/图表/公式，标注“锚点粒度不足”，在 `uncertainty` 中记录。

### 步骤 6：生成结构化笔记与 result.json

- **动作**：汇总章节总结、论文卡片、知识点清单、证据链接，生成 `notes.md`。构建 `result.json`，包含 `case_id`、`status`、`sources`、`uncertainty`、`change_records` 及所有 `original output_contract` 字段。
- **冻结产物**：`notes.md`、`result.json`。
- **门控**：若任何步骤失败，`status` 设为 `partial` 或 `failed`，在 `result.json` 中记录失败原因和可人工接管位置。

### 步骤 7：自检与降级

- **动作**：运行自检脚本，检查锚点可核验率、字段覆盖率、逐字引用准确率、章节对齐率。若低于阈值，降级处理并记录。
- **冻结产物**：`self_check.json`（各项指标、是否达标、降级原因）。
- **门控**：自检不通过时，不删除已生成的部分结果，保留并标注限制。

## 专家方法与量化口径

### 关键指标定义与公式

| 指标 | 定义 | 公式 | 单位 | 目标 | 可接受波动 |
|-|-|-|-|-|-|
| 章节对齐率 | 笔记章节与论文章节匹配数 / 论文章节总数 | `(N_matched / N_total) × 100%` | % | ≥90% | ±5% |
| 字段覆盖率 | 已填充必填字段数 / 必填字段总数 | `(F_filled / F_required) × 100%` | % | 100% | 0% |
| 锚点可核验率 | 可定位到具体段落/图表/公式的笔记条数 / 关键笔记总条数 | `(K_located / K_total) × 100%` | % | ≥95% | ±3% |
| 逐字引用准确率 | 逐字引用与原文完全一致的引用数 / 总逐字引用数 | `(Q_exact / Q_total) × 100%` | % | 100% | 0% |
| 未报告标注率 | 标注为未报告/无法判断的条目数 / 应标注条目数 | `(U_marked / U_should) × 100%` | % | 100% | 0% |
| 运行成功率 | 成功完成案例数 / 总案例数 | `(C_success / C_total) × 100%` | % | 100% | 允许部分完成但需明确 |
| 效率增益 | 基础 Agent 耗时与 Skill Agent 耗时之差 / 基础 Agent 耗时 | `(T_base - T_skill) / T_base × 100%` | % | ≥30% | ±10% |
| 质量增益 | Skill 结构化得分与基础得分之差 / 基础得分 | `(S_skill - S_base) / S_base × 100%` | % | ≥20% | ±5% |

### 计算示例（数字自洽）

假设某案例论文共 6 个章节，笔记覆盖 6 个章节：

- 章节对齐率 = `(6 / 6) × 100% = 100%`
- 必填字段 10 个，全部填充：字段覆盖率 = `(10 / 10) × 100% = 100%`
- 关键笔记 20 条，19 条可定位到具体段落/图表/公式：锚点可核验率 = `(19 / 20) × 100% = 95%`
- 逐字引用 5 条，5 条完全一致：逐字引用准确率 = `(5 / 5) × 100% = 100%`
- 应标注未报告 3 条，全部标注：未报告标注率 = `(3 / 3) × 100% = 100%`
- 基础 Agent 耗时 600 秒，Skill Agent 耗时 240 秒：效率增益 = `(600 - 240) / 600 × 100% = 60%`
- 基础结构化得分 55，Skill 得分 88：质量增益 = `(88 - 55) / 55 × 100% = 60%`

## 领域知识清单

### 容易犯的事实性错误

1. **混淆“未报告”与“无效果”**：论文未报告 p 值或置信区间，不等于“无显著差异”。必须标注“原文未报告”。
2. **图表数据目测**：不能从图中目测数值，除非明确说明“从图 X 估算”，并引用图表编号。应优先引用正文中明确给出的数值。
3. **公式符号改写**：公式中的符号、上下标、变量定义必须保留原文，不能自行改写或统一符号。
4. **摘要与正文不一致**：摘要中的结论可能与正文数据不完全一致，需以正文数据为准，并标注差异。
5. **补充材料遗漏**：关键数据可能在 Supporting Information 中，需单独提取并回链。
6. **术语同义混淆**：如 XRD 与 X-ray diffraction 是同一方法，但 XRD 与 XRF 不同；需建立同义词表，避免错误归并。
7. **双栏 PDF 错序**：双栏论文按列提取会导致阅读顺序错乱，需按阅读顺序合并。
8. **非中文论文翻译**：翻译时需保留原文术语，标注“原文为英文，此处为翻译”，避免误译。

### 单位/量纲陷阱

| 场景 | 常见陷阱 | 正确做法 |
|-|-|-|
| 材料科学 | wt%, at%, mol%, ppm, ppb 混用 | 保留原始单位，标注换算关系，不自行换算 |
| 化学工艺 | 温度 K vs °C，压力 Pa vs bar vs atm | 保留原始单位，必要时在括号中标注换算值 |
| 浓度 | mol/L vs mol/kg，体积浓度 vs 质量浓度 | 区分并保留原始表述 |
| 催化 | TOF (h⁻¹), TON 无量纲 | 保留单位，不省略 |
| 光学 | nm, eV, cm⁻¹ 混用 | 保留原始单位，标注对应关系 |

### 文献依据要求

- 每个关键结论必须回到原文具体位置（页码、段落、图表、公式）。
- 逐字引用必须与原文完全一致，否则降级为“转述”并标注。
- 未报告、无法判断、材料冲突必须明确说明，不得写成事实。
- 锚点粒度与可核验性匹配：重要论断锚点到段落或图表，一般性描述可锚点到章节。

## 一个完整虚构案例演示

### 输入

```json
{
  "case_id": "case_demo_001",
  "task_type": "literature_structured_notes",
  "material_path": "/input/paper_demo.pdf",
  "task_requirements": ["章节总结", "论文卡片", "知识点提取", "来源回链"]
}
```

`task.md` 要求：按论文章节总结，提取研究问题、数据、方法、主要发现、局限，知识点可检索，每条关键笔记回链原文。

论文：虚构材料科学论文《Enhanced photocatalytic degradation of methylene blue by TiO₂/g-C₃N₄ heterojunction under visible light》，共 6 页，6 个章节：Introduction, Experimental, Results and Discussion, Conclusion, References, Supporting Information。含 12 个图表、8 个公式。

### 关键中间量

| 步骤 | 产物 | 关键数值 |
|-|-|-|
| PDF 解析 | `raw_text.json` | 6 页文本，12 个图表编号，8 个公式编号，双栏布局已合并 |
