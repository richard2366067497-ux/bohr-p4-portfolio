# GAIN_EVIDENCE · kb-version-qa

记录加载本 Skill 前后在同类任务上的可观察增益（形式为方法对照；具体数值随案例材料而定，不冒充正式测试分数）。

| 能力 | 基础流程常见表现 | 本 Skill 的做法 | 目标口径 |
|---|---|---|---|
| 盘点完整性 | 只列文件名/大小，遗漏不可读项 | 递归盘点 + 哈希 + 权限 + 可读性，跳过必记录 | 覆盖率达标 |
| 关系判定 | 按文件名猜重复/版本 | 内容 SHA-256 + 版本证据链，禁无记录覆盖 | 去重/版本准确率达标 |
| 证据回链 | 只给结论无定位 | 每条结论附 locator / 冻结产物指针 | 证据可核验 |
| 可复跑 | 只有最终结果 | operations 日志 + 哈希清单 + 固定命令 | 可复跑率达标 |
| 异常处置 | 静默跳过、谎报完成 | status 区分 completed/partial/failed 并列限制 | 静默跳过 =0 |

## 量化目标（来自专家手册）

文件覆盖率 ≥95%；元数据完整率 ≥95%；版本关系准确率 ≥90%；证据覆盖率 ≥90%；证据准确率 ≥90%；缺证判断准确率 ≥90%；可复跑率 ≥95%；效率增益 ≥20%。

## 对照说明

- 同输入、同权限下，本 Skill 通过「先盘点、再计划、后落库、终自检」的分段冻结，减少返工与人工核对条目。
- 差异可通过 `result.json.coverage`、操作日志与自检报告复核；不编造对照分数。
