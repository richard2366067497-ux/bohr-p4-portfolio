## 1. 任务本质与判分要点

### 1.1 任务本质

交付物不是“写作建议”或预制范文，而是**一整套证据约束、可追溯、可复算的学术写作工作流产物**：
在未知案例上读取真实材料，产出可编辑稿件，并同步给出事实来源、引用核验、修改记录、材料缺口
和运行状态。写得多不等于写得好；**不可回查的句子是负债**。

### 1.2 判分要点（优先级从高到低）

1. **实际效果**：完整成稿而非提纲；数值、样本量、统计量、图注和参考文献准确；必需章节齐全；
   每个事实能回查。
2. **使用增益**：相同输入与权限下，相对基础 Agent 减少缺项、错引和返工。**没有真实对照记录，
   不得宣称提升百分比。**
3. **创新增益**：优先形成“材料—论断—图表—引用”四向映射、自动数值复算、缺项检测等可运行能力。
4. **可靠体验**：能处理 PDF、DOCX、CSV、图片等材料；遇到缺图、乱码、冲突或文献不可访问时
   仍保存诚实的部分结果。
5. **生态贡献**：`SKILL.md`、脚本、模板、虚构示例和自查方法可独立复用；公开 GitHub 链接须
   免登录可访问。

### 1.3 错误做法 → 正确做法

| 错误做法 | 正确做法 |
|---|---|
| 根据文件名或领域标签猜实验内容 | 实际读取文件，记录路径、哈希、页码或行号 |
| 只输出章节提纲、写作建议 | 直接写出满足体裁和篇幅要求的完整文本 |
| 用“合理值”补齐缺失样本量、DOI | 显式标注“缺 X 待核”，列入人工复核队列 |
| 看到均值不同就写“显著提高” | 仅有统计检验依据时报告显著性，否则只描述观察差异 |
| 仅凭论文标题挂引用 | 保存支撑原句、具体位置及元数据核验状态 |
| 将计算值伪装成原始测量值 | 区分原始事实与派生量，保存公式、输入和精度 |
| 为补齐章节虚构方法或声明 | 保留必需标题，显式写明材料缺口 |
| 只返回 JSON，没有可编辑稿件 | 稿件、证据表、检查记录和 `result.json` 一并交付 |
| 到运行末期才保存结果 | 初稿形成即写入 `/app/output`，随后增量完善 |

## 2. 求解框架（6 步法）

所有正式结果写入 `/app/output`，中间产物写入 `/app/work`。下表中的冻结产物一旦通过门控，
后续修改必须留下记录。

| 步骤 | 操作 | 冻结产物 | 门控条件 |
|---|---|---|---|
| S1 读取契约 | 读 `/input/task.md`、`case.json` 及实际附件；提取体裁、章节、字数、格式、引用与 `output_contract` | `run_manifest.json`：案例标识、输入哈希、约束、计划输出 | 输出字段逐项复制，不自创替代字段；缺文件与解析失败分开记录 |
| S2 材料索引 | PDF 按页解析，表格保留表头，图片记录图号与分面；乱码或低文本 PDF 转视觉/OCR 检查 | `material_index.jsonl`：材料 ID、路径、SHA-256、定位信息、提取状态 | 每条采用材料均可打开、可定位；不可读内容不得猜测 |
| S3 证据登记 | 将原始观测、外部文献、派生计算和未知项分类；保存短逐字引文 | `evidence_index.jsonl` | 数字必须有来源；派生量必须有公式和输入证据 ID |
| S4 章节—证据规划 | 展开必需章节、图表和声明，为每个事实性论断绑定证据 | `coverage_matrix.csv`、`evidence_map.csv` | 必需项均有“完成/缺口”状态；无证据内容不得作为事实进入正文 |
| S5 成稿 | 先写完整可编辑稿，不等待非关键补充；引用使用稳定内部 ID，最后统一格式 | `/app/output/manuscript.md`，按要求增加 DOCX 等 | 不是素材堆叠；不引入任务禁止的外部事实 |
| S6 三路核查与交付 | 复算数值，核对摘要—结果—图注，逐条检查论断—引文—文献条目；保存修改记录与状态 | `numeric_checks.csv`、`citation_audit.csv`、`review_queue.md`、`result.json` | 阻断性错误为 0；合同字段完整、文件非空、复算命令实际执行；失败则保留部分产物并写明限制 |

**时间预算**：材料冲突时并列保存两个值及其位置；仅当任务明确规定来源优先级时才选定，否则标记
“需人工确认”。运行失败时仍保留已完成的稿件和检查表。初稿形成即写盘，不要攒到最后。

## 3. 量化口径与判定规则

### 3.1 质量指标

设事实性论断数为 \(F\)，其中有充分证据者为 \(S\)，有有效定位者为 \(L\)；引用实例数为 \(C\)，
同时满足“支撑该句且书目信息正确”者为 \(C_s\)。

\[
R_{\mathrm{cov}}=\frac{S}{F}\times100\%,\qquad
R_{\mathrm{loc}}=\frac{L}{F}\times100\%,\qquad
R_{\mathrm{cite}}=\frac{C_s}{C}\times100\%.
\]

目标均为 100%。待核内容**不算**已支撑事实；装饰性引用计入 \(C\) 但不计入 \(C_s\)。

- **章节完成率**：实际完成的必需项数 / 必需项总数。空标题和待核占位不计“完成”，另报缺口标注率。
- **数值一致率**：通过复算的数值项 / 全部数值项，目标 100%。
- **无依据事实数**：目标 0，**不能用较高的平均覆盖率抵消单个虚构值**。

### 3.2 精度与统计

连续重复测量按任务要求报告：

\[
\bar{x}=\frac{\sum x_i}{n},\qquad
s=\sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}},\qquad
SEM=\frac{s}{\sqrt n}
\]

\(s\) 为样本标准差，**不能与 SEM 互换**。均值为百分数时，均值差用“个百分点”，相对变化用：

\[
\Delta_{\mathrm{rel}}=\frac{\bar{x}_T-\bar{x}_C}{\bar{x}_C}\times100\%
\]

**精度规则**：转录值不得有波动；派生值保留 \(d\) 位小数时，报告值与高精度复算值之差不得超过
\(0.5\times10^{-d}\)。例如 42.307692% 保留一位小数为 42.3%，误差 0.007692 个百分点，小于 0.05。
实验本身**不存在**通用“允许 ±5%”规则；材料内冲突必须保留，不能四舍五入掩盖。

### 3.3 效率增益

若有真实同条件对照，效率增益可写为 \((T_0-T_1)/T_0\times100\%\)；须同时报告计时范围和
返工定义，三次重复逐次列出，**不只挑选最佳一次**。没有实测对照就写“未测”。

## 4. 领域知识清单

1. **样本量**：独立实验、技术重复、视野数和细胞数不可混作同一个 \(n\)；不得把技术重复当独立
   重复计算推断统计。
2. **统计标记**：SD 描述离散度，SEM 描述均值估计精度；未提供检验方法、原始数据和设计信息时，
   不补算或编造 \(P\) 值。
3. **百分比**：50% 到 74% 是增加 24 个百分点，不是增加 24%；相对增幅为 48%。
4. **化学量纲**：\(n=cV\)，计算前将 mL 换成 L；\(m=nM\)。1 mmol 对应的质量在数值上等于
   “摩尔质量 g/mol × 1 mg/mmol”。
5. **工艺指标**：转化率、选择性、收率不是同义词；通常“收率 = 转化率 × 选择性”仅在定义和
   基准一致时成立。wt%、mol%、vol% 不得互换。
6. **材料术语**：粒径、孔径、厚度及掺杂量须保留测量方法和基准；不能仅凭形貌图推断晶相或因果关系。
7. **图文一致**：图注中的样本量、误差线含义、分面标签、单位和显著性符号必须来自图面或材料，
   不能套用常见写法。
8. **论证边界**：相关、先后和单批观察不自动构成因果；机理示意图不能替代机理证据。
9. **文献依据**：引用必须支撑其所在句的具体对象、条件和强度。综述可支撑背景概括，具体实验数值
   优先引用原始研究。
10. **元数据**：作者、年份、题名、期刊、卷期页码和 DOI 逐项核对。无法访问全文时标为“全文未核”，
   不得以摘要或标题冒充全文验证。

## 6. 完整虚构案例

> 以下材料、数据与输出均为演示虚构，不对应任何正式测试案例。

**任务输入**：依据 `M1.csv` 和 `M2.md` 撰写结果段及图 1 图注；报告均值 ± 样本 SD、组间差值和
相对增幅；不得判断显著性，不添加外部文献。

```csv
group,run_id,V_mL,c_mmol_L,M_g_mol,m_product_mg
experiment,E1,25.00,2.50,160.0,7.20
experiment,E2,25.00,2.50,160.0,7.40
experiment,E3,25.00,2.50,160.0,7.60
control,C1,25.00,2.50,160.0,5.00
control,C2,25.00,2.50,160.0,5.20
control,C3,25.00,2.50,160.0,5.40
```

`M2.md` 逐行说明：①各组为 3 次独立重复；②图 1 显示均值柱、样本 SD 误差线及独立重复散点；
③未进行统计显著性检验。

**关键中间量**：

\[
n=cV=2.50\ \mathrm{mmol/L}\times0.02500\ \mathrm{L}=0.0625\ \mathrm{mmol}
\]

\[
m_{\mathrm{theory}}=0.0625\ \mathrm{mmol}\times160.0\ \mathrm{mg/mmol}=10.00\ \mathrm{mg}
\]

产率为 \(m_{\mathrm{product}}/10.00\times100\%\)，故实验组为 72.0%、74.0%、76.0%，对照组为
50.0%、52.0%、54.0%。两组均值分别为 74.0% 和 52.0%，样本 SD 均为 2.0 个百分点；均值差为
22.0 个百分点，相对增幅为 \(22.0/52.0\times100\%=42.307692\%\)，报告为 42.3%。

**稿件输出**：

> 实验组与对照组的产率（均值 ± 样本 SD）分别为 74.0% ± 2.0% 和 52.0% ± 2.0%（各组 \(n=3\)
> 次独立重复）。实验组平均产率较对照组高 22.0 个百分点，相对增幅为 42.3%。材料未提供统计
> 检验结果，因此本结果仅描述本批重复实验的观察差异，不作显著性判断。

> **图 1｜实验组与对照组产率。** 柱高表示均值，误差线表示样本标准差，散点表示 3 次独立重复。

**证据映射示例**：

| 论断 ID | 来源与逐字定位 | 处理 |
|---|---|---|
| D01 | `M1.csv/run_id=E1..E3,C1..C3` | 按上述公式计算产率、均值、SD 及差值 |
| D02 | `M2.md/L1：“各组为3次独立重复”` | 确定 \(n=3\)，使用样本 SD |
| D03 | `M2.md/L3：“未进行统计显著性检验”` | 禁止写入“显著” |
| D04 | `M2.md/L2` 及图 1 | 核对柱高、误差线和散点含义 |

复算命令：

```bash
python -c "import statistics as s; a=[72,74,76]; b=[50,52,54]; print(s.mean(a),s.stdev(a),s.mean(b),s.stdev(b),s.mean(a)-s.mean(b),(s.mean(a)-s.mean(b))/s.mean(b)*100)"
```

预期输出依次包含 `74.0、2.0、52.0、2.0、22.0、42.307692…`。本例状态可记为 `completed`；
“未进行显著性检验”作为结论边界写入不确定性，而不是材料缺失或运行失败。
