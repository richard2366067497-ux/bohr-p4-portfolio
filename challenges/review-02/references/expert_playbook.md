# 专家参考手册 —— 引用与事实核验（review-02）

执行前**完整阅读本手册**，按 §2 六步门控推进，交付前逐项过 §8 自查表（18 项）。

## 1. 交付什么

交付物不是综述、不是润色建议，而是**逐条可回查的审查结论清单**。每条结论同时含五要素：

| 要素 | 说明 | 缺失后果 |
|------|------|----------|
| 定位串 | 页/段/行/图表号 | 判为不可复核 |
| 原文摘录 | 被审查语句的逐字引用 | 无法验证判定与原文是否一致 |
| 判定结论 | 六类之一 | 分类错影响严重度 |
| 严重度 | critical / major / minor / info | 错配直接扣分 |
| 修改建议 | 具体可操作方向 | 降为「仅发现」 |

评委看四件事：可复核性、判定正确性（区分「引用存在」与「引用支持结论」）、覆盖率（六类全覆盖）、
增益可验证（同输入对照下的净改善）。失败模式 → 正确：只给总体评价 → 逐条列问题；定位只写「第 3 节」
→ 精确到 `p.7, ¶2, L4-6`；凭记忆判定 → 必须摘录原文比对；所有问题同一严重度 → 按事实影响分级；取不到引文
强行判定 → 标「待复核（原文不可获取）」并保留定位串；漏统计一致性 → 正文/表格/摘要/图注四方交叉核对；
输出字段缺失 → 严格按 output_contract；不记来源与版本 → 记 DOI/URL + 检索日期 + 版本。

## 2. 六步门控

`输入解析 → 结构解剖 → 六维审查 → 证据锚定 → 严重度定级 → 交付组装`；前一步未冻结不进入下一步。

1. **输入解析**：解析 `case.json`（case_id、审查重点）与论文（全文、表格、图注、参考文献）；建段落索引
   `{section, page, paragraph, line_range}`；提取引用标记（`[N]`、`(Author, Year)`）。*门控*：索引条目 ≥
   正文段落数，引用标记数 ≥ 参考文献条目数，否则记解析缺陷。
2. **结构解剖**：识别章节；标注审查优先级 讨论＞结果＞方法＞引言＞摘要＞结论；抽出定量声明与因果推断句。
   *门控*：声明清单覆盖 ≥ 80% 含引用标记的语句。
3. **六维审查**（核心）：D1 引用支持（S/P/N/U）｜D2 来源可靠性（R/Q/U）｜D3 证据定位（E/F/M）｜
   D4 数值一致性（C/X/I）｜D5 论证链（L/J/R/G）｜D6 学术规范（K/N/S）。*门控*：六维均有判定或显式
   「未检查（原因）」。
4. **证据锚定**：每条 finding 补逐字摘录（≤80 字）、数值出处表、locator 串 `TEXT: p7¶2L4-6`、
   `TABLE: Table2/R3/C5`、`FIGURE: Fig3/panel-b`、`REF: [12]/p4¶1`。*门控*：每条 ≥1 个 locator + 1 段摘录。
5. **严重度定级**：见表；Critical/Major 需 ≥2 条独立证据。*门控*：定级理由可追溯到证据。
6. **交付组装**：`result.json` + 报告 Markdown + 运行日志 + 声明清单 + 证据锚定。*门控*：schema 通过、
   必填非空、locator 可解析。

## 3. 判定与量化口径

**四级支持度**：S 完整支持（原文明确陈述全部要素、方向一致、无附加条件）；P 部分支持（支持部分要素，
或带限定范围/条件）；N 不支持（语义矛盾或对象/条件不同）；U 无法判定（原文不可获取或严重歧义）。

- 引用支持率 =(S + 0.5×P)/审查声明数 ×100%；同一案例三次运行波动 ≤5 个百分点。
- 定位精度 = 精确定位(E)/finding 数 ×100%，目标 ≥90%；模糊(F) 必须写明原因（如 PDF 无页码）。
- 维度覆盖率 = 该维度有判定数/应审查数；每维 ≥85%，总体 ≥90%。
- 误报率 = 人工复核为非问题的 finding/总数，目标 ≤15%；主要来源是过度推断与忽略上下文限定。
- 严重度经验分布：Critical 5–15%（>20% 需审视）、Major 20–35%、Minor 30–45%、Info 10–25%。

严重度定义：**Critical** 影响核心结论正确性（关键引文错引致结论方向反转、核心数据矛盾）；
**Major** 影响局部论证可信度（部分支持被写成完整支持、统计量缺关键参数）；**Minor** 不影响结论但影响
严谨性（引用格式、精度表述）；**Info** 建议性意见。

## 4. 领域陷阱

常见事实性错误：数值篡改（原文 p=0.06 被引为 p<0.05）；结论过度推断（「可能相关」被引为「已证实因果」，
比对情态动词与限定词）；样本量错配（摘要 n=120 / 方法 n=118，四方交叉核对）；单位混淆（MPa vs GPa 差
1000 倍、°C vs K、原子% vs 质量%）；撤稿/更正未更新（查撤稿与更正状态）；预印本与正式版不一致（记录版本
并比对差异）；方法错引（声明方法 A、引文描述方法 B，核查引文方法部分）。

量纲速查：材料 GPa/MPa/kPa；化学 mol/L vs mmol/L，标准态 STP 0°C vs SATP 25°C；生物医学 μg/mL = mg/L
（数值同、表述不同），IC50 单位常缺失；统计量 SD vs SE 混淆、CI 缺失、p 值精度（p=0.050 vs p<0.05）。

来源记录：每条引文核验记 DOI/URL + 检索日期 + 数据库版本；预印本标「未经同行评审」；retracted/corrected
记日期与原因；同一文献在不同位置被引用时分别核查语义是否匹配。

## 5. 交付物与可核验方式

`result.json`（含 case_id、status、summary{总声明数/总 finding/严重度分布/支持率/定位精度/覆盖率}、
findings[]、pending_review[]、unchecked[]、evidence_map、change_log、coverage、limits）、
`citation_report.md`（人读报告，含摘录与定位串）、`manuscript.md`（逐条标注的被审稿件）、
`evidence.jsonl`（证据流）、`index.json`（材料索引快照，含 sha256 前缀）、`run_manifest.json`（输入哈希、
计数、预算）。

自证方式：locator 用正则校验并抽样回查原文；摘录可在材料文本中全文命中（NFKC 去空白后，须落在单个段落
单元内）；数值类 finding 列原文数值与计算过程；每条引文附 DOI/URL + 检索日期。

## 6. 异常处置

| 场景 | 处置 | 记录 |
|------|------|------|
| 材料无法解析 | 标解析失败并尝试备选提取 | 失败原因、尝试次数 |
| 引文全文不可获取 | 判 U，保留摘要级判定 | 数据库、检索日期 |
| 引文严重歧义 | 判 U 并列 ≥2 种解读 | 歧义说明 |
| 来源已撤稿 | 记 Critical | 撤稿日期与原因 |
| 版本不一致 | 记 Major | 两版 DOI 与关键差异 |
| 权限不足 | 待复核（权限不足） | 数据库名与错误信息 |

## 7. 虚构案例（自洽校验）

案例 `demo_case_001`：纳米 SiO₂ 对水泥基材料力学性能的影响；结构 摘要+引言+方法+结果+讨论+25 条参考文献。

中间量：段落索引 87 段；25 条文献、正文引用 42 处；声明 40 条（含引用 38、定量 22、因果 15）。六维审查
D1 38/12、D2 25/3、D3 28/0、D4 22/4、D5 15/5、D6 1/2（审查数/问题数，覆盖率均 100%）。支持度
S=22、P=8、N=5、U=3 → 支持率 =(22+0.5×8)/38 = 26/38 = 68.4%。定位 E=26、F=2（92.9%）。严重度
Critical 2（7.1%）、Major 8（28.6%）、Minor 13（46.4%）、Info 5（17.9%），合计 28。

- **F001（D1，Critical）** `TEXT: p8¶3L2-5` 原文「Zhang et al. [7] demonstrated that 5% nano-SiO₂ increases
  compressive strength by 45% at 28 days.」判定 N：引文 Table 3 为 23%（p<0.05），45% 属 10% 掺量，被错
  归属到 5% 掺量。建议：改「45%」为「23%」或改掺量为 10%。置信度 0.95。
- **F007（D4，Major）** 定位 `TEXT: p1¶2L8-9; TABLE: Table2/R3/C5; TEXT: p12¶1L3`：摘要/讨论 12.8 MPa，
  Table 2 实测 11.6 MPa，差 1.2 MPa；35% 提升基于 9.5 基准 →(12.8−9.5)/9.5=34.7%，用 11.6 则 22.1%。
  建议统一数值来源并改提升率为 22%。置信度 0.92。
- **F015（D5，Minor）** `TEXT: p11¶4L1-6`：由「C-S-H 凝胶含量增加」推断「成核位点」有引文支持，但直接跳到
  「耐久性显著提高」缺中间证据。建议补渗透性/抗冻融数据或改为「可能有助于改善耐久性」。置信度 0.80。

自洽校验：2+8+13+5=28 ✓；22+8+5+3=38 ✓；26/38=0.6842 ✓；26/28=0.9286 ✓；(12.8−9.5)/9.5=34.7% ✓；
(11.6−9.5)/9.5=22.1% ✓。

- [ ] C03 全部 locator 符合格式规范且可被正则解析
- [ ] C04 支持度用四分类 S/P/N/U，不是二分类
